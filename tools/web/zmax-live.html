④ 现场页能干什么

  • 全看：所有活着的流同屏 —— 全局只开 1 条串行取帧连接（手机只有 6 条 HTTP 连接，多路 MJPEG 会把连接吃干、整页卡死）
  • 单看：挑一路放大，只开 1 条 MJPEG 常连，可选「原图 / 叠加」
  • 叠加来源：🎯 仿真投影 · 🧠 大模型理解 · 📋 场景契约 · 🔍 真机检测，点哪个都回显真实结果（含失败原因）
  • 导出：状态 JSON / CSV（带帧龄+拍照时间）/ 全部流地址，一键复制
  • 装 APP：页面内直接下载安装包 + sha256 校验串
