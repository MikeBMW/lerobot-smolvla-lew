### 歪斜根因（实测，不是猜）
1. 固定窗 `[[400,1000],[2000,1000],[2000,1250],[400,1250]]` 与实际条位置对不上：条中心 y 在 **1008~1450** 漂 ~400px，条自身还带 0.6~1.0° 倾角

### v4 做法
- **模板法**：参考真图去倾斜 ROI 做模板（`templates/gf_strip_template.png/.json`）→ 1/4 尺度多角度粗搜 → 1/1 局部窗精修（角度+尺度）
  → **角度扫描**：直接以「实心金带核心行（行密度≥95% 峰值）质心线斜率」为目标度量取最小（不猜符号）→ 单次仿射映射到规范化画布
  → 兜底链：模板失败 → HSV 条带 → 中心窗（明确标记，不装正常）
- **只保留金手指本身**：纵向成分实测 = 焊盘排 y[1097,1162]（金覆盖 29.8%、|gx|=28.6 边缘密集）· 缝 · 实心金带 y[1180,1265]（覆盖 64.3%、|gx|=8.3）· 塑料本体亮边沿 y≥1258（亮度冲 255）
  → 取「最上面那片 边缘密集 且 高≥20 行」的 run = **金手指本身 1455×70**，下面两者一律不进画布
- **拉长给 YOLO**：21:1 太扁 → 纵向拉伸到 **960×960 方图**（与 `yolo_detector/config.yaml` 的 `imgsz=960` 对齐：不 letterbox 也不上采样），另存一份「原比例 1455×70」供目检

## 二、视觉伺服对准 + 自动对焦（`tools/aoi_gold_servo.py`，注册 `L2.aoi_gold_align`）✅ 离线验证

- 控制律：区域偏差 `e=(cx−cx*, cy−cy*)` → `Δarm = −M·e`（**符号必须为负**：M 是「臂动 1mm 图像动多少 px」的逆，要消掉偏差得让图像反向移动；写成 +M·e 会越跑越偏 —— 离线测试专门抓这个）
- 对焦：沿光轴退火爬坡 0.8→0.4→0.2mm，判据 = 区域内 Laplacian 方差，变差则退回并反向，峰值即停
- **四级安全闸**：①默认 dry-run，真动必须 `--authorize` ②检测不可靠（score<0.85 或 金覆盖<0.45）→ **否决步**，一条指令都不发 ③限幅（单步 2mm / 单轴累计 15mm / 25 次）④跳变闸（实测位移 vs 雅可比预期 >3× 立即停）
- 执行全部走 **L2 收口**（`L2.move_x/move_y/lift/lower`），脚本自身无自研运动学
- 现场三步（**真机未动，等老倪授权**）：`check`（只读）→ `teach`（人工摆最佳视角记基准）→ `calibrate --authorize`（真动 2 次各 1mm，自动回位）→ `serve --authorize`
