## 一句话
技能「进入金手指AOI检测区」的目标点被**做成了可编辑参数**，GUI 下拉把默认值判成无效后**静默停在第一项 `home`**，
于是下发的是 home（z≈0.294，比当时位姿低约 375mm）→ 老倪看到"继续下降"按下急停。

## 根因（两层）
1. **目标点可被参数改**：`registry.json` 里 `L2.goto_aoi_gold` 的 `param.point.default = "aoi_gold_view"`；
   `l2_skill_dialog.py` 造下拉时，若默认值不在候选列表里 `findText` 返回 -1 → **不设 currentIndex → 停在第 0 项 `home`**（静默）。
2. **下发层没有方向/意图守卫**：`l2_daemon` 直接写 ros2 service 调用，日志只打 `已下发 X -> home`，
   既没有 Δ(Δx,Δy,Δz) 也没有"回点技能不该向下 400mm"的否决权。

## 修复（本次已落地并实测）
1. **点位锁死在技能上**（`point_locked: true` + `point: "aoi_gold_view"`）：收到 spec 里的 `point` 一律忽略并告警；
   技能改成**无参数**（对话框显示"无参数, 直接开始"，从源头消掉误送）。
2. **下发前方向守卫 + Δ 必打**：每条运动日志写 `目标 … pos=… · Δ=(+0.0,+0.0,+30.0)mm ↑上升|↓下降|→平动`；
   技能可声明 `guard.dz_down_limit_mm`（本技能 20mm），向下超限**拒发**，除非 spec 带 `allow_down_mm` 显式确认。
3. **对话框默认值修复**：默认值不在候选里时**插入并选中**（不再静默回到 home），并把传授点库
   `taught_points.json` 的点名合并进下拉。
4. 实测（全部无动作）：恶意送 `point=home` → 被锁定忽略、目标仍 `aoi_gold_view` ✓；
   从上方 100mm 回点 → 守卫拒发 ✓；带 `allow_down_mm=150` → 放行 ✓；从下方 30mm 回点 → `Δ=+30mm ↑上升` ✓。
