# 第 1 章 总则与方案定位

## 1.1 方案定位
本协议定义 Z700 机器人（大小脑模型）面向光模块工厂 5 大作业场景的具身智能方案：
- 以**节拍物理硬指标**（≤6s / ≤15s / ≤20s）为不可妥协的顶层约束，反推机器人本体形态与模型架构；
- 以自研**左右脑双脑策略**（左脑动作生成 + 右脑世界模型 + 状态机调制）为核心算法基线；
- 将 Simulink 工程资产（Model Zoo 七模型 / 原子技能库 / 画布 Flow）整理为**可控模型清单**与方案交付物。

## 1.2 三控原则（工程质量点）
| 原则 | 含义 | 工程落点 |
|---|---|---|
| **可控模型** | 每个场景有明确的模型归属与备选 | Model Zoo 七模型 + 双脑策略，见第 4 章 |
| **可控架构** | 分层解耦、接口标准、可替换 | 六层架构 + L0-L4 分层目标，见第 4/5 章 |
| **可控指标** | 每个动作有可测量、可验收、可监督的指标 | 指标树 + 大屏监督，见第 6 章 |

## 1.3 节拍物理硬指标（顶层约束，不可妥协）
| 场景 | 单颗节拍上限 | 依据 |
|---|---|---|
| FW Loading / EEPROM（单颗顺序插拔） | **≤ 6 s** | 20 只/盘，1 人 2 台机异步 |
| ATS / 线外检测（多步骤循环） | **≤ 15 s** | 扫码+光口+清洁+电口+光纤+目检+分拣 |
| 热海柜体（电口+光口完整循环） | **≤ 20 s** | 电口插入 + 光口×2 插入 + 检测 |

节拍是**物理指标**：由机器人运动学（行程/速度/加速度）、动力学（负载/惯量/扭矩）、控制周期共同决定。
重量越大 → 惯量越大 → 加速度越低 → 节拍越慢。因此**机器人本体尺寸与重量必须受节拍约束反推**（见第 3 章）。

# 第 3 章 机器人本体设计依据（形态论证）

## 3.1 形态选项对比（为什么是 AMR + 协作臂）

| 形态 | 节拍能力 | 多工位 | 占地 | 成本 | 结论 |
|---|---|---|---|---|---|
| 固定工位 6 轴臂 | ★★★★ 最优（无移动损耗） | ✗ 单工位 | 小 | 中 | 测试台固定场景最优，但需每工位一台 |
| **AMR + 6 轴协作臂（Z700）** | ★★★ 6s 可行（见 3.4） | ✓ 1 机看管 2-4 台 | 0.7×0.6m 底盘 | 高 | **主推**：异步多机台是节拍关键 |
| 龙门/直线模组 | ★★★ 快速 | 线内 | 大 | 高 | 仅批量产线，不灵活 |
| 人形/双足 | ★ 慢 | ✓ | 大 | 极高 | 节拍不达标，排除 |

**结论：AMR + 协作臂是唯一同时满足"1 人 2 台异步看管"+"跨工位移动（场景 2/3）"+"6s 节拍"的形态。**

## 3.2 自由度规定（工程论证）

| 自由度 | 轴/机构 | 用途 | 依据 |
|---|---|---|---|
| 6 | 协作臂（J1-J6） | 空间位置+姿态到达（取料/翻转/插拔/分拣） | 6DOF 覆盖 3D 位置+3D 姿态 |
| 1 | 夹爪开合（伺服） | 抓取模块（20-200g，防划伤） | 视触觉指尖，夹持力 0.1-5N 可控 |
| 1 | 夹爪旋转（腕部附加） | 翻转模块 180°（标签向下） | 翻转 0.8s 关键动作 |
| 2 | AMR 差速驱动 | 跨工位移动/异步看管 | 平面定位 ±10mm，工位对接靠臂补偿 |
| 1(可选) | 升降立柱 | 老化箱多层抽屉（场景 3） | BI 箱多层 1.2m 高度覆盖 |
| **≥10** | 合计有效自由度 | | 冗余设计：7DOF 臂可选（避障+奇异规避） |

## 3.3 外形尺寸与重量约束（节拍反推）

| 项 | 要求 | 论证 |
|---|---|---|
| 整机重量 | **≤ 250 kg**（含电池） | 6s 节拍要求末端平均速度 ≥0.5m/s、峰值 ≥1.5m/s；重量 ↑ → 惯量 ↑ → 加速 ↓ → 节拍超限 |
| AMR 底盘 | ≤ 700×600×350mm · ≤ 150kg | 操作通道 0.6m 可通过 |
| 协作臂 | 自重 ≤ 25kg · 负载 5kg · 臂展 ≥ 800mm | 覆盖工作台 1.13×0.75m + 料盘区 |
| 末端执行器 | ≤ 1.5kg（夹爪+视触觉+旋转） | 末端轻量化是节拍关键（惯量 ∝ m·r²） |
| 电池 | 24h 连续运行 ≥ 8kWh | 24H 作业 + 峰值功率 1.5kW |

**重量-节拍关系（工程依据）**：末端有效惯量 I ∝ m·L² → 基座关节峰值扭矩 ≥60-80Nm（5kg 满载 3m/s²）；
全臂 25kg 时静载 ≈100Nm → **协作臂必须自重补偿**；**结论：整机 ≤250kg、臂 ≤25kg、末端 ≤1.5kg 是 6s 节拍的物理前提**。

## 3.4 6s 节拍达成的工程手段（按优先级）
1. **异步多机台**（1 机 2 台）——节拍利用率 ×2（核心手段，不增加单机速度）
2. 末端轻量化（1.5kg → 1.0kg）——惯量降 33%，加速度 +30%
3. 路径规划（直线插补 + 圆角过渡，缩短 15% 行程）
4. 预测控制（任务预取：测试结果未出先到分拣位待命）
5. 宏微复合：宏动快飞（1.5m/s）+ 微动力控对位（±0.1mm）

**关键设计（已实测）**：
- 左脑输入恒为状态，contact **不喂左脑**，只作状态机转移条件（该抓了吗）
- 状态机不喂信息给左脑，而是**调制左脑输出**（接近阶段动作×0.3+偏置×2；抓取×0.1+夹持0.6；转移速度自适应 0.6/0.35/0.15；插入力控）
- 成绩：抓起 8/8 · 插入 7/8（官方专家 7/8 基准，超视觉 BC 全部 0/8）
- 训练：lerobot 标准管道（left_right policy）· 800 epoch · MSE+BCE · seed 42 确定性复现

# 第 6 章 性能指标体系（可控指标 · 大屏严格监督）

## 6.1 指标树（每动作可测、可记录、可监督）
| 层级 | 指标 | 目标 | 监督方式 |
|---|---|---|---|
| 整机 | 成功率（全流程一次性通过） | ≥99% | 大屏 KPI |
| 子动作 | 各场景子动作成功率 | 各 ≥99.5% | 大屏动作级指标 |
| 节拍 | 场景 1 ≤6s · 场景 5 ≤15s · 场景 4 ≤20s | 硬指标 | 大屏节拍实时 |
| 精度 | 定位 ±1mm · 重复 ±0.05mm（Z700 ±0.02mm）· 力觉 0.1N | 硬指标 | 大屏精度 |
| 工艺 | 金手指零划痕 · AOI 零漏检 | 硬指标 | AOI 复核 |
| 监督 | 每机器人每动作指标达成率 | 100% 记录 | 大屏 + action-log |

## 6.2 大屏监督（factory-dashboard.html 对接本协议）
每个机器人卡增加"动作级指标"区：
- 当前动作（状态机阶段）+ 场景
- 每指标实时值 vs 目标（✅/⚠️/🔴）
- 未达标 → warning（单次）/ alarm（关键指标或连续 3 次）+ 记录
- 每个动作完成 → POST /api/action-log（robot/stage/metrics/pass/ts）→ 可追溯可导出

指标来源：left_right `select_action` 逐阶段量测（d_hp/contact/插入深度/插拔力）→ 推理循环每 N 帧上报 → 大屏实时监督。

## 6.3 验收方法
- 甲方指定环境 · 连续 72h · 累计有效插拔 ≥5000 次
- 成功率 = 成功次数/总尝试×100%（机器人原因失败允许重试 1 次，重试成功仍计失败）
- 节拍 = 中间稳定段 ≥200 颗平均值（测试等待不计入，但需证明异步能力）
- **大屏 action-log 全记录为验收留痕**，双方工程师现场签字确认非机器人原因失败
- 换型验收：软件切换型号 ≤0.5H，QSFP/OSFP/SFP 系列兼容

# 第 10 章 场景仿真工作模式定义（web3d 高保真仿真）

> 目标：把静态 3D 场景升级为**工艺仿真**——物体按原子技能序列运动、节拍实时计时、性能指标实时监督。
> 仿真数据（几何尺寸/速度/节拍）全部来自协议硬指标，保证**工艺合理、数据准确**。

## 10.1 物体 → 39D state 映射（通用）
| 39D 段 | 场景物体 | 仿真表现 |
|---|---|---|
| [0:3] 末端位置 | 机械臂手部（协作臂末端） | 沿技能轨迹运动 |
| [3] 夹爪开度 | 夹爪（视触觉） | 0=张开 1=闭合（抓/放） |
| [4:7] 工件位置 | 光模块 / 料盘 / 检测件 | 被夹持移动 |
| [7:11] 工件姿态 | 模块四元数 | 翻转/位姿调整 |
| [11:18] pad | 空槽位 | 固定 0 |
| [18:36] 上一帧 | 上帧快照 | 帧堆叠（历史） |
| [36:39] 目标位 | 插槽 / 货架格 / 检测位 | 技能目标点 |

## 10.2 场景仿真（三场景已上线）
| 场景 | URL | 技能序列 | 节拍目标 |
|---|---|---|---|
| insert（插拔=场景1 FW Loading） | scene-3d.html?scene=insert | 取料→扫码→翻转→对位插入→(测试异步)→拉出→AOI位姿→分拣 | **≤6.0s** |
| handle（搬运=场景2） | scene-3d.html?scene=handle | 料盘识别→取料→移动→放置 | ≤3.3s |
| aoi（AOI 检测=场景5 目检环节） | scene-3d.html?scene=aoi | 上料→转台×4→检测×3→判定→分拣 | ≤8.6s |

## 10.3 仿真数据准确性要求
1. **几何准确**：物体尺寸/相对位置与协议第 3 章（工作台 1.13×0.75m、通道 0.6m、AMR ≤700×600mm）一致
2. **运动准确**：技能动画速度按节拍预算反推，节拍计时 = 动画时长
3. **指标准确**：仿真 KPI 值与协议第 6 章指标树一致
4. **状态准确**：物体位置/姿态实时可读（window._sceneState 暴露 39D 映射）
5. **监督一致**：仿真节拍达标/超标实时红绿显示，规则与大屏监督一致
