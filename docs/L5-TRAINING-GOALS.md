# 大模型层（L5）训练目标

> 老倪 2026-09-25：「大模型层给出训练目标」
> 配套：`docs/L5-UPGRADE-STRATEGY.md`（升级策略） · 本文给**可验收的量化目标**
> 口径纪律：每个目标都带**平凡基线**与**判据来源**；未达标不得进默认档。

---

## 一、L5 在系统中的职责（重申）

```
L5 = 定方向（任务规划 / 阶段序列 / 变体方向）
    + 造数据（L5 规划 → 引擎真跑 → 落 h5）
不负责：控制执行（那是 L2 收口）、不负责认知预测（那是 L4）
```
**因此 L5 的"训练目标"= 规划质量 + 造数据价值，而不是逐帧回归误差。**

---

## 二、量化训练目标（4 条，逐条可判）

### 目标 1 🎯 **规划合法率**（最高优先 · 可立即验收）
```
定义: L5 产出的阶段序列中, 通过三条硬校验的比例
  ① 顺序合法（接近→对位→下降→抓取→抬起→转移→插入, 不跳反）
  ② 依赖满足（插入前必须已抓取; 抓取前必须已下降）
  ③ 与观测一致（不得规划"回到接近"当 L4 预测已在插入）
目标: **合法率 ≥ 99%**（当前无校验 ⇒ 不可测; 接入校验后为基线）
基线: 无（新指标） → 首轮测得基线, 再逐步提
判据来源: tools/planner_validate.py（待建, P1 项）
验收: 100 条规划样本, 非法即回退规则规划器（回退率一并报出）
```

### 目标 2 🎯 **造数据增益**（已验证有效 · 继续加大）
```
定义: 用 L5 造的域随机化数据训练后, 留出集 MAE 相对"仅真机数据"的改善
现状: 观测 **0.013 → 0.010 (优 23%)** ✓ 已达标
目标: **≥ 25%**（再扩变体维度/样本量）
加大方向: 变体谱从 5 维(对位±20mm/高度±10mm/阶段/力档/速度) 扩到 **8 维**
          （+ 模块姿态扰动 ±3° · 槽位错位 ±5mm · 来料表面状态档）
判据来源: tools/joint_unified_backbone.py --files 对比
验收: 同口径(同留出/同步数/同增强) 严格 A/B
```

### 目标 3 🎯 **规划-预测一致性**（P4 联动 · 中期）
```
定义: L5 规划的阶段序列, 与 L4 认知预测的 rollout 轨迹的一致度
现状: 两者各算各的（无联动）
目标: **一致性 ≥ 0.8**（L5 候选序列经 L4 rollout 打分后, 择优序列的预测代价
                       低于随机候选 20% 以上）
基线: 随机候选（无联动）
判据来源: tools/planner_mpc_eval.py（待建, P4 项）
验收: 20 个任务场景 × 3 候选 = 60 次 rollout 对比
```

### 目标 4 🎯 **场景理解延迟**（工程 KPI · 已部分达成）
```
定义: L5 场景理解（本地小 VLM）单帧延迟 + 分级调用占比
现状: 云端 DeepSeek Vision **61s**（不可用）→ 已做异步旁路; 本地 smolvlm2-500m 兜底
目标: **高频路径 < 200ms 占比 ≥ 90%**（云端只在阶段切换/异常时触发）
基线: 每步调云端 = 61s（闭环不可用）
判据来源: 延迟测量 20 轮平均（含 GPU 同步, 预热 5 轮）
验收: 闭环连续 100 帧的延迟分布
```

## 三、当前 L5 状态（实测，不夸大）

| 项 | 现状 | 目标 | 差距 |
|---|---|---|---|
| 规划合法率 | **无校验**（不可测） | ≥99% | 需先建校验（P1）|
| 造数据增益 | **+23%** ✓ | ≥25% | 扩变体维度 |
| 规划-预测一致性 | **无联动** | ≥0.8 | 需建 MPC 评测（P4）|
| 场景理解延迟 | 云端 61s / 本地兜底 | <200ms ≥90% | 需规范化分级调用（P2）|
| L5 在引擎里的意图通道 | **未接**（`L5_intent` 引擎无产出 → SU(2) 返回单位元, 诚实标注）| 接入 | 需引擎侧配合 |

**红线**：L5 未接入的部分一律**如实标注"未接"**（如结构化流形里 L5 θ=0），不编造数值。

---

## 四、执行顺序（按投产比）

```
P1 规划合法率校验 + 度量          → 0.5 天（最便宜, 防幻觉出不可执行序列）
P2 场景理解分级调用规范化          → 1 天（治 61s 延迟）
P3 变体谱扩到 8 维 → 造数据增益 ≥25% → 1 天（已验证方向, 收益确定）
P4 规划-预测联动（MPC）            → 2 天（收益最大但最贵）
P5 L5 意图接入引擎（打通 θ_L5）    → 需与引擎侧协同
```

## 五、与"训练总目标是流形引擎"的关系

```
L5 的目标最终服务于流形引擎:
  · L5 定方向 → 决定流形上的**目标点**（goal manifold 上的目标状态）
  · L4 认知   → 在流形上做**预测/导航**（测地线）
  · L3 调度   → 流形上的**速度场**（沿测地线的推进节奏）
  · L2 反馈   → 流形上的**约束收口**（把执行拉回可行域）
⇒ L5 的可验收指标 = 它给出的目标点是否**合法可达**（落在流形上且路径存在）
   这正对应目标 1（合法率）与目标 3（一致性）
```
