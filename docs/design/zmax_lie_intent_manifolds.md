## 一、架构 (四流形 + 李群结构)

| 对象 | 流形 | 表征 | 在本工程里的落地 |
|---|---|---|---|
| INTACT 旋转意图 | SU(2) | ω = log(ΔU) ∈ su(2)≅R³ | Φ_su2: 意图 Δz(192) → ω (腕/绕插拔轴) |
| INTACT 刚体意图 | SE(3) | ξ = (ω, v) ∈ se(3)≅R⁶ | Φ_se3: 意图 Δz → ξ = log(T_ee(t+1)T_ee(t)⁻¹) |
| 动作流形 A | 平移 twist 部分 | u = (v_x,v_y,v_z,grip) | 引擎动作 (旋转走 yaw 通道, 另有 SU(2) 路) |
| 接触流形 C | SE(3) 上的 twist | e = log(T_hole⁻¹·T_peg) | **孔系表达**的接触误差 (位置+姿态同一 twist) |
| 性能流形 P | 以 C 为底空间 | F_P(6) | 只作条件不注入 (插拔次要) |
| L2 执行 | 肌肉记忆/解析伺服 | 唯一出口 | 幅度包络 (每层只能收窄) |

数据流:
```
INTACT 预测潜空间 Δz
   ├─Φ_su2→ ω(3) ──┐
   ├─Φ_se3→ ξ(6) ──┴→ ① DiT 几何 token [δ(192) ⊕ ξ(6) ⊕ ω(3)] = 201 维
                      ② 导航方向参考 u_dir = unit(ξ_v)·‖u_ff_L2‖  (幅度按 L2 包络收窄)
                           ↓
                      🎚 切空间增益融合: u = (1−K_nav)·u_L2 + K_nav·u_dir (+K_flow·u_DiT)
                           ↓ 方向/幅度闸 (cos≥0.9, ≤1.5×) → 否决则交回 L2
                           ↓ L2 收口 (sched.decide + safety.saturate, 唯一出口)
```

## 二、数学 (实现见 `src/lerobot/manifold/lie_intent.py`, 纯 numpy)

- SU(2): 四元数乘法/共轭, log/exp, **双覆盖消歧 w≥0**, SLERP 测地线插值
- SE(3): so3_exp/log (含 180° 分支), se3_exp/log 闭式 (V 矩阵), 群合成
- 接触丛: `e = log(T_hole⁻¹·T_peg)` —— 与旧欧氏 F_C(6) 的差别: 姿态误差与位置误差同 twist,
  且**坐标系固定在孔上** ⇒ 同一物理误差在不同世界位姿下数值一致 (可跨场景比)
- 增益融合在**切空间**做: ξ_fuse = (1−K)ξ_L2 + K·ξ_nav, 含旋转时即群上测地线插值
  (K=0 逐位等于 L2 = 零回退; K=1 恰好 nav; 中间 = 测地线中点, 不越出流形)
- Φ 标定: PCA(32) + ridge + LOO 交叉验证, 闸 R²_loso ≥ 0.30 且 null < 0.10 (同仓既有口径)

## 四、诚实边界 (本轮没做完的)

1. **DiT 真消费 201 维条件未跑**: `SS_L4_DIT=1` 在 CPU 上极慢 (实测 120 步 >900s) → 需单独小步数实验;
   本轮只证"条件被真的拼接成 201 维并逐帧产出" (§三③), 没证 DiT 用上它后动作变好。
2. **动作里没有旋转**: 引擎动作是平移+gripper (姿态走 yaw 通道) ⇒ 切空间融合在当前动作空间
   退化为欧氏凸组合 (数学上正确且逐位可验); Lie 测地线融合的价值要等 yaw/姿态通道接进同一出口才体现。
3. **权重未重训** (沿用"换源不重训"纪律): 新增的是 Φ 标定 + 条件口径; DiT/流形预测器权重一字未改。
   "整体更新模型" 在这一轮 = 新增两路几何映射与条件 token, **不是**重训网络。
4. **无性能声明**: 本轮没有成功率的同口径 A/B (只有 §三③ 的接线与数值证据)。
