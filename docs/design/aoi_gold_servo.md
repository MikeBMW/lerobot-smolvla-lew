## 1. 已经落地的接口（工控机 192.168.23.23:10082，程序 `cam_finger_10082_work_v4.py`）

→ 上含焊盘排；**底部按行亮度中位数×1.25 切除塑料本体亮边沿**。实测 ROI y[1097,1255]（上含 1096 起的焊盘排，下停在亮带 1260 之前）。

## 2. 视觉伺服方案（`tools/aoi_gold_servo.py`）
### 2.1 控制律
- 区域检测给出定向框：(cx, cy, w, h, angle) 与清晰度 focus。
- 横向误差 `e = (cx - cx*, cy - cy*)`（像素）；**步进 `Δarm = -M · e`**，`M = (px_per_mm)^-1`（mm/px）。
  符号口径：`px_per_mm` 是“臂动 1mm 图像动多少像素”，要**消掉**偏差必须让图像反向移动 e，所以步进取负（离线测试 ① 就是抓这个符号）。
- 对焦：沿光轴（`L2.lift/lower`）**退火爬坡**（步长 0.8 → 0.4 → 0.2 mm），以 `focus`（区域内 Laplacian 方差）为判据，变差则退回并反向，峰值即停。
- 雅可比 M 由一次**现场标定**得到（沿臂 X/Y 各推 1mm，看区域中心在图像里移动多少像素）。

### 2.2 四级安全闸（缺一不动，全部在 L2 收口）
| 闸 | 判据 | 行为 |
|---|---|---|
| ① 授权闸 | 默认 dry-run | 只算并打印“本想下发什么”，真动必须显式 `--authorize` |
| ② 检测可靠闸 | score ≥ 0.85 且 金覆盖 ≥ 0.45 且 区域宽度合理 | 不可靠 → **否决步**，不发任何指令 |
| ③ 限幅闸 | 单步 ≤ 2mm、单轴累计 ≤ 15mm、迭代 ≤ 25 | 超限压到边界/停止 |
| ④ 跳变闸 | 实测区域位移 vs 按雅可比预期位移 > 3× | 立即停并报错（防夹持滑移/遮挡导致的假收敛） |

### 2.3 与状态空间的关系（分层原则）
上层（画布/技能）只给**意图**：“把金手指调到最佳视角并合焦”；执行全部落 `L2.move_x/move_y/lift/lower` 原子技能（FIFO 一行 JSON）。
伺服脚本本身**不做自研运动学**，只算偏差 + 限幅后调 L2。

## 3. 现场三步（一次性）
```bash
python3 tools/aoi_gold_servo.py check                     # 只读: 区域检测 + 与基准偏差 + 本step会下发什么(不动)
python3 tools/aoi_gold_servo.py teach --name aoi_gold_target   # 人工把模块摆到最佳视角, 记基准(只读相机)
python3 tools/aoi_gold_servo.py calibrate --authorize     # 量雅可比(真动 2 次, 每次 1mm, 自动回位)
python3 tools/aoi_gold_servo.py serve --authorize         # 伺服: 横向对准 + 自动对焦(真动)
```
基准与雅可比存 `data/skills/l2_atomic/aoi_gold_target.json`。L2 技能注册名：**L2.aoi_gold_align**。

## 4. YOLO 区域检测模型（第二阶段，数据自动标）
现在 `/region` 的几何是**模板法**（已在 5 张真图上验证：score 0.964~0.995、残余倾角≈0）。
要换成真正的 YOLO 区域检测，缺的只是数据；而数据可以**自动标**——模板法几何本身就是精确真值框：
```bash
python3 tools/aoi_gold_region_label.py --src <图片目录> --out data/gf_region_ds   # 或 --fetch N 从现场抓
yolo detect train data=data/gf_region_ds/data.yaml model=yolo11n.pt epochs=100 imgsz=960
```
- 标签：`0 cx cy w h`（归一化，类 0 = gold_finger_region），低可信样本（score<0.90 或 金覆盖<0.45）自动挑出人工复核；
- 实测（5 张真图）：5 张标好、5 张裁剪图被判低可信并跳过（正确）。
- 注意：模板法给的是**定向框**，当前落成轴对齐框（含 ±1° 旋转外扩 ~21px）。若要更紧，改走 OBB（旋转框）数据集。
- 训练后的模型直接替换画布 YOLO 节点的区域检测分支；`/region` 改为返回模型输出（接口形状不变）。
