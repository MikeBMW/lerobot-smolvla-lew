# 融合定位 · 模糊识别 → 补偿动作 → AOI 复焦复检 方案 (2026-09-24)

> 需求原话 (老倪): 「融合定位节点，主要功能是根据 目标检测、缺陷检测、触觉反馈等信息，融合成统一的状态空间，
> 要给出光模块的抓取位姿；上一个节点的外观质量检测，有的时候 AOI 给出的图片是模糊的，需要微调；
> 融合定位节点需要根据外观质量检测的是否模糊，而微调机械臂，给出修正后的位姿引导。
> 在 yolo 模型的目标检测的基础上，增加模糊图片的识别，进而补偿动作，再次让 AOI 检测聚焦」

## 0. 一句话 + 实测结论
**模糊不是缺陷**——现有 AOI 把"拉普拉斯方差低"直接判 `DET-AOI-02 对焦不良/端面破损` FAIL，
于是**离焦会被误判成端面破损**（`quality_check.py` 第 15 行注释自己写明了这个混淆）。
本方案把「模糊」从**判定项**改成**可观测状态量 + 可补偿量**：融合定位识别模糊 → 归因 → 给出**修正位姿引导**
（沿光轴扫焦 / 驻停重拍 / 补光）→ L2 收口执行微调 → 复拍 → AOI 复检。

**验证件已跑通 (10/10 判据全绿, 真机 D405 真图 + 合成离焦物理)**:
σ 估计误差 **0.056px** · 单帧量测 **2.75ms** · 扫焦曲线单峰且峰值落点 **±0.00mm** ·
两方向起步 (－9mm / ＋12mm) 均复焦成功 · 归因四类对照全对 · **现役 AOI 真机黑帧被前置闸拦住**。

## 3. 判定链 (实现于 `src/lerobot/policies/left_right/state_space/focus_quality.py`)

### 3.1 量测 (目标 ROI, 非全图)
| 指标 | 公式 | 作用 |
|---|---|---|
| `lap` | `Var(∇²I)` | 锐度 (沿用现有 AOI 口径) |
| `ten` | `mean(‖∇I‖²)` | 梯度能量 (光照更稳) |
| `hf` | 频谱 `r>0.25·r_max` 能量比 | 诊断用 |
| `aniso` | 最高频带 (r>0.6·r_max) 角度分布 (P90−P10)/mean | **仅记录** (见 3.3) |
| `clip_hi` / `mean` / `std` | 过曝占比 / 灰度均值 / 灰度标准差 | 曝光 + 有效帧 |

**模糊量用物理量表达**: `σ_est(px) = c_lap·sqrt(1/√r_lap − 1)`, `r_lap = lap/lap*` (标定最佳帧),
质量分 **`q = exp(−(σ_est/2)²)`**, **放行 q_ok=0.78 ⟺ σ_est ≤ 1.0px** (端面/金手指 ROI 边缘可判缺陷的界限)。
- ✅ 选拉普拉斯比而非 HF 比：实测 HF 比在 σ≥2px 下溢乱跳 (σ_est 4.7→18.3 **非单调**)，
  拉普拉斯比 0.5~6px **全程单调** (0.41/0.77/1.02/1.47/1.85/2.44/2.96)；σ≳3px 后饱和 → 封顶 (保守方向)。
- ✅ `c_lap` 由 R0 标定 (实测 0.532)，有效域 (0.75~2px) 内 σ 估计误差 **0.056px**。

### 3.2 🚦 有效帧闸 (第一道, 真机实测缺口)
`ten < 50` 或 `std < 5` 或 `mean < 3%` → **`no_target`**: 不判模糊、不判缺陷、不动臂 → 先查取图链路。

### 3.3 归因 (顺序: 有效帧 → 曝光 → 运动 → 清晰 → 离焦/不可恢复)
| 现象 | 判据 | 依据 | 处置 |
|---|---|---|---|
| **曝光** exposure | `clip_hi>2%` 或 `mean < 0.5×参考帧` (相对!) | 与 PSF 无关 | 调曝光/增益/补光后重拍 |
| **运动** motion | **臂速 > 0.15 (编码器真值)**，图像方向性仅作佐证 | 匀速运动 PSF 是线段 | **驻停 settle** 后重拍 (不动臂) |
| **离焦** defocus | q < q_ok 且**扫焦行程内 q 峰值可达放行线** | 离焦 PSF 圆对称, 移动光轴改变锐度 | **沿光轴扫焦** (§4) |
| **不可恢复** unresolvable | 扫焦后 `q_best < q_ok` (或曲线近乎平坦 <5%) | 端面散射/破损/污染/遮挡 | **不修** → 如实报 NG 转人工 |

**三条实测修正 (全部来自本轮真机数据, 每条都否掉了一个"想当然"的判据)**:
1. **运动归因不能用图像方向性**: ① 方向依赖 —— 0°/90° 拖影时 aniso 反而**降**到 0.52×/0.62×基线 (会漏检);
   ② **离焦把该比值抬得比真运动更高** (深离焦 2.70× vs 真运动 2.17×) → 任何"方向性=运动"的判据都会误杀离焦。
   ⇒ 图像只回答"糊不糊"，"为什么糊"由系统状态回答 (**臂速**)。
2. **曝光判据必须相对参考帧**: 暗场工件 mean=8.4/255 是正常值，绝对阈值 0.15 会全体误报欠曝。
3. **"能否修"= 扫焦后能否恢复到放行线**，不是"q 随 Z 变不变"：相机在臂上 ⇒ 任意模糊都随 Z 变。

## 4. 补偿动作 (上层只给意图/条件, L2 收口执行)
```
pose_grasp     = YOLO 3D → 抓握点 (pegGrasp 锚 + 上方 2cm) + yaw 对准        ← 抓取位姿 (语义不变)
Δfocus         = n̂_cam · dz,  n̂_cam = R_base←cam 光轴 (手眼外参可得)
pose_corrected = pose_grasp + Δfocus                                        ← 修正后的位姿引导
intent         = {reason: no_target|exposure|motion|defocus|unresolvable|clear,
                  action: inspect_chain|light|settle|refocus|none, expect: q ≥ q_ok}
```
**扫焦律 = 对比检测式 AF (粗扫 + 细化), 不用梯度爬山**:
1. 微探 ±1mm 定方向 (等值时反向再探一次)
2. **粗扫**: 3mm 步长两方向对称扫 `±travel/2`
   ⚠️ 为什么不用爬山: 深离焦 (σ>4px) 时 q 落到地板 (≈0.11) **无梯度**, 实测 12mm 偏差走不回来;
   AF 标准做法 (有界粗扫 + 局部细化) 只依赖 **q(z) 单峰** (R1a 已证单峰)。
3. **细扫**: 1mm → 0.3mm 逐级收敛到 `q ≥ 0.78`
4. 限幅: 单步 ≤3mm · 累计 ≤30mm · **仅非接触阶段白名单**; 力控/插入中禁止动 Z
5. 失败诚实: 行程内 `q_best < q_ok` → `unresolvable` → 报 NG 转人工 (绝不假装成功)

## 8. 风险与红线
- ❌ 不把"移动臂修固有缺陷"当功能 (扫焦后仍 < q_ok → 报 NG)
- ❌ 不在接触/插入段动 Z (白名单 + L2 收口闸)
- ❌ 图像判据不越权: 方向性**不作运动判据**; 曝光/结构阈值**相对参考帧**
- ❌ 图像为传输/曝光/无结构问题 (黑帧) 时不动臂 → `no_target` 先查链路
- ✅ 每步留证据: `q(z)` 曲线 / 探测轨迹 / 归因 json, 失败如实上报
