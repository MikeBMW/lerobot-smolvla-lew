## 一、INTACT 三要素(论文原话)与本仓库逐条对照

| # | INTACT 要素(原文) | 论文含义 | 本仓库现状 | 判定 |
|---|---|---|---|---|
| ① | Shared **proper action likelihood** | 同一个算子 G_eta,用**同一个动作概率分布**输出动作(物理与目标统一成一种语言) | `intent_pair.SharedIntentEncoder` 两态走同一 `__call__`、同一套参数 ✓ 但输出是**确定性动作**,不是**似然** | **结构共享已达成 / 似然层缺失** |
| ② | Attached physical-successor endpoint + **stop-gradient** goal anchor | z_{t+1} 双向梯度(绳,接地);z_g 单向停梯度(锚,不扰动物理认知) | `SharedIntentEncoder.stop_grad_on_goal` 语义写对(前向照常/反向截断)✓ 但**尚无真实训练循环**执行它 | **语义已实现 / 训练未落地** |
| ③ | **No pointwise loss** to collapse the two latent condition families | 拒绝用 L2 把 z_t 与 z_g 拉成逐点相等;只要"当前状态下触发相同动作"即为等价 | `motor_hub.build_quotient()` 条件动作商 ✓ **已实测**:孔位(左)/(右)数值不同 → 折叠进同一动作等价类 → 输出同一动作 | **已真正落地** ✓ |

**结论**:三要素里,③ 已实证落地,① 结构共享已做,② 语义已做但训练未落地;
**① 的"似然"与 ② 的训练循环是缺口**。

## 二、为什么必须"三合一"(缺一即退化)

```
缺 ① 共享似然  → 物理与目标各用一套网络/损失 → 表征割裂 (representation-control asymmetry)
缺 ② 非对称梯度 → 目标端反向改写编码器 → 模型为迁就目标而扭曲物理认知 → 反物理动作
缺 ③ 无逐点损失 → L2 强拉 z_t 与 z_g 相等 → 潜空间塌缩 (传统 JEPA 的老毛病) / 反物理
```
**三者同时成立,才叫 INTACT;任何一条缺失,都退化成"普通模仿学习 + 世界模型"。**

## 三、与现有流形的关系(为什么保留流形是对的)

```
                  ┌── 接触流形 (保留): e_par → m_local , e_perp → 风险
 状态 z_t ────────┤
                  └── 性能流形 (保留): −∇V_p → m_goal , η → 完成度
                            │
                            ▼
              G_eta (共享算子, INTACT ①): 共享语法(Δz∈R³)+ 共享参数
              输出 p(a | z_t, m)  ← **似然**,不是确定性 a
                            │
                  训练目标 (INTACT ②③):
                    · m_local 路径: 梯度畅通 (attached, 塑造编码器)
                    · m_goal  路径: stop-gradient (锚, 不改写物理认知)
                    · 损失**不用** ‖z_t − z_g‖²;改用:
                      动作似然 NLL  +  条件动作商一致性(类内一致/类间可分)
```

**流形提供"物理接地"(状态在哪个曲面上、约束与风险边界),意图层提供"规划能力"(往哪走)。**
二者正交、互补 —— 流形恰好补上 INTACT 论文靠"物理状态转移"隐式提供的接地性,
而且本仓库的流形是**显式几何**(可审计、可解释),比隐式潜空间更强。

**关键洞见:等价类的边界 = 流形的边界。** 同一个流形通道内,目标数值虽异而动作规律相同
(这正是 ③ 说的"不需在数值上长得一样")。

## 四、分阶段路线(可执行)

### 阶段 1:意图层接入引擎(零训练,当天可验)★ 进行中
- [x] `intent_pair.py`:二态意图 + 共享算子 + 同构核验 + 符号统一
- [ ] 引擎 L4 档每帧产出 `(m_local, m_goal)`,写入 `tr` 与 shared_memory
- [ ] 可选引导开关 `SS_L4_INTENT=1`(默认关):用 `m_goal` 引导长程段 / `m_local` 引导短程段,L2 伺服兜底
- [ ] 验证:同 seed 对比"接入前/接入后"成功率与步数,**成功组零回退**

### 阶段 2:动作似然头(补 ① 的缺口,轻量训练)
- 把 `SharedIntentEncoder` 从确定性输出改为 **分布输出** `p(a|z,m)`
  (高斯/混合高斯;对角协方差起步,参数量小、可在现有 4060 上训)
- 训练目标:`NLL(a* | z_t, m)` — 两态**共用同一个似然头与同一套参数**
- 验收:两态在同一似然头下的 NLL 均下降,且 **m_local 路径的编码器梯度范数 ≫ m_goal 路径**(即 ② 生效)

### 阶段 3:非对称梯度 + 无逐点损失(补 ②③ 的训练落地)
- 训练循环中显式:`m_goal` 分支 `detach()`(实现 ② 的锚)
- 损失函数**禁止**出现 `‖z_t − z_g‖²` 类逐点项;改为:
  ```
  L = NLL(a_local | z_t, m_local)                     # 物理接地(attached, 全梯度)
    + NLL(a_goal  | z_t, m_goal.detach())              # 目标导向(锚, 停梯度)
    + λ · L_quotient                                     # 条件动作商一致性:
                                                         #   同类动作规律一致 / 异类可分
  ```
  `L_quotient` 直接复用 `motor_hub` 的等价类标签(已实测可得),**不需要**潜空间逐点匹配。
- 消融(必须做,证明三要素各自的作用):
  | 消融项 | 预期退化 |
  |---|---|
  | 去 ② (goal 也反传) | 物理认知被目标扭曲 → 反物理/精度下降 |
  | 去 ③ (加回 L2 逐点) | 潜空间塌缩 → 泛化/多样性下降 |
  | 去 ① (两套网络) | 表征割裂 → 两态各自变差 |

### 阶段 4:与 L2/L3/L4 分层对齐(架构定稿)
- **L4**(本层):流形 + 二态意图,产出 `m_local/m_goal` 与动作似然
- **L3**:以意图为条件的技能选择(哪些技能能实现该意图)
- **L2**:六层伺服执行,**保持不动**(已验证资产)
- 验收口径沿用今日已验证流程:引擎真物理 + AOI PASS + 视频存证 + 模型路径打印可核对

## 五、风险与红线

1. **不得回退**:任何阶段都要做"成功组零回退"回归(成功组步数须与接入前逐帧一致或更优)。
2. **不得伪造**:所有结论须有 `tools/eval_takeover.py` 类的可复现脚本 + 视频/日志证据;
   模型 ckpt 路径必须打印在日志里。
3. **不得替换流形**:流形是物理接地的真源,意图层只叠加。
4. **L2 执行层不改**:decoder/意图层只产出"参考/意图",不出底层力矩。
5. **训练量诚实报数**:epoch、有效 batch、步数、时长一律标明(避免"30 分钟够不够"这类误判)。
