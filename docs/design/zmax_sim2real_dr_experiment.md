# Z-MAX 感知层 sim→real 域差专题: 域随机化 (DR) 同口径对照实验 (2026-09-17)

老倪原话: 「我要用 yolo 目标检测的模型, 运行在 orin 上, 能够感知实际的机器人环境」。
上一轮 (`zmax_sim2real_yolo_flow.md`) 把**链路**打通了 (仿真/真机同一份检测+反投影, 换源即换世界,
Orin 上 D405 真跑 36ms/帧); 剩下唯一的硬缺口是**模型本身看不懂真机画面** (真机 D405 帧 0 检出)。
本轮把这条缺口做成有结论的同口径 A/B。

## 一、结论先说 (实测数字)

| 臂 | 训练数据 | 真机 19 帧 × 4 朝向 | 真机最高 conf | 仿真 hold-out (不回退判据) |
|---|---|---|---|---|
| `peg_v1` (现生产权重) | 仿真 1800 | **0 帧检出 / 0 框** | 0.0107 | 3.00 框/帧 · 三类齐全 60/60 · conf 0.96~0.97 |
| `ctrl_sim` (控变量: 只重训) | 仿真 1800 (同集重训) | **0 / 0** | 0.0301 | 3.00 · 60/60 · 0.96~0.97 |
| `dr_mix` (域随机化) | 仿真 1800 + **DR 8100** | **0 / 0** | 0.0177 | 3.00 · 60/60 · 0.92~0.94 |

**结论**: 纯仿真域随机化**不足以**跨到产线真机 —— 76 次推理 (19 帧 × 4 朝向) 全 0 检出,
峰值置信度只从 0.0107 抬到 0.0301 (DR 臂 0.0177), 仍只有阈值 0.25 的 ~1/10; 仿真侧零回退。
⇒ 真机数据微调 (路线①) / 教师蒸馏 (路线②) 是必做, 二者都需要 **Orin 在线**; 本轮 Orin 直连网卡不在,
两条路都动不了 (见 §6)。

## 二、为什么这个负结果可信 (口径)

- **同帧集**: 真机 D405 帧去重后 20 张 → 剔除 1 张纯黑帧 (`live_0`, std<5) → **19 帧**; 4 朝向枚举
  (真机朝向未知); 全部 `imgsz=480` · `conf=0.25` · ultralytics BGR 口径。
- **同基座/同超参**: 三臂都从生产权重 `peg_v1` 域适应微调; 25 epoch · batch 16 · imgsz 480 · seed 0 · GPU 4060;
  **只差数据**。
- **测集自检 (不需要模型)**: 20 张真机帧其实分两类 ——
  `20260917_0930xx` 那 8 帧下方正中 ROI 有明显成块结构 (最大边缘连通块 619~651px, ROI 梯度 7.3 > 全图 6.7),
  `dev2/dev4/live/alt` 那 11 帧 ROI 几乎无结构 (最大块 4~39px)。
  → 分帧组报: 两组**都是 0 检出**, 所以"0 检出"不是被少数空白帧拉低的 (`real_frame_selfcheck.json`)。
- **位置先验判据**: 现场光模块位于画面**最下方正中** (老倪口述) → 检出框中心须落
  `x∈[0.25,0.75] ∧ y∈[0.55,1.0]` 才算真检出。三臂真机 0 框 ⇒ 也**没有"区外噪声拟检"**。
- **朝向一致性**: 真机相机朝向固定 → 真检出应集中在同一 rot; 三臂 4 朝向分布全是 `[0,0,0,0]`。

## 三、DR 做了什么 (两层, 全部保留几何一致性)

生成器: `src/lerobot/policies/yolo_3d/gen_yolo_data.py --dr`(**默认关 = 原路径零回退**)

| 层 | 内容 |
|---|---|
| ① 场景层 `--dr-scene` (mujoco) | 光照位置/方向/强度/色温偏移/环境光/高光 · **12 个材质颜色全随机** · 6 张纹理换随机噪声 · 相机 ±3cm 位置抖动 · fovy ±5% · 相机微旋转 ±5°(图像与标注读同一份 model, 天然同步) |
| ② 图像层 | 亮度/伽马/对比度/色偏(白平衡) · 高斯噪声 · 运动/离焦/降采样回采样模糊 · 暗角 · 随机遮挡块 · 缩放裁切(框同步) · 小角旋转 ±8°(框同步) · **灰底 114 letterbox**(复刻 640x480 真机帧送进 imgsz=480 后的版式) |

数据: **9000 张** (30 episodes × 150 步 × 2 rep, `--scene-seed 20260917`) + 原仿真 1800
→ 训练 9900 / 验证 1500 (DR 留出 3 个整 episode 900 张 + **非 DR** 仿真 hold-out 600 张, 场景未训过)。

## 四、取证 (全部可复跑)

| 验证 | 方法 | 结果 |
|---|---|---|
| **零回退** | `--dr` 关闭时, 新代码标注公式 vs git HEAD 旧公式**同进程同帧**逐字符比对 | **120/120 一致** ✅ |
| DR 可复现 | 同 `--scene-seed` 跑两次, 整棵输出树逐文件 md5 | **300/300 逐位一致** ✅ |
| 标签几何一致性 | 独立方法: 标注框中心放**唯一标记**, 标记 patch 走同一几何变换链, 再在增广图上模板匹配 | **60/60 通过**, 最大错位 **7.3px**(中位 0.7px) ✅ |
| 位置先验/朝向/分帧组 | `tools/analyze_real_det.py` | 三臂 0 框, 无区外噪声 ✅ |
| 侧向不回退 | `tools/eval_sim2real_yolo.py` 仿真 hold-out 侧 | 三臂 3.00 框/帧 · 60/60 ✅ |

**两个重要坑 (写进技能了)**:
1. **跨进程"逐位比对"在这套生成器上不成立**: mujoco/metaworld 的场景随机向量走**全局 np.random**,
   `env.reset(seed=ep)` 不生效 → 同一份旧代码跑两次, 300/300 图**都不一样**(实测)。所以
   (a) 零回退只能用"同进程等价性"证明; (b) 训练/评测必须用**落盘的固定数据集**, 不能靠"同 seed 重生成";
   (c) 想要可复现必须显式 `--scene-seed`(新加, DR 模式默认带上)。
2. **模板匹配做标签一致性时, 底图必须放唯一标记**: 用规则矩形/纹理当底图 → `matchTemplate` 歧义
   (匹配度 0.05~0.17) → 假失败; 另外 patch 的**缩放因子**(96×480/cw)与**旋转中心**(patch 自身中心,
   不是图像中心) 必须算对, 否则也是假失败 (本轮两版都踩过)。

## 五、结论对交付的意义

- 代码侧: 链路、标注工位(v5.6.22)、DR 数据管线、双侧评测器**都已就绪**, 且 DR 数据可直接作为
  真机微调的**混合防遗忘集** → 本轮不是白干, 是排除了成本最低的一条路。
- 模型侧: "仿真跑完无缝移植到真机"的**接线部分已达成**(零回退 0.00e+00, 几何 2.22e-16),
  但**感知能力**这一段在数据侧卡住, 且已定量: 不是接线问题, 是域差问题。
