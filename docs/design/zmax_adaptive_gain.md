# 🎚 Z-MAX 卡尔曼式自适应增益 (L4 导航 / L3 流程 / L2 执行)

> 需求原文 (老倪 2026-09-16):
> "🧠 前馈 MLP 主执行 这个通道, 需要参考卡尔曼滤波增益的方式, 即系统根据算法结构, 自动调整增益,
> 增益大了, 则更相信 L4, 增益小了, 默认使用 L2 功能前馈加速器的功能; L2 功能是直接连接底层物理
> 世界的, 是靠肌肉记忆保持高效运行的; 只有泛化场景, 或者被干扰后, L4 的功能就被抬升增益, 即
> **L4 是导航增益, L3 是流程增益, L2 是实际动作执行**; DiT 模块负责将 L4 的意图转化成流程动作,
> 这个流程动作, 又被 L2 层的肌肉记忆修正, 最终被物理执行。"

## 一、数学 (卡尔曼形式, 纯 numpy, 无训练权重)

每轴独立 (xyz; 夹爪由状态机管辖, 不进增益):

```
先验 (L2 肌肉记忆/解析伺服 = 直接连物理那层)   u⁻ = u_l2
先验不确定度                                  P⁻ = κ·P + Q0 + Σ Q_event
观测 (两路, 各自有噪声)                        y_nav = L4 意图动作 (对齐后)   y_flow = L3 DiT 流程动作
观测噪声                                      R_i  = (标定残差)² + R0_i
增益 (唯一"自动调整"机制)                       K_i  = P⁻ / (P⁻ + R_i)      ← 熟场景 P 小 → K 小
更新                                           u    = u⁻ + K_nav(y_nav−u⁻) + K_flow(y_flow−u⁻)
后验                                           P    = (1 − K_eff)·P⁻      (K_eff = 1−(1−K_nav)(1−K_flow))
肌肉记忆修正 (L2 收口)                          u    ← u + K_mm(u_champ − u),   K_mm = K_mm0·(1−K_nav)
熟场景零增益闸                                  P⁻ ≤ 1.6·Q0/(1−κ) → K 硬置 0 (逐位回到 L2)
```

物理直觉: **先验 = L2 (肌肉记忆)**, **观测 = 上层 (L4 导航 / L3 流程)**。P 小 = 练熟了 =
自动信 L2; 场景一变 (OOD/没练过/受扰/停滞) 事件项把 Q 抬起来 → P 涨 → K 自动涨 = 信上层。
事件消失后 κ(=0.90) 逐步衰减把它拉回 L2 —— 稳定性锚仍在 L2 的势函数上, 不会长期脱离执行层。

### 事件 → Q (全部真实可测, 无凭感觉系数)

| 事件 | 观测来源 (引擎实测信号) | Q 抬升 |
|---|---|---|
| `ood` 泛化 | 39 维观测按左脑 MLP 自带 sm/ss 归一化后 max\|xn\|/DOMAIN_SIGMA − 1 | 0.05·ε |
| `mm_miss` 没练过 | `muscle.get_champ(seed, stage)` 无标杆 (该场景没固化过) | 0.03 |
| `innov` 受扰 | ‖y_nav − u⁻‖ > 3σ_√R → 归一化新息超门幅度 | 0.04·ε |
| `stall` 停滞 | 本阶段任务势 25 帧窗口内几乎不降 (hand→本段目标 / peg头→孔口) | 0.06 |
| `stage_switch` 换阶段 | 阶段标签变化 (流程不确定) | 0.02 |

**势必须与阶段同口径** (实测教训): 一开始统一用 ‖peg头−孔口‖, 接近段 (还没抓件) 该量恒
338mm 不变 → 停滞恒 1 → 增益被顶到帽 (熟场景也判"受扰")。改成 下降/抓取/插入/拔出 → peg↔孔口,
其余段 → hand↔本段目标 后, 熟场景自然回到 0。

### 三层语义 (与老倪口径一一对应)

| 层 | 增益 | 只准产出 | 上界 |
|---|---|---|---|
| L4 | `K_nav` 导航增益 | 意图 → 对齐层 → 动作量纲参考 | 0.5 |
| L3 | `K_flow` 流程增益 (DiT 流程动作) | 流程参考 | 0.5 |
| L2 | 执行层 (肌肉记忆 + 解析伺服) | **唯一执行出口** (sched.decide + safety.saturate) | 1.0 |

**读法 (诚实, 不吹)**:
- **机制生效且方向正确**: 熟场景 K 尾=**0.0 / 纯 L2** (p_last 0.0015 < p_zero 0.0016, 肌肉快通道
  命中 564/600 帧); 泛化场景 K≈0.34~0.4 (mm_miss 事件驱动, 未顶帽); 关闭开关时增益层 592 帧
  **一次没跑** (gain.steps=0, 运行期惰性)。
- **增益抬起来没有带来收益** (本轮实测): 所有 gain 变体的终点都差于 base (777: 47~51 vs **23.4**mm;
  0: 338~441 vs **337**mm), 只有"最小距离"略好 (777: 16.6~16.7 vs 18.5mm)。
- 方向/幅度闸 (cos≥0.9, ≤1.5×) 实测: 777 只否掉 **40/592 帧** (cos 均 0.933), 终点 47.24→47.97
  (差 0.7mm) ⇒ **闸不是瓶颈**; 对齐层已让方向一致 (LOO cos +0.931) 却仍不如 base
  ⇒ **瓶颈是上层动作本身的质量** (与此前离线判闸一致: 模型动作幅度塌/预测 std 小 16 倍),
  不是接线也不是闸。
- ⇒ 结论: **保持 opt-in, 不进默认档** (老倪门槛: 有提升非仅不回退, 本轮**无提升**)。
  下一步的前置条件写清楚了: **抬增益必须以"上层提案在当前场景优于 L2"为前置判据** (质量闸),
  否则 stall 这类事件只是把不如 L2 的动作放大; 建议做成: 离线先判 (同权重同帧 L4 vs L2 的
  MAE/势差), 过闸的场景才允许 K>0, 未过闸 → 只记录不注入。
