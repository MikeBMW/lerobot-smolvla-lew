四、关键判读 (为什么"总超限")
  1. 静止时 J5 实测 21.93~21.98 Nm, 而限定力矩 = 22.000000 Nm ⇒ 基线只差 0.02~0.07 Nm,
     任何动作/扰动都会立刻越过 ⇒ "一动就报"
  2. J5 的重力模型只有 2.03 Nm, 传感器读 21.93 ⇒ 相差约 20 Nm
  3. J1 是竖直轴, 重力力矩在任何姿态恒为 0, 传感器却读 28.98 Nm ⇒ 该值不可能来自重力
  4. 排除外部力/干涉: 全部连杆与末端都在台面之上(最低 z=0.293m); 假设末端只受一个外力,
     最小二乘解出需 132 N 且仍有 22.8 Nm 残差解释不了 (原始残差 58.9)
  5. 结论: 关节力矩传感器读数与控制器动力学模型不自洽 (即 #41447 报的内容), 与负载大小无关

五、已做过的处置

     (J1 29.129→28.983, J5 -21.981→-21.927) ⇒ 重启不改变该偏差
