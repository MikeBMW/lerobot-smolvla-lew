## 一、方案一句话

**机器人自己就是标定物和标注机。** 让机器人夹着光模块在相机视野里走 13 个位姿 (带深度 + 姿态变化),
用"画面里的模块运动"配"末端位姿真值"来自标定出"3D→像素"的投影矩阵; 之后机器人的每一次正常插拔,
都能自动产出几何真值的 YOLO 标签 → 在画布上选『🎯 真机数据 L2 训练』跑闭环 → 有提升才上在役。

不需要棋盘格, 不需要人拖框, 不需要在 Orin 上装任何程序 (只读旁路)。

## 二、三段链路 (谁在什么时候动)

```
S0 探针运动 (现场一次, 约 10 分钟)
    机器人夹着模块走 13 个位姿: 3x3 栅格(±40mm) + 3 个深度(+55/+110mm) + 姿态 ±16°
    边走边采: 每帧图像 + 该刻 TCP/四元数真值 (必须**同刻配对**) + 模块区域(ROI)
       │  tools/real_probe_plan.py 生成计划并做安全/可辨识性预检 (不连机器人)
       ▼
S1 自标定 (秒级)
    配对: 图像运动域质心 ↔ 两帧 TCP中点 + R(中点姿态)·实测模块偏移
    解 3x4 投影矩阵 P (DLT) → 预检 (非共面?) → rms ≤2px 才落盘 models/real_cam_proj.json
       │  预检不过 / rms 超差 → **拒绝落盘** (不把只在平面内有效的 P 当标定用)
       ▼
S2 批量自动标注 (常驻, 随生产跑)
    任何"抓取→搬运→插入"过程: 模块 8 角点投影 → AABB → YOLO 框 (class=peg, annotator=auto:kinematic)
    抓取门: 只在"模块该在的位置有随动"的帧发标签 (没夹住/不在视野一律不发)
       │  自动标签**只进 train** (永不进 val)
       ▼
训练模式闭环 (画布「🔀 训练/推理」→ 🎯 真机数据 L2 训练 → ▶ 运行)
    几何标注**两条标定来源**: ① 机器人动作自标定 models/real_cam_proj.json (优先)
                              ② 棋盘格/手眼 models/real_cam_calib.json (次之)
    都没有 → 几何路拒算 (回落到伪标注, 并如实标 annotator=auto:pseudo); `--status` 的 calib_route 显示当前走哪条
    新样本 ≥12 张 → 建集(去重+auto强制train) → 从在役权重微调 → **训练后新采真机帧同口径对照**
    → 有提升才原子切换在役指针 (记 sha256); 无提升按纪律不上默认档
```

真机数据侧的独立核查 (今天现场归档帧):
- 在役 YOLO 对真机帧 peg 检出 12/12 (conf 0.295) —— 说明"能看到实际图像"成立, 但 conf 低 → 只能当 ROI/伪标注兜底, 不能当几何真值。
- 真机帧上模块**比周围暗** (框内−环带 Δ 中位 −25 灰度): 所以"按亮度把模块抠出来"这条路**不成立**, 必须靠区域(ROI) 或独立定位。
- 归档会话里 **帧与 TCP 真值时间未对齐** (0718 会话: ΔTCP=0mm 而画面移动 ~100px) → 采集必须同刻配对, 否则配对数据本身就是废的。
- 用**在役权重**给真机会话生成 ROI (`tools/make_roi_from_yolo.py`, 已加质量门): 0718 会话 3/3 帧检出
  (conf 0.912~0.942, 框 51x106px) 可用; 1434 近景会话 7 帧里最高只有 conf 0.213 且框贴在画面右边
  (9.8x131px, 模块被裁掉) → 质量门 (conf≥0.5 + 剔贴边框) 判 0 条可用。⇒ **ROI 会缺帧, 缺了就保守不发标签**;
  近景视角要靠人工框一次, 或先补这类视角的数据。

## 四、七条工程要求 (每条都对应一个实测数字)

1. **质心取"全部运动域的面积加权", 不取"最大连通域"** —— 纯平移时对称差是两瓣, 取最大域会随机偏 15~30px。代码: `motion_centroid_all()`。
2. **3D 点必须加"实测模块偏移"** —— 模块中心 ≠ TCP (长杆夹在一端)。不给偏移, 标签整框偏; 给了才 ≤2px。
3. **运动必须收口到"模块区域(ROI)"** —— 不收口时差分质心是"模块+夹爪"合成点, 标签 IoU 0.0。ROI 要**每帧独立**给 (相邻两帧取并集就自动覆盖帧间位移), pad 只能小 (6px), 放大会把夹爪重新框进来 (实测留出误差 2.3 → 19.2px)。
4. **探针位姿必须非共面** (要有 60~130mm 深度变化) —— 只在正对相机的平面上平移, DLT 病态, 反解 K=0 (实测 rms 244px)。
5. **探针要带 ±16° 以上姿态变化** —— 只平移时"偏移给错"会被 DLT 自洽吸收 (rms 1.64px 看着很好, 盲测 35px)。
6. **抓取门看"模块该在的位置有没有随动"** —— 看全图最大域的话, 任何跟着 TCP 动的东西 (夹爪) 都会放行。
7. **配对的位置和姿态都取中点** —— 位置取 TCP 中点, 姿态取四元数 slerp 中点。少一样都引入半采样周期偏置 (长杆上姿态偏可达 10px)。

## 五、闸门与红线 (写死在代码里)

| 红线 | 实现 | 为什么 |
|---|---|---|
| 不拿旧帧冒充实时 | 帧龄 ∈ [0,3s], **负帧龄拒用** | 现场时钟回拨事故 |
| 位姿退化不许落盘 | `probe_design_check()`: 平面性 σ3/σ1 ≥ 0.15, 否则拒绝写入 P | 平面 P 在平面外完全不可用 |
| 标定不达标不许出标签 | rms >2px / 无 P → 不出标签 | 错标定比没标定更坏 |
| 抓取未确认不发标签 | 夹爪真值优先; 否则"模块预测位置 ±半径内有随动" | 不给"没夹住"的帧发标签 |
| **自动标签永不进 val** | 建集时 `is_auto → train` 强制; `auto_in_val` 必须 0 | val 是交付门槛的裁决集 |
| 未证明提升不上线 | 只看"训练后新采真机帧同口径对照"; 0 检出不算提升 | 老倪门槛 |
| 只读真机 | 只读旁路落盘的帧+真值, Orin 零自研零自启 | Orin 侧红线 |
| 上线原子性 | 符号链接原子替换 + sha256 留痕 | 读者要么旧要么新 |

## 六、现场操作清单 (Orin 在线后, 约 30 分钟)

```bash
# 0) 前置 (各量一次, 不猜)
#   ① 模块物理尺寸 (游标卡尺): 长x宽x厚 mm
#   ② 模块几何中心相对 TCP 的偏移: 沿工具轴量, 给 mm
#   ③ 模块区域 ROI (每帧一个模块框, 放 <会话>/roi.jsonl):
gui-venv311/bin/python tools/make_roi_from_yolo.py --session data/yolo_annot/sessions/<会话>
#      在役权重自动出框 (conf≥0.5 + 剔贴边框); 缺帧就是缺帧, 不补; 近景检不出时人工框一次

# 1) 生成探针计划并自检 (不连机器人也可以先跑)
gui-venv311/bin/python tools/real_probe_plan.py --tcp <当前TCP> --out /tmp/probe_plan.json
#    自检: 非共面 / 带姿态变化 / 步距在限内 / 全在安全盒内 —— 不合格会直接拒

# 2) 现场按计划走 13 个位姿, 边走边采图 + 真值 (必须同刻)
#    (Orin 侧零程序: 4060 侧 Docker 只读订阅 /robot/tcp_pose + D405 帧, 或控制台采集)

# 3) 自标定 (秒级) —— 预检不过 / rms 超差会拒绝落盘
gui-venv311/bin/python tools/real_autolabel.py --probe <会话>/frames --truth <会话>/truth.jsonl \
    --module-offset <偏移mm> --out models/real_cam_proj.json

# 4) 试标一版 (只统计不落盘), 看标签数与 IoU 抽检
gui-venv311/bin/python tools/real_autolabel.py --label-session <会话> --size <尺寸mm> --module-offset <偏移mm> --dry-run

# 5) 正式接进训练模式: 画布「🔀 训练/推理」双击切到『🎯 真机数据 L2 训练』→ ▶ 运行
#    之后正常插拔过程就会自动攒样本 → 到阈值自动跑一轮 → 有提升才上在役
```

## 七、还没打通的 (诚实缺口, 按依赖排序)

1. **相机内参 K 不能从探针里反解** —— 实测: 反投影残差 1.2px 的拟合里 fx 只有 175 (真值 610)。浅景深下内参不可辨识。
   ⇒ **2D 标注够用** (这正是 S2 需要的); 要做 **3D 反投影(像素→米)** 必须单独标 K (棋盘格 10 分钟, 或 D405 工厂内参)。
2. **帧与真值的时间对齐** —— 归档会话实测 ΔTCP=0 而画面移动 ~100px。采集端要同刻配对 (共同时钟 + 容差), 否则 S1 的点对本身是废的。
3. **夹爪开度发布者缺失** —— 抓取门现在只能靠"图像随动" + ROI; 有 `/gripper_pos` 真值时应优先用真值 (更硬)。
4. **现场几何未示教** (`real_cell_geometry.json` 缺) —— 现在只标 `peg`; 示教 `goal` 点后才有 `hole` 类与"距孔口"量。
5. **val 只有 2 张人工标注** —— 门槛裁决集太薄; 要覆盖不同姿态/光照, 再人工标 100+ 张 (auto 标签永不进 val)。
6. **真机探针还没跑** —— 本机现在不在产线网 (USB 网卡不在, Orin no route to host), 位姿流收不到; 上线后按第六节走一遍即可闭环。
