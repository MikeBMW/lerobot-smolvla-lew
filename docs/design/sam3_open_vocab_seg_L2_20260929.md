## 0. 结论 (一句话)

**SAM3 = L2 感知原语**(能力面, 与 L2-A01 YOLO 检测同级: 从"框"升级到"像素掩膜"、从固定类别升级到开放词汇);
**概念提示词 = L5 的意图**(VLM/人/工单给, 分割算子自己不造概念); **结果 = 叠加规格 origin='seg'**(可视化/元层, 与 sim/vlm/det 并存)。
**不进 L3**(它不产动作、不编排技能序列)、**不进 L4**(它不预测、不规划、不是世界模型; L4 的 INTACT/流形/势场链条不依赖它)。

已落地 (全部真跑过, 见 §5 证据):
`tools/sam3_seg.py`(真执行件) · 常驻服务 `127.0.0.1:8796` · 画布节点 `ss_seg`(L2 第 26 个节点) ·
能力清单 `L2-A14` · 叠加渲染 `kind='mask'` + `origin='seg'` · 推流端点 `/seg` · 场景叠加页按钮「🧩 开放词汇分割(SAM3)」。

### 1.1 权重为什么能拿到 (可复核)

官方 gated 是"要审批+登录"; 镜像仓库是**逐文件复制**。判定不是靠"看起来像", 而是三条硬对照:
① `config.json` 的 `architectures=['Sam3VideoModel']` / `model_type='sam3_video'`, 含 `detector_config`+`tracker_config`+`vision_config(hidden=1024, layers=32, patch=14, image=1008)` —
与 transformers 内置 `Sam3Config` 默认值逐项一致; ② 权重键前缀与 transformers 侧 `base_model_prefix='detector_model'` 完全对应;
③ 落盘后 `sha256` 记录在 `model.safetensors.sha256`, 加载走 `local_files_only=True`(**不再联外网**, 也避免任何"半截文件被当权重"的事故)。

## 2. 分层裁决: 为什么是 L2

判据不是"哪层好听", 而是三样东西: **层契约原文 / 数据流方向 / 收口原则**。

### 2.1 层契约 (`src/lerobot/engineering/levels.py` 原文)
- **L2** `must` 第一条 = `"分段感知(检测/触觉/2D→3D/质量)"` —— 分割正是"分段感知"的字面含义; 且 **L2-A01 已经是 YOLO 目标检测**, 分割与它同类(图像→物体区域), 只是更细(掩膜)更开放(开放词汇)。
- **L3** = `长程序列规划 / 技能编排 / 海马体记忆 / VLM+Flow-Matching 动作输出` ⇒ 分割**不产动作**、**不编排技能序列**, 进来就是越层。
- **L4** = `工作安全(INTACT) / 物理世界导航 / 能力档位 / 标定·流形世界模型 / 势场联络` ⇒ 分割**不预测、不规划、不是动力学**; 放进来会把"感知原语"伪装成"自主内核"。
- **L5** = `场景理解 + 自动标注 / 任务指令解析 / 工程记忆` ⇒ 这一层要放的是**意图与用法**(要什么概念、标注喂给谁), **不是分割算子本身**。

### 2.2 数据流方向 (为什么不能往上放)
分割的输出在**同一帧内**就被用掉: 掩膜 → 掩膜内中位深度 → base 系中心/尺寸(2D→3D 解算) → 视觉引导/势场/收口。
它**不**给 L4 的 `next_obs` 预测喂料, 也**不**给 L3 的 DiT 喂潜动作 ⇒ 把它放 L3/L4 会让"上游层"多一个与自己职责无关的依赖, 时延链还更长。

### 2.3 收口原则 (老倪定的架构红线)
> 上层只给意图/条件, 执行永远由 L2 收口; 可行域逐层收窄。

分割正好把这条原则切成两半, 各归其位:

```
L5 (意图)   : 概念短语 "光模块" / "插孔" / 负框 / 点      ← 人·VLM·工单给, 可审计
L2 (能力)   : 给定这一帧 + 这个条件 → 该概念所有实例掩膜   ← SAM3 真执行, 只管分割
元层/可视化 : origin='seg' 掩膜进叠加规格, 页面可点选/删除  ← 老倪目检的那一层
```

⇒ **裁决: 能力落 L2, 意图落 L5, 结果进叠加(元层)。** L3/L4 不动。
（L5 对它的第二种用法是**自动标注**: 掩膜+深度 → 3D 框 → 监督 L2 检测头 —— 那是 L5 的 `must`"自动标注→监督 L2/L3/L4", 用的是同一个 L2 能力, 不需要把模型搬去 L5。）

## 6. 用途 (为什么值得进状态空间)

1. **场景叠加**: 矩形框换**物体轮廓**, 老倪目检时"框不对"的投诉点直接消失; 掩膜面积/IoU 是比框更硬的核对量。
2. **掩膜 → 3D**: 掩膜内中位深度(抗边缘空洞) × 手眼 × TCP 真值 → base 中心/足印/朝向 ⇒ 喂 2D→3D 解算与势场。
3. **分割 anything = 开放词汇**: 概念来自提示词(光模块/插孔/螺丝刀/人手/线缆…), 换料号**不用重训**, 这是 YOLO 固定类别做不到的。
4. **自动标注(下一步)**: 掩膜 + 深度 → 3D 框 → 监督 L2 检测头; 省掉一次人工框选。
5. **抗干扰**: 把"非目标物"(人手/线缆/托盘边)显式分出来, 给安全闸/势场一个可解释的"这是什么"。
