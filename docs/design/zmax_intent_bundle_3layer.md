# Z-MAX 三层能力整合设计 — 意图丛(Intent Bundle)架构 v1

> 2026-09-10 老倪课题: 参考卡拉比-丘流形 / 纤维丛联络 / 量子场论的"力"(状态间关联), 结合 INTACT
> (INtent-To-ACTion, 无搜索世界模型) 论文, 把 L2/L3/L4 从"各自为政"整合为能力可共享的整体。
> 核心诉求: **L2 已能成功插拔(肌肉记忆原子动作) → 把这份能力作为"基"传递给 L3/L4**。

## 0. 一句话结论

把 L2 固化标杆(champ_u 动作块)当作**纤维丛上的局部截面 / 共享动作基**:
**层间只传"意图向量 Δz", 动作只从 L2 出**。L3 只做"沿任务流形的组合(联络/平行移动)",
L4 只做"曲率大处的势场修正与筹划"。三层共享同一潜在意图空间 → 能力天然可传递。

## 1. 数学骨架(为什么这样分, 每一格都对应真实实体)

| 数学对象 | 系统实体(真实代码/实测) |
|---|---|
| 底空间 B = 任务流形 | 阶段流形(8 段) + 流形坐标 6 维 `progress/risk/V/eta/rem/dperp`; 引擎实测观测 **PCA 2D@95%** → 底空间确实紧致低维(CY 类比的成立条件) |
| 纤维 F | 该段动作块空间 A = R^{4×T}; L2 标杆 `champ_u ∈ F` = 纤维上的**局部截面** |
| 联络 ∇(跨层传输) | L3 的"组合"= 把段 i 的出口截面**平行移动**到段 i+1 的入口(相位/坐标对齐) — 需要"接力契约"(入口/出口状态+夹持相位), 现在缺这个 |
| 曲率 Ω | 接触/插入段 Ω≠0(不可积) → **不可能纯重放**。这正是现有"插入/完成段禁快通道"的数学解释, 不是工程妥协 |
| 势 V / 力 | V=½‖e⊥‖²(接触流形)、½δᵀWδ(性能流形); 动作 u ≈ −∇V + 伺服项 → 层间只需给"势的目标 z_g", 局部力由 L2 解 |

**推论(回答"能力能不能共享"): 能, 且数学上只有"局部截面+联络"可共享。**
端到端大策略在曲率大的 µm 级插拔处没有优势; 经过局部校准的 L2 截面反而是最可靠的动作基。

## 2. 三层分工与同构接口(Z-INTACT 四槽语法)

统一意图语法(三层同产同消, 即 INTACT 的"共享四槽 + 共享参数"落地):

```
goal  : 目标潜在点 z_g (流形坐标/势场目标)     ← L4 产
from  : 当前 z_t + 段 s + 夹持相位             ← 感知层产
skill : L2 技能 id + 参数(seed桶/速度档)       ← L3 产
gate  : 验收度量(mani 6维/位置残差) + 阈值     ← 由 history 校验
```

- **L4(筹划/宏观观察)**: 观测流形 → 出 `goal`(z_g) + 候选技能集; 残差大时出修正。
- **L3(长程规划)**: `goal+from` → 出技能序列(沿 B 的路径 + 接力条件), 以 l3.flows 流程经验做先验。
- **L2(执行)**: `skill id` → 动作块直出(现有 champ 快通道, <1ms)。

层间只传 `Δz = z_g − z_t`(对应 INTACT: 物理意图 `z_{t+1}−z_t` 在 L2 内部, 目标意图 `s_g(z_g)−z_t` 在层间)。
→ **动作只在最底层生成一次**(单一共享算子), 上层不做动作搜索 = 无 CEM、无 test-time search。

## 3. 能力共享三机制(逐条落地老倪诉求)

| 机制 | 内容 | 对应现有代码的差距 |
|---|---|---|
| **M1 L2→L3 组合调用** | 技能补 `io` 契约(entry/exit 状态+相位+度量); L3 推理先用 champ_u 作**先验动作块**(INTACT Direct 条件均值), 仅 gate 不过时用 ≤384 候选校正 | 现无 io 契约; L3 推理无 L2 先验 |
| **M2 L2→L4 动作基** | 离线生成技能词典 `{skill → Δz_预测}`(由 champ_x 差分); L4 预测 Δz 后**kNN 直读技能**, 不在连续动作空间搜索 | 无技能词典; L4 目前只预测流形量、未驱动技能选择 |
| **M3 L4→L2 更新** | L4 残差超阈/卡阻 → 发 `rechampion` 事件(标准动作重固化: 最近成功轮融合 α=0.3, 已存在; 或重置桶) + 写 l4.recover + links | 无 rechampion 通道; 记忆三层是**并列记录**, 无层间链接(各自为政的根因) |

## 4. 落地切片(依赖序, 每片独立可验证)

- **S3 L3 先验条件化**: smolvla_lew 推理管道加"L2 先验动作块 + gate 校验" — **影子模式先行**(只记录不接管)。
- **S4 L4 直读 + rechampion**: 引擎 L4 档接 recall/kNN 直读; rechampion 先影子。
- **S5 画布**: L2/L3/L4 记忆节点加跨层连接通道(links 数 / recall 命中 / 直读延迟), 中枢显示直读命中率。

## 5. 验证(红线优先, 诚实打点)

1. **回归红线**: L2/L4 插拔成功率**不得回退**(SS_MUSCLE=0 基线对比)。
2. **新能力量化**: ①L3 用 L2 先验 vs 从零 — 成功率/步数/所需训练 epoch; ②L4 技能直读命中率 + 延迟(目标 <10ms, INTACT 实测 2.9–5.5ms); ③抗干扰 90° 布局成功率增益。
3. **不达标如实标注**, 不声称"突破"。

## 6. 风险与边界

- 曲率大段(插入)禁止纯重放 → 只做"先验 + 现场校正", 且影子模式先行。
- 视觉域(R1)有标杆失配历史(SS_MUSCLE=0 才成功) → 先只在 R0/确定性域启用共享, R1 待视觉稳定再放开。
- 意图检索负迁移: `recall` 必须带距离门(相似度不过阈不命中), 布局差异大时退化为无先验。
