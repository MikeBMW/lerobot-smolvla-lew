# Z700 R MPV 模型能力架构 (v2.0)

> 2026-08-19 · 设计: 静静 · 输入: R MPV Z700 产品全景方案书

## 一、总体架构（四层，对齐产品方案书）

```
┌────────────────────────────────────────────────────────┐
│ L0 任务规划层    多机台·多车协同调度 · 场景编排           │
│                    (跨工位流转任务 · 多车分配)           │
├────────────────────────────────────────────────────────┤
│ L1 技能编排层    作业阶段编排 · 原子技能库 (200项)        │
│                    (接近→抓取→翻转→对位→插入→检测→分拣)   │
├────────────────────────────────────────────────────────┤
│ L2 模型决策层    作业执行能力 + 预判引导能力              │
│                    (模型节点可替换: 作业模型/引导模型/    │
│                     编排模型/感知模型/第三方)            │
├────────────────────────────────────────────────────────┤
│ L3 感知执行层    感知认知 · 作业执行 · 移动流转           │
│                    (视觉/力觉/触觉 · 臂/夹爪 · 基座/立柱) │
└────────────────────────────────────────────────────────┘
```

## 四、标准接口（三层接口契约）

### 4.1 模型接口（L2 决策层 · 模型可替换）
| 接口 | 用途 | 信号 |
|---|---|---|
| 观测输入 IN | 多维观测接入 | 关节状态 + 视觉 + 力觉 + 触觉 (按模型组合) |
| 动作输出 OUT | 作业动作下发 | 空间平移 (x/y/z) + 夹爪开合 + 姿态 |
| 引导输出 GUIDE | 预判结果下发 | 下一状态预测 + 接触概率 |
| 阶段调制 MOD | 作业阶段切换 | 阶段状态 + 调制后动作 |

### 4.2 系统接口（L3 感知执行 · 对接硬件）
Modbus TCP · CAN · USB3.0 · HDMI · 千兆网口 ×2 · WiFi6 / 5G 可选

### 4.3 平台接口（L0/L1 · 对接产线与平台）
数据采集 SDK · 边缘网关 (断点续传) · MES 对接 · 训练平台 API · 大屏指标上报

## 五、模型节点（可配置 · 可替换 · 非技术表达）

| 节点 | 能力组合 (Manifest) | 说明 |
|---|---|---|
| 作业执行模型 | B·C·D 域能力 | 完成从看到做的完整作业 (方案书: 动作模型 <70ms) |
| 预判引导模型 | D1·D2 | 预判过程走向, 提前引导 (方案书: 引导模型) |
| 作业编排模型 | C1·D3·G2 | 阶段编排与决策说明 (方案书: 状态机 8 阶段) |
| 感知模型 | B 域能力 | 识别/定位/检测 (第三方可换) |
| 第三方模型 | 自定义组合 | 注册 Manifest + 适配器即接入 |
