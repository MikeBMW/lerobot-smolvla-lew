# 🏭 Z-MAX 精细操作场景需求 + 调制动作技术指标监督方案
> 版本: v2.0.0 · 2026-08-10 · 关联: left_right 双脑策略技术方案 (docs/left_right_policy.md)
> 依据: 工厂实际工艺 (factory-3d.html 储翰工厂多区域场景) → 产品大屏严格监督 (factory-dashboard.html)

## 一、背景：从 39D 状态机到工厂精细操作

left_right 双脑策略的核心能力：
- **39D 观测**: 末端位置(3)+夹爪(1)+工件位姿(7) ×2帧 + 目标位(3) —— 对应工厂里"机器人手 + 夹爪 + 物料 + 工装/治具目标位"
- **8 状态机调制**: 接近→对位→下降→抓取→抬起→转移→插入→完成 —— 对应工厂精细操作的完整动作链
- **动作调制输出**: 每个阶段按规则改写动作（偏置接近/夹持锁定/速度自适应/力控插入）

工厂实际工艺（factory-3d.html ZONES 工位）的精细操作全部落在**"搬运-对位-插入-压合"**四类动作上，
与状态机的"接近-对位-抓取-转移-插入"一一对应。本文把状态机的每个调制阶段翻译成
**可监督的技术指标**，并在 factory-dashboard.html 大屏上逐机器人逐动作实时监督、记录。

## 二、精细操作场景需求（6 大场景）

### 场景 1 · WB 金线键合连板上料/出料 (OE区 I152 · Z700F+AOI)
| 项 | 内容 |
|---|---|
| 工艺步骤 | 料笼取下连板 → 进连板 → 打线(193根金线) → 出连板 → 显微镜检100% |
| 机器人动作 | 连板搬运 + 治具导轨插入/抽出 |
| 状态机映射 | 接近(料笼取板) → 抓取 → 抬起 → 转移(至键合机) → **对位(治具导轨) → 下降 → 插入(连板进治具)** → 完成 |
| 39D obs 内容 | 末端位姿 + 夹爪开度 + 连板位姿×2帧 + 治具导轨目标位 |
| 调制动作指标 | 接近收敛 d≤0.06m · 对位误差 ≤0.3mm · 插入力 ≤5N · 节拍 ≤6s · 成功率 ≥99.5% |

### 场景 2 · DA 芯片贴装上下料 (OE区 I136/I140/I145 · Z100L)
| 项 | 内容 |
|---|---|
| 工艺步骤 | 连板识别 → DA贴片(PIC/TIA/PD/COC) → 出料退至料盒 |
| 机器人动作 | 料盒取料/放料（托盘插拔）+ 连板流转 |
| 状态机映射 | 接近(料盒取料) → 抓取(托盘) → 抬起 → 转移 → 对位 → 下降 → 插入(料盒槽位) → 完成 |
| 调制动作指标 | 接触判定 contact>0.5 · 抬升 +8cm±2mm · 转移到位 ≤5mm · 插入到位 ≤0.5mm · 节拍 ≤4s · 良率 ≥99.8% |

### 场景 3 · LD Lens AA 耦合 (OE区 I171 · Z700)
| 项 | 内容 |
|---|---|
| 工艺步骤 | 拿取物料上设备 → 接电启动 → **耦合程序(六轴主动对准)** → 取下放置 |
| 机器人动作 | 透镜取放 + AA 耦合主动对准（全厂最高精度动作之一） |
| 状态机映射 | 接近 → 抓取(lens) → 抬起 → 转移(至耦合台) → **对位(AA耦合 ±1μm) → 下降 → 插入(耦合工位)** → 完成 |
| 调制动作指标 | **对位误差 ≤±1μm(AA)** · 下降到位 ≤0.2mm · 接触力 ≤2N(力控) · 节拍 ≤10s · 成功率 ≥99.5% |

### 场景 4 · PEI Cover 组装 (OE区 I155 · Z700F+AOI)
| 项 | 内容 |
|---|---|
| 工艺步骤 | 料笼取下连板 → 手动点胶(3处) → **cover 安装(压合)** → 目检 → 装回料笼 |
| 机器人动作 | Cover 压合插入（插销式装配，最接近 peg-insert 的工艺） |
| 状态机映射 | 接近 → 抓取(cover) → 抬起 → 转移(至连板) → **对位(销孔) → 下降 → 插入(压合到位)** → 完成 |
| 调制动作指标 | 对位误差 ≤0.5mm · **插入深度到位(±0.1mm)** · 压合力 ≤10N(力控) · 节拍 ≤15s · 良率 ≥99.9% |

### 场景 5 · 隔离器贴装 (OE区 I159 · Z700F+AOI)
| 项 | 内容 |
|---|---|
| 工艺步骤 | 手动点胶左(胶水T16) → 安装隔离器左 → UV固化(10s) → 点胶右 → 安装隔离器右 → UV固化 |
| 机器人动作 | 微型件拾取-放置（Pick & Place） |
| 状态机映射 | 接近 → **抓取(接触判定)** → 抬起 → 转移 → **对位(胶面) → 下降 → 贴装(力控放置)** → 完成 |
| 调制动作指标 | 拾取接触 contact>0.5 · 放置对位 ≤0.2mm · 贴装力 ≤2N · 节拍 ≤20s · 良率 ≥99.7% |

### 场景 6 · COC 绑定/共晶 (COC区 I113/I115 · Z700)
| 项 | 内容 |
|---|---|
| 工艺步骤 | 绑定固晶 ±1μm / AuSn 共晶 280°C 温控, 空洞率<5% |
| 机器人动作 | 亚微米对位 + 压合（全厂最高精度，±1μm 级） |
| 状态机映射 | 接近 → 抓取(COC) → 抬起 → 转移 → **对位(±1μm) → 下降 → 压合(力控+温度联动)** → 完成 |
| 调制动作指标 | **对位误差 ≤±1μm** · 压合力 力控曲线 · 共晶温度 280°C±1°C · 节拍 ≤8s · 良率 ≥99.9% |

## 三、调制动作技术指标体系（8 状态 × 可监督指标）

left_right 状态机的每个调制阶段 = 一个可监督动作段，指标实时采集、逐动作记录：

| 阶段 | 调制动作 (来自 left_right) | 监督指标 | 目标值 (通用) | 记录字段 |
|---|---|---|---|---|
| 接近 APPROACH | `act×0.3 + 偏置×2` | 收敛距离 d_hp · 接近时间 | ≤0.06m · ≤1.5s | d_hp, t_appr |
| 对位 ALIGN | xy 对齐 | 对位误差 e_xy | ≤0.5mm (精密≤1μm) | e_xy |
| 下降 DESCEND | 朝目标下降 | 到位精度 e_z · 下降速度 | ≤0.2mm · ≤0.5m/s | e_z, v_desc |
| 抓取 GRASP | `act×0.1` + 夹持 0.6 | 接触概率 contact · 夹持力 · 抓取成功 | >0.5 · 0.6±0.05 · 是/否 | contact, grip_f, ok |
| 抬起 LIFT | `[0,0,0.8]` | 抬升高度 Δz · 抬升时间 | +8cm±2mm · ≤0.5s | dz, t_lift |
| 转移 TRANSFER | 速度自适应 0.6/0.35/0.15 | 转移时间 · 到位偏差 · 速度曲线合规 | ≤2s · ≤5mm · 分级正确 | t_xfer, e_xy2, v_profile |
| 插入 INSERT | 下降插入 | **插入深度 · 插入力 · 完成判定** | 到位±0.1mm · ≤力阈值 · d<0.05 | d_ins, f_ins, done |
| 完成 DONE | 保持 | 保持稳定 · 阶段节拍 | 无漂移 · 按工艺 | hold, t_done |

**场景级指标**（每次动作完成汇总）: 节拍(s) / 成功率(%) / 良率(%) / CPK / 质量门通过。

## 四、产品大屏严格监督方案 (factory-dashboard.html 扩展)

### 4.1 现状缺口
大屏现有: 机器人卡(速度/节拍/负载/温度) + KPI(OEE/节拍/良率/告警) + AGV。
**缺口: 无动作级指标** — 不知道每个机器人当前在做什么动作、动作指标是否达标。

### 4.2 数据模型扩展 (机器人卡)
```javascript
{ id: 'R3', name: 'R3', type: 'Z700', zone: 'oe', status: 'running',
action: { // ← 新增: 当前动作
stage: 'INSERT', // 状态机阶段: APPROACH/ALIGN/DESCEND/GRASP/LIFT/TRANSFER/INSERT/DONE
scenario: 'PEI-Cover-组装', // 场景名 (场景1-6)
metrics: [ // 该阶段监督指标实时值
{ k: 'd_ins', name: '插入深度', v: 0.02, unit: 'mm', target: 0.1, pass: true },
{ k: 'f_ins', name: '插入力', v: 7.2, unit: 'N', target: 10, pass: true }
],
pass: true, // 本动作全部指标达成?
lastFail: null // 最近未达成项
},
actionLog: [ ... ] // 历史记录: {ts, stage, scenario, metrics, pass}
}
```

### 4.3 数据接口 (API)
```
GET /api/robot-action?robot=R3&zone=oe
→ { stage, scenario, metrics[], pass, ts } # 实时动作指标
POST /api/action-log # 动作完成记录 (监督留痕)
{ robot, stage, scenario, metrics[], pass, ts }
GET /api/action-log?robot=R3&date=today # 查询记录 (导出/追溯)
```
数据源: 机器人控制器 (left_right policy 推理时同步上报) 或 MES 中间库。
演示模式: 大屏内置模拟器 (同现有 setInterval 刷新), 字段齐全可接真机。

### 4.4 大屏展示设计 (每机器人卡)
```
🤖 R3 [Z700] ●运行中
当前动作: 插入 (PEI-Cover-组装) [状态机 7/8]
┌─ 动作指标 ─────────────────────┐
│ 插入深度 0.02/0.10mm ✅ │
│ 插入力 7.2/10.0N ✅ │
│ 完成判定 d<0.05 ✅ │
└───────────────────────────────┘
速度 1.8件/min · 节拍 33s · 负载 42% · 温度 42°C
```
- 指标值 vs 目标: ✅绿(达标) / ⚠️黄(临界>90%目标) / 🔴红(超标)
- 单指标超标 → 卡 warning; 连续 3 次或关键指标(插入深度/力)超标 → alarm + 记录
- 每个动作完成后追加 actionLog 一条 (可点开看时间线)

### 4.5 监督记录 (留痕)
- 每次动作完成 → POST /api/action-log (robot/stage/metrics/pass/ts)
- 汇总指标: 各场景成功率 / 各阶段达标率 / 每机器人节拍分布 / 超标动作 TOP 榜
- 导出: CSV (MES 对接) ; 周报自动生成

### 4.6 告警规则
| 级别 | 条件 | 动作 |
|---|---|---|
| warning | 单指标 > 90% 目标 或 单次未达标 | 卡变黄 + 记录 |
| alarm | 关键指标(插入深度/力/对位)超标 或 连续3次未达标 | 卡变红闪烁 + 告警列表 + 建议停机检查 |
| 恢复 | 指标连续 5 次达标 | 自动解除 (记录恢复时间) |

## 五、实施计划

| 阶段 | 内容 | 产出 |
|---|---|---|
| P0 (本方案) | 场景需求 + 指标定义 + 监督设计 | 本文档 + 帮助文档菜单 |

每个阶段结束时把实际量测 (d_hp/contact/peg_z/插入深度/力) 写入 `self.metrics` dict,
推理循环每 N 帧经 API 上报 → 大屏实时监督。仿真先跑通 (metaworld 实测指标),
真机 (Z700/Z700F) 换力传感器读数。
