# 已证伪旋钮登记表 (别再重试; 2026-09-15 汇总)

## 用途
本项目一半以上的算力浪费在**重试已被证伪的旋钮**。试任何新参数/新策略前先查本表。
纪律: 每条证伪都要 (a) 留下实测数字 (b) 旋钮**默认关/默认不动**, 只作选项保留
(c) 叠加验证 (单测有效的旋钮组合后可能失效甚至回退)。依据: 老倪红线"未证明提升不得进默认档"。

## 表 (按类别)

| 旋钮 / 策略 | 试法 | 实测结果 | 默认 |

## 交叉引用
- 滑移类的更早三条证伪 (GRIP_CLOSE / 运动限幅 / "滑移时重夹") 见 SKILL.md **⑫**。
- 螺旋搜索本身**不是**证伪项 —— 它是 ⑬ 提出的正确方向, 只是"扩参数"没用; 遇阻先螺旋、再回退的
  行为保留。
- 失败先分类再决定杠杆: 若失败是**闭环死循环** (回撤→重对孔→同偏差再顶住), 阈值类旋钮天然无效 →
  转结构性改动。见 `paired-ab-and-noise-control.md` §④。
