# R1 视觉定标结论 (probe_r1_calib.py, 2026-09-04)

5 个夹爪位形 × render→detect_3d, 对比 YOLO 输出 vs metaworld 物理锚。

## YOLO 检测质量矩阵 (同机同模型, peg_v1 检测 + peg_depth_v1-2 深度)

| 目标 | 可用性 | 实测误差 | 结论 |
|------|--------|---------|------|
| hand | ❌ 不可用 | 位形2/3(夹爪贴近销)错位 12-20cm | 遮挡/重叠时检测崩, 不能作控制锚 |
| peg (来料) | ✅ 条件可用 | 悬停高位(z>6cm) 7-17mm; 贴近 2cm 内 26-48mm | 悬停刷新 + 下降冻结 |
| hole | ❌ 不可用 | 全程 6-37cm 漂移 | 不参与控制, 仅统计 |

## 真机同构架构结论 (比成功率更值钱)

1. **hand 必须走编码器** (obs[0:3]): 机械臂末端有编码器, 视觉只定位工件 —
   真机不会用视觉闭环末端位置。R1 实现: hand=obs 真值, 视觉只管 peg/hole。
2. **插入工位固定 → 一次标定** (每轮现场采样 = 产线安装标定), 不做每帧视觉。
3. **peg (来料随机) = 唯一视觉任务**: 悬停位拍照 + EMA 平滑 + 跳变保护。

## R1 感知实现细节 (state_space_sim_real.py --vision)

- 刷新条件: 未夹持 && (peg 未定位 || step%vision_every==0 && hand_z > 0.09)
  (遮挡是**垂直接近**造成的 → 用垂直高度判定刷新区, 不用水平距离; 首次 0/6 卡下降
  即因水平条件在"手悬停销正上方"时不刷新 + 视觉 z 偏低)
- EMA: vis_peg = 0.5*new + 0.5*old, 单帧跳变 >5cm 丢弃 (peg 噪声 ±1-3cm → ~1cm)
- 夹持后销位置 = 编码器 hand + 锁存偏移 (真机无视觉跟销); 视觉 peg 仅"未夹持"时用
- **视觉反投影 z 偏低 ~1.5cm** (深度 scale) → at_grasp_pose 禁用视觉 z 阈值,
  改**下降物理停滞**: hand z 连续 ≥8 帧位移 <0.4mm = 被销/台顶住 → 抓握位 (0/6 实锤)
- hole_off = goal−孔口 现场偏移 (模拟 CAD 已知孔深) — 但最终 hole 控制走工位标定,
  视觉 hole 仅统计 (检出率 100% 但坐标 6-37cm 漂)

## RealityGap 量化

- R0 真值感知: 5/8 = 62%
- R1 视觉工件 (peg 视觉 + 工位标定孔): 3/6 = 50%
- 视觉定位误差成本 ≈ 12%; 成功轮 315-329 步与 R0 同量级 → 链路可行

## 抓取对准的视觉专用修法 (R0 基础上)

- 抓取对准目标用**冻结的悬停视觉 peg** (下降期不刷新, 防幻影追飘)
- 回退重抓: 强制回退 stage 0 后夹爪张开悬停, peg 掉回台面,
  hand_z>0.09 刷新条件自动重新定位被碰移的销
- 失败主因仍是 peg 水平误差 ~3cm 超夹爪容差 (±3.5cm) 的布局 → 多帧 EMA 缓解
