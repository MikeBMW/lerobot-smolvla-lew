## 1. ⚠️ 自检阈值必须与"运算次数"匹配 —— 红了先怀疑阈值，别先怀疑数学

**血案经过**：为新写的流形视图做纯数学自检，8 项里 2 项红：

```
❌ U·U⁻¹ = I          （阈值 1e-9）
❌ FS 自距离 = 0       （阈值 1e-9）
```

第一反应是"SU(2) 实现有 bug" → 深挖（打印真实残差 + 读 `__mul__`/`inv` 源码）：

```
(u*u.inv()).theta   = 2.98e-08      ← 不是 0 的只有浮点量级
u.distance_fs(u)    = 1.49e-08
purity(u*u.inv())   = 1.000000
__mul__ = 标准哈密顿四元数积 ;  inv = 共轭四元数   ← 教科书实现，正确
⇒ **是我的阈值(1e-9)过严，不是代码错。**
```

**结论 / 规则**（照抄进任何群公理自检）：

| 检查类型 | 合理阈值 |
|---|---|
| 单步构造、取模、|w|、‖r‖ | `1e-15 ~ 1e-12`（实测 ≤1e-15）|
| **多次群乘/求逆后再比较**（U·U⁻¹、FS 自距离、剥离残余）| **`1e-6`**（float64 经数次乘/逆的合理残差）|

- 自检红了 → **先 `print` 真实残差量级**。若在 `1e-8` 量级 = 阈值问题；若在 `1e-2` 量级 = 真 bug。
- 别把"仅在被测对象退化时才失效的断言"当判据（同源教训：见
  `mixture-of-experts-architectures/references/README-FIRST-stale-content-corrections.md`
  里"某专家独占 → 对应率假通过"）。

## 2. 把结构化流形搬进训练/部署控制台（完整通路）

用户要求："训练控制界面要能看到模型训练的结构化流形"，且**每句代码真实可 debug**（不许装饰）。
可复用通路（实现在 `tools/manifold_train_view.py`，全部由真实代码驱动）：

```
引擎真跑 rollout
   ↓ trace(列式 dict, 每步一列)
frame(行式 dict)  ← 字段映射, 缺项置 0（与 encode_layer 契约一致, 不编造）
   ↓ su2.encode_layers(frame, obs43=...)
{层: SU2Element}
   ↓ compose_scene / peel_layers / commutativity_matrix / fs_distance_matrix
结构化流形 JSON
   ↓ GET /api/manifold
控制台面板（θ(t) 曲线 + 各层 θ 条 + 层间耦合 + FS 距离）
```

**本仓库引擎 trace 的真实字段名**（写 frame 时照抄）：

```python
TRACE_TO_FRAME = {
    "mani_progress": "mani_progress",   # L3 流形进度 e∥
    "mani_dperp":    "mani_dperp",      # L3 法向偏离 e⊥
    "mani_rem":      "mani_rem",        # L3 剩余插入深度
    "u_sat":         "u_sat",           # L4 限幅后动作范数
    "contact_p":     "contact_p",       # L4 接触概率
    "mani_eta":      "mani_eta",        # L4 性能流形达成度 η
}
# L5_intent 引擎里 **不存在**(0 处) → 不给该字段 → encode_layer 返回单位元
#   = 诚实标注"L5 未接入 LLM", 不要编造意图数值
```

**L2 必须是真通路，否则恒为单位元**（踩过）：
```
encode_layer("L2", ...) 需要 obs43; 只传 frame 不传 obs43 ⇒ L2 = 单位元
真值取法: obs43 = su2.obs43_geometry(引擎的 obs)   # → peg_head − hole 几何误差
   实测首帧 e = [-0.06112, -0.5201, -0.08866]（有量级 = 通了）
```

**实测产出（240 步，全部为真实调用结果）**：
```
θ 统计: min 1.687 · max 2.746 · mean 1.870 · std 0.241
末帧各层 θ: L2 0.188(检测) · L3 0.846(调度) · L4 2.542(认知主导) · L5 0.0(未接, 诚实)
层间耦合: L3|L4 **0.5618**(最强) · L2|L3 0.1424 · L2|L4 0.1142   ← 调度↔认知强耦合
FS 距离: 首→中 0.323 · 首→末 0.671 · 中→末 0.549（单调演化）
```

## 3. 又一个"部分打印 → 假结论"的坑

调试耦合矩阵时我打印了 `list(coupling.items())[:6]`，看到**全是 0.000000**，
一度以为"层间无耦合 / 代码坏了"。实际那 6 项恰好是 `L2|*` 与 `L3|L2/L3` ——
**L2 当时是单位元**（没传 obs43），参与的对自然恒 0。

```
⇒ 规则: 看矩阵/分布时**必须打印全量或过滤非零**, 不要 [:N] 截断后下结论。
   正确姿势: {k:v for k,v in m.items() if v > 1e-9}
⇒ 同族教训: 与 ④对应率假阳性、FS 阈值假失败 一样, 都是
   "被观测对象的退化恰好让某个弱判据看起来通过/失败"。
   凡下结论前先问: **这个退化情形会不会让我的判据给出反信号?**
```

## 4. 控制台接线要点（零依赖、可复制）

```
· 单文件标准库 http.server（不用 Flask）→ 可复制/可运维, 无依赖漂移
· GET /api/manifold → 直接吐 JSON（APP 也能直接取, 不必解析 HTML）
· 面板: canvas 画 θ(t)、div 条形画各层 θ、pre 画耦合矩阵
· **L5=0 必须在界面上写明"未接 LLM"** —— 诚实标注是这一类可视化的硬要求
   (否则看板会让人以为"大模型层在工作")
· 若流形数据缺失, 面板显示"尚无数据 → 跑 <生成脚本>", 不要显示假曲线
```
