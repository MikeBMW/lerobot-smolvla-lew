# 真机人机在环示教 (Human-in-the-Loop Robot Teaching)

适用: 操作员在现场、机械臂不能自主跑完整任务，agent 逐步下发单条动作、由人把关安全并逐步示教点位。
首次完整打通: 视觉伺服对准 → 合爪 → 抬升验证 → 回槽位放料 (2026-09-19, 协作臂+臂上相机+电动夹爪)。

## 1. 作业纪律 (红线，先读这条)

- **每条动作前逐条请示**，拿到明确"可以"才发；**一次只发一个单步**；发前发后都取证 (关节/TCP/状态/画面)。
- 现场口径: 「要保证安全，不要做没有把握的事情。不要损坏机器人。」
- 动作要**慢**且**肉眼可见**: 1° 手腕 = TCP 0.43mm，操作员会说"太小没看清" → 演示步用 5°/10mm 量级。
- **顺序纠正 (逐字)**: 「要先向后退，再放回槽位」⇒ **不在插入位直接下降**。
  放料顺序 = 先退 → 到槽位 → 下降 → 张爪 → 抬起。
- **方向表述**: 操作员面板常显示**180° 翻转帧**，agent 用的是原始帧。
  同一目标: agent 帧"上左" = 用户帧"下右"；检测模型按未翻转帧训练 (翻转后 conf 掉一半)。
  ⇒ **报方向一律说"朝画面中心 / 远离中心"** (两视图共同的不动点)，避免"左/右/上/下"歧义。
- 操作员喊停/接管 (drag 模式) 时 **立即停发一切指令**，改只读观察，等其交接。

## 2. 下电机制 (操作员最烦的点，提前预告)

| 路径 | 动作后 servo | 用法 |
|---|---|---|
| 相对关节 (rt 实时路径) | **被驱动主动下电** | 每步前要示教器上电；SDK 无上电服务 → 少用 |
| 绝对关节 move_joint | **仍 on** | **自带上下电流程** ⇒ 连续动作优先 |
| 绝对笛卡尔 move_line/move_pose | **仍 on** | 单轴平移/抬升首选 |

⇒ 发动作前主动说明"这条之后可能下电，属正常"，别让掉电变成"莫名其妙"。

## 3. 超时不重发 (血亏教训)

`success=False` + `error_code=ROBOT_IDLE_TIMEOUT`("wait_until_idle: timed out after 30.0s")
**但动作其实已精确到位** (实测 z 目标 0.20840611 → 实到 0.20840644，误差 0.33µm)。
判完成只看 **真值(关节/TCP) + operation_state=idle**；**绝不因 success=False 重发** (会叠成 2 倍位移)。

## 4. 可达性与单轴原则

保持姿态的**斜向大跨步** (如 -93mm X 同时 -169mm Y) 会被拒:
`error_code=-50002 「目标点超出运动范围, 或为奇异点」`，且**一步没走** (安全)。
⇒ 横向/纵向**分开单轴小步**；某轴到边界 (再走同向被拒) 时，改用**基座回转 (J1 微转)**做等效横向。

## 5. 每步前清错

`has_error` 是**驱动侧**标志，示教器清报警**不一定**清掉它 ⇒ 带着它发动作会再被拒。
用无运动的复位服务 (如 `std_srvs/Trigger` 的 recover/estop-recover) 清，然后再三查:
`power_state=on` + `operation_state=idle` + `has_error=false`。

## 6. 视觉伺服常数 (量一次即可复用)

```
基座 -X → 画面 ↓ ≈1.05 px/mm      基座 +Y → 画面 ← ≈1.12 px/mm
基座 +X → 画面 ↑ ≈1.07 px/mm      (对称性自检: 两次独立测量差 ~2%)
交叉验证: fx(px) ÷ 增益(px/mm) ≈ 相机-目标距离 ✓
```
用法: 把"目标在画面里的像素误差"换算成基座位移，**分步迭代** (增益随视角变化，别一次跨太大)。

## 7. 夹爪 (电动夹爪 srv 类接口)

- 字段: `target_pos`(0~200, 0=全合) · `speed/force/acc/push_*` (`-1`=保持现值)
- **srv 只回开度，没有力反馈** ⇒ agent 读不到当前夹持力，要**如实说读不到**，别编数值。
- `force=-1`(默认力) 往往只合到 250~311 (操作员会说"有间隙、没夹住")；
  **显式给 `force=40` → 合到 185 = 夹牢** ✓ (空载全合 = 21) ⇒ 力的量纲/有效值因夹爪而异，需现场试出"夹牢开度"。
- 一次从全开直接命令 0 可能不动 ⇒ **分步给值** (1000→400→100→0) 更可靠。
- **拖动模式 (operation_state=drag) 下夹爪指令可能被完全忽略** ⇒ 先切回 idle/自动再合爪。
- 夹爪是独立控制盒，**不影响机械臂供电**。

## 8. 抓取验证判据 (不靠"看起来像")

- **抬升前后开度不变** (185 → 185，抬升 100mm 并返回) ⇒ 未滑移 = 夹牢 ✓；掉回 ~21 ⇒ 已脱落 ✗
- 图像侧只作辅助: 相机装在夹爪旁、镜头朝下 ⇒ **夹爪本身常在视场外**，
  无法从图像确定"夹爪像素" ⇒ "把目标对准画面中心/夹爪像素"不可靠，
  改用**人工示教位姿** + 视觉伺服到该点。

## 9. 示教点位落档 (供后续复用)

`data/points/<工件>_槽位与插入位_<日期>.json`:
`slot_pick_place`(抓取=放回点) · `pre_insert`(即将插入位姿) · `grasp_recipe`(开/夹紧/软夹/空载值/验证结论) ·
`motion_recipe`(单步目标/速度/教训)。`data/` 常被 .gitignore ⇒ 同时 `docs/teach/` 放一份入库。
操作员说"记住这个位置"时 ⇒ **当场读实时位姿落盘 + 回声确认**，别等动作做完再补。

## 10. 重记已有点位 (操作员说"位置不对/偏移了, 我挪一下你记录")

**只读采样, 全程不下发任何运动。**
1. **先备份点位库**: `cp data/skills/l2_atomic/taught_points.json ~/zmax_data/taught_points_backup_<ts>.json`
   —— 回滚就是一条 cp 反向拷回; 没有备份就不要改。
2. 操作员挪臂到位 → 跑仓库自带记录器: `./gui-venv311/bin/python tools/record_l2_point.py <点名> "<说明>"`
   (只读 `/robot/tcp_pose`, 经本机 Docker tap 容器 `ss-remote-tap` + `ROS_DOMAIN_ID=0`, **采样 6 帧取均值并报极差**)。
3. **臂还在动时它一定拒记** (判据: pos 极差 ≤1e-4 m)。现场挪动要几十秒 ⇒ 手点一次看到"拒绝"不是故障,
   挂轮询等停稳:
   `for i in $(seq 1 30); do out=$(…record_l2_point.py <点名> "<说明>" 2>&1); echo "$out" | grep -q 还在动 && { sleep 8; continue; }; echo "$out"; break; done`
4. **回声确认 + 三代对比**才算交付: 打印 旧值/中间版/新值 的 `|Δ|mm` 与姿态夹角 (`2·acos|q1·q2|`, 点积先取绝对值判同向)。
   现场说"偏移了"时, 这个差量就是验收口径 (典型量级: 几毫米 + 几度)。
5. 版本化: `data/` 常被忽略或是外链符号目录 ⇒ 把**新旧两份**点位快照拷进已跟踪的 `reports/` 一起提交,
   提交用**路径限定**形式 (`git commit -m … -- <只有我的路径>`), 别 `git add -A`。
   ⚠️ 路径限定提交**只对已跟踪路径生效**: 新增的快照文件必须先 `git add`, 否则报
   `pathspec … did not match any file(s) known to git` 且**什么都不会提交**(看着像失败但容易漏掉);
   另外别用 `git add -A` 扫全仓 —— 仓里常有别的会话/工作流的暂存改动, 会被一起带走。

坑:
- **技能目标点不在技能定义里, 在点位库里**: 技能带 `point_locked: true` 时目标点只认库里那个名字 ⇒
  **改点位库 = 改技能目标**, 不用碰技能定义。
- **改点位库不用重启执行器**: l2_daemon 每次执行技能都 `_load_points()` 重读 ⇒ 热生效;
  但**改 daemon 自身代码必须重启**(脚本改动不热加载)。
- **两次独立采样给出同一位姿 (差 ~0.02mm / 姿态 0°) 是好证据** —— 说明臂确实没再动;
  只测一次无法区分"臂没动"和"采到了旧值", 交付时要说清这一点。
- 记录的是 **TCP 位姿** ⇒ "对不对"取决于记录时刻的夹爪/工件状态(夹着工件与空载的 TCP 偏置不同);
  现场说"位置不对"时先确认是**带工件还是空载**记的。
- 记完提醒: 臂就在点上时距离守卫会**通过** ⇒ 技能会**真动** (阶段1 到正上方 → 阶段2 下降),
  让人在旁边看着、急停用示教器。
