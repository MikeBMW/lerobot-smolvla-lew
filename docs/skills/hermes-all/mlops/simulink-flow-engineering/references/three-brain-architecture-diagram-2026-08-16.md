# 三脑架构图 + 快慢通道 (2026-08-16) — 分层递阶控制绘图

## 用户方案 (老倪给的 Mermaid)

三脑架构 = 分层递阶控制 + 数据流闭环, 自左到右: 输入 → 并行处理(快慢通道) → 决策融合 → 输出 → 反馈校准:
- 第一步 时空感知前端: 传感器融合(RGB-D+力觉+触觉) → 43D 统一状态向量
- 第二步 并行处理层(快慢分离): 前馈加速器(左脑MLP, ~5ms, 金色) / 自适应状态估计器(右脑GRU, ~15ms, 蓝色, 内部拆 先验预测器+创新检测校正器)
- 第三步 认知决策层(握有否决权): 认知任务调度器(状态机, 红色六边形) → 安全执行边界(饱和限幅)
- 输出: 执行器 → 物理世界; 反馈闭环: z_k → 创新检测, 校正后潜状态 → 先验预测器 (红色虚线)
- 要点: 调度器只读前馈输出(u_ff 权重30%), 不改 MLP 权重; 反馈标注"预测误差"非"误差梯度"

## 快慢通道数据流 (述职用)

快速通道(前馈加速器): 直连 43D 状态 → 神经网络硬算 ~5ms → 建议动作
慢速通道(自适应状态估计器): GRU 循环 + 力觉反馈 ~15ms → 接触概率 + 阶段判定
两通道在认知任务调度器汇合 → 安全执行边界 → 物理指令 → 反馈 z_k 回创新检测 (卡尔曼闭环)
