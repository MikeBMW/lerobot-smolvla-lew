# 口径同源评估纪律 (same-source evaluation)

## When to Use
- 给一个训好的模型/策略/预测头出"成功率/提升"，尤其是结果好得不真实 (**数字 0%** 或 **1/1=100%**)。
- 有人说"模型没效果"时, 先怀疑评估口径, 再怀疑模型。
- 要把训练产物接进在跑的系统 (仿真闭环 / 真机闭环 / 线上服务) 之前。

## 铁律 1: 评估必须走**运行链路自己的**预处理
自拼 batch 的独立 harness = 假结果。运行链路通常包含: 输入预处理器 (归一化 stats) + 特定的观测布局 +
图像尺寸 + 语言/任务串 + 模型包装器 (左右脑/双头拼接)。
- **做**: 直接复用运行链路的那个函数/路径 (例: 引擎的 `_l3_pre(batch)` + 引擎自建的 `visual39`), 或让运行链路
  自己跑 (在闭环里量指标)。
- **别做**: 在评测脚本里 `pol.select_action({"observation.state": obs})` 就完事。
- 指纹 (看到就当假结果查): 首层 shape 不匹配 (如 `mat1 64x43` vs `mat2 39x512` — 少了 4 维条件),
  或"模型输给持久基线 5×"这类极端反常。

## 铁律 2: 永远同表放**平凡基线**
值预测类目标必须和 trivial baseline 同表比: 持久 (`ŷ=obs[t]`)、匀速 (`obs[t]+(obs[t]-obs[t-1])`)、
多数类。**若平凡基线 R²≈1.0, 说明这个靶子本身不成立** —— 换靶子, 别调模型:
- 实测: 引擎物理平滑 ⇒ 匀速 R² 0.997~1.000; 模型 0.11~0.95 ⇒ 值预测(1 步/多步 K=5/10)全部无意义。
- 有效靶子通常是**事件级**: "未来 H 帧内是否发生 X" (到位/夹爪闭合/在动/异常), 它们**能**赢平凡基线
  (AUC 0.77~1.00 且跨域不退化), 而值预测不能。
- 目标维里若有常量维 (全 0/全 1), 只在**有方差的子空间**上报, 否则基线被"零维度"白送满分。

## 铁律 3: 报 **K 折 CV 均值 + 最低折**, 不报单次划分点值
同一颗模型: 单次留出 1/1 = **100%**; 5 个种子 = **1/5 = 20%**。单点值可以骗人, 分布不会。
- 按**实体**分折 (变体/场景/episode), 不能随机切帧 (时序泄漏)。
- 报告: `均值 ± std · 最低折 · 折数`; 均值刚过线而最低折低于线 ⇒ 标注"勉强达标", 不当强结论。

## 铁律 4: 训练数据必须来自**运行流**, 不是旁路生成器
两条管线"看起来一样"是不够的。实测同一颗头:
| 训练数据来源 | 闭环 AUC |
|---|---|
| 旁路生成器产物 | **0.238** (低于随机) |
| 运行链路自己的轨迹 | **0.997 ~ 1.000** |
⇒ 差 4 倍, 全在口径。先采运行流 (如引擎 trace) 再训。

## 铁律 5: 跨域不可假定
同一分布内训→评可以; 换域 (不同生成器/不同机器/不同光照) 必须**成对实测**, 不能假定迁移。
反向也要查: 同源头拿到别的域上失败是**预期**结果, 不是回归。

## 铁律 6: **自洽 ≠ 正确** —— 一致性指标必须配一条独立的物理/外部判据
闭环一致性 (各视图投回同一坐标系的 std)、方法间离散度、K 折均值 —— 这些都是**自洽**指标:
它们只要求多个估计**互相一致**, 不要求它们**与真实世界一致**。估计数少时, 一个整体偏掉的解
能同时满足所有自洽检查。实测一次校准: 闭环 std=**1.88mm**、4 种方法离散 <2mm、逐视图重投影 rmse
**0.15~0.44px** —— 看着无懈可击 —— 但解出的旋转仍偏 ~10°, 直到拿**物理约束**才暴露。
⇒ 任何校准/变换/模型验收,**除了自洽指标还要加一条与外部真值对照的判据**:
- 标定: 靶标已知的物理朝向 (平放板 ⇒ 法向必须竖直)、已知机械尺寸 (法兰→TCP 距离) 反核平移尺度。
- 模型: 平凡基线 (见铁律 2)、留出集、跨域成对实测 (见铁律 5)。
- 报数时把两类分开写: 「自洽: X」+「外部对照: Y」——只报前者的结论不得进默认档。

## 铁律 7: 自动标注/自动建集流水线要有"空数据闸门 + 真推理复核"
自动标注 → 建集 → 训练 的流水线最容易产出**假成功**: 标注 0 框 ⇒ 数据集为空 ⇒ 训练照跑完并打印
`N epochs completed in 0.001 hours` + `✅ 完成`，你汇报"训好了"，其实是一个什么都没学的空模型。
三道闸门缺一不可（均已实测）：
1. **标注侧**：产出 0 框时**判失败并分出原因**（① 没取到帧 ② VLM 返空/超时（点名 `max_tokens<3000` 致 content 空，或图过暗）
   ③ VLM 认了但都没命中类别表（带 `skipped_labels`））。判据用 `mapped_boxes>0` 且无空标签/越界，否则 ok=False。
2. **训练入口**：启动前断言数据集非空 —— 数 `labels/` 文件数与非零框数（`{'files':N,'nonzero':M}`），
   全 0 ⇒ **拒绝启动**，并把 `cmd` 记为 None（硬证据：训练进程一次都没起）。**别指望训练脚本自己会拒**，
   它会在空集上"成功"跑完。
3. **训练出口**：训完必须**真推理复核**（拿真实帧推理数框）—— `n_boxes=0` ⇒ 判**不算成功**、权重标**不可用**、
   **不上在役**（覆盖训练脚本自己打的 `✅ 完成`）。同时换在役要做**回退风险检查**：新模型 0 框 / 在役 N>0 框 ⇒
   拒绝自动切，只打印切换命令（默认 `--check-only`，须显式 `--yes --force` 才实切），且切法是**改软链**不覆盖权重文件。
- 自动标注数据一律**不进 val**；自动跑很多轮 ≠ 有用：数据只有 2 图/2 框时 20 epoch 跑完也是 0 框 ⇒
  如实说"样本太少、不算成功"，**不报"训练完成"**。
- 汇报里必须带这三条各自的实测数字（框数 / nonzero / paths），只有一行 `✅ 完成` 不算证据。

## 铁律 8: 自动标注的框当标签前要有**独立像素复核**, 口径冲突要公开
VLM 会给出"看着很高置信、其实是套模板"的框: 实测一次 14 槽位标注 —— 14 个框**尺寸完全相同**(50×60px)、
两排间距**全等**(60px)、conf 只有 0.8/0.9 两个值; 而独立像素实测是口袋宽 28~33px、间距 61.5/68px(两排相位还不同),
最大偏差 58px。**它的数量(14)与语义(两排各 7/四角被占)都是对的** ⇒ **数量与语义对不能推出位置对, conf 不是精度**。
- 落盘/进训练前必须再加一条**独立判据**(暗区带扫描、局部对比、CLAHE 目检); 两者一致才能当监督标签。
- 冲突时**两套框都交付、各带 origin 标签**(`origin=vlm` + `origin=l5corners`), **绝不静默取一边**;
  低置信框必须标出(不得当高置信用); 被目标自身遮挡的位置只能外推 ⇒ conf 降到 0.35 并注明"外推"。
- **两种口径都成立时要说清用了哪个**: 槽内左壁有阴影 ⇒ "暗区中心"比"几何中心"偏左 ~10px,
  实测残余 ≤10px(上排)/10~15px(下排) 是**口径差**不是算法错 —— 残余量写进交付说明, 不粉饰。
- **同一个 VLM 跳次调用会自相矛盾**(同场景早上报"只有一个模块"、稍后报 4 个) ⇒ 单次 VLM 输出不是稳定标签, 要复核。
- **单目尺度**: 拿已知尺寸物体当标尺(四角各放一个已知件)只能给**每角一个 mm/px**(实测 0.32~0.41, 透视不同),
  中部用单应插值; 换另一个已知尺寸互校会差 ~1.7× ⇒ mm 值 **±20%**。交付时**像素值是硬数据, mm 值附不确定度**,
  不报看起来精确的毫米数。

## 交付判据 (老倪式验收)
- 有提升 ≠ 不回退: **未证明提升不得进默认档**; 只进"可选档"且写明实测结论。
- 每条结论附取证文件 + 复现命令; 与上一轮结论冲突时**显式纠正**上一轮。
