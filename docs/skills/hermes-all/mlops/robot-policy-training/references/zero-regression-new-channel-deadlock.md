# 零回退新通道「0x0 死锁」— 加条件通道后消融无差异 = 通道是死的, 不是模型学不会

(2026-09-14 INTACT-JEPA v6「记忆条件通道」实锤。完整取证配方/代码在
`integration-level-audit` 的 `references/dead-conditioning-channel-0x0-deadlock.md`, 这里只留
训练侧该记住的判据与修法。)

## 适用
给已训好的策略**新增一路条件通道**再暖启动微调时: L2 原子技能上下文 / 记忆层 / 触觉 /
目标相对向量 / 任何 "E(s)" 式条件块。凡是要求"暖启动与老模型逐位等价 (零回退)"的场景。

## 坑
"零回退"的通行做法是把**新通道输出投影零初始化**。若同时把**入口层注册的新列也置零**
(为了让入口层老列逐位不变), 就变成 **0×0**:

```
贡献 = 0(入口新列) × 0(末层零初始化) = 0
∂L/∂(末层) = (新列ᵀ·δ)⊗输入 = 0
∂L/∂(新列) = δ ⊗ (末层输出)ᵀ = 0      ← 两侧恒零 ⇒ 谁也不会先离开 0 ⇒ 通道永久死亡
```
表现是"一切都像接上了": 训练日志打 `xxx_used=1.000`、推理诊断报 `used=1.0`、前向形状对、
loss 正常收敛 —— 唯独那路条件贡献恒 0, 训多少轮都一样。实测: 训满 3 个 epoch 后
`intent_actor.skill_enc.3.weight` 仍 100% 为 0; `∂L/∂(末层)=∂L/∂(新列)=0` 而
**对照组** `∂L/∂(入口层老列)=9.222e-01` (老能力一直在学, 只有新通道死了)。

## 判据 (指标自报不算证据)
1. **消融**: 同一权重、同一批真帧, 只改"看不看得见这路条件"(喂真值 vs 喂全零),
   两遍输出 `torch.equal` 为 True / MAE 到小数点后 16 位都相同 ⇒ 通道输出恒 0。
2. **梯度**: 用真模型真损失 backward, 看该通道**两侧**参数的 grad 是否都为 0
   (必须带对照组: 同层的其它列应该非 0, 否则是整个模型没在训, 不是通道问题)。
3. **权重**: ckpt 里那个零初始化的末端层, 训 N 轮后是否离开 0。
   (随机初始化的那侧 nonzero%=1.0 没意义, 别拿它当"在学"的证据。)

## 修法 (保住零回退, 但让梯度可通)
**只允许一端是零**:
```python
_b = 1.0 / (new_w.shape[1] ** 0.5)
new_w[:, old_w.shape[1]:].uniform_(-_b, _b)   # 入口新列: 小随机 (不要置零!)
# 末层保持零初始化 → 暖启动输出仍逐位不变 (0 向量乘任意权重恒 0), 梯度通了
```
实测: 解冻前后输出逐位相同 (零回退不破), `∂L/∂(末层)` 0 → 1.165e-01; 真优化 5 步后
`|末层.weight|max` 0 → 0.002758, `loss(on)=11.25210 < loss(zero)=11.25257`。
另外加一个 **无条件** 的 init 后体检 (两端同时全零就地解冻), 否则**续训**会把旧权重的
死锁状态一起带过来。

## 连带义务
- 死通道上所有"该通道无提升 / 预测塌缩"的判闸 ❌ **作废, 重训后重判** —— 那是对恒零通道的
  正确描述, 不是"模型学不会"。但要分清批次: 同任务里**压根没有这路通道**的旧模型
  (本例 v5) 的 ❌ 是另一回事, 属真·能力不足, 别一起作废。
- 重训**另起目录名** (v6r2 → v6r3) 留旧 ckpt 作"修复前"对照, 别原地覆盖。
- 先查数据: 数据集里那一路条件的列是不是真值 (逐维非零占比), 排除"数据没给"再改模型代码。
