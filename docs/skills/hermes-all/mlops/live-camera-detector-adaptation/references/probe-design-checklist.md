# 探针/自标定设计清单 (kinematic eye-hand, 逐项可勾)

配套 SKILL.md §7。用在"要让机器人带着工件走一趟来标定相机"之前/之后逐项核对。
每条都对应一个实测数字 —— 不做就是标签错或标定废。

## A. 现场之前 (离线就能做完, 不需要机器人)

- [ ] **工件物理尺寸** 量一次 (卡尺): 长×宽×厚 mm。不给就是猜, 框大小必错。
- [ ] **工件中心相对 TCP 的偏移** 量一次 (沿工具轴, mm)。长杆夹在一端时偏差几十 mm;
      不给偏移, 拟合 rms 和标签位置都会整体偏 (实测给错时留出盲测 35px vs 给对 6px)。
- [ ] **探针计划** 用 `tools/real_probe_plan.py` 生成并自检:
      非共面 (平面性 σ3/σ1 ≥ 0.15) · 含真实深度变化 (60~130mm) · 姿态 ≥±16° · 步距 ≤80mm · 全在安全盒内。
      只在正对相机的平面上平移 → DLT 病态 (实测 rms 244px, 反解 K=0)。
- [ ] **ROI 来源** 备好: 在役权重出框 (`tools/make_roi_from_yolo.py`, conf≥0.5 + 剔贴边框) 或人工框一次。
      ROI 只用来"选区域", 不产生标签 → 不构成自证循环。

## B. 采集时

- [ ] 帧与 TCP/四元数真值**同刻配对** (共同时期 + 容差)。归档数据里实测出现过 ΔTCP=0 而画面移动 ~100px。
- [ ] 相邻位姿在画面里动 ~20~40px (太小差分没有运动域, 太大对称差会跑出 ROI)。
- [ ] 每个位姿都落: 帧 (jpg) + truth.jsonl (tcp/tcp_quat) + roi.jsonl (该帧工件框)。
- [ ] 留 **2~3 个验证位姿** (姿态与拟合位姿不同) —— 用来盲测判定标定可用性, 不要全拿去拟合。

## C. 标定后 (落盘前必查)

- [ ] `--probe` 输出: ① 朴素解 rms ② 联合解 (P, 工具系偏移)。
      ② 解出的偏移是"工件+夹爪"**合成点**, **只能当诊断**, 出框一定要用实测偏移。
- [ ] **位姿预检 ok** (非共面)。退化时工具会**拒绝落盘** —— 这是设计, 不要绕过。
- [ ] **rms ≤ 2px** 且 **留出盲测 ≤ 2px**。注意: rms 会骗人 (偏移给错时 rms 仍 1.64px), 盲测才拦得住。
- [ ] **不要用反解出的 K** 做 3D 反投影: 浅景深下内参不可辨识 (反投影 1.2px 时 fx 估 175 vs 真值 610)。
      2D 出框够用; 像素→米必须单独标 K (棋盘格/工厂内参)。

## D. 出标签 (S2)

- [ ] 抓取门生效: 只在"工件预测位置附近有随动"的帧发框; 没夹住/不在视野 → 不发 (实测没夹住 → 0 标签)。
- [ ] 自动标签 **只进 train, 永不进 val**; 无标签帧进待标注池, **不当背景负样本**。
- [ ] 抽检 IoU: 合成演练里真实几何 + ROI 的中位 IoU 0.758 (无 ROI 时 0.0)。

## E. 已知盲区 (如实记录, 别粉饰)

- [ ] 工件静止但**夹爪可见**且没有 ROI 时, 抓取门会被夹爪的运动骗过 (实测误放行 10 张, IoU 0.0)。
      加 ROI 后归零 → 所以 ROI 是硬要求, 不是优化。
- [ ] 真机不在线时的结论一律标"合成演练, 待真机复测"; 不要拿演练数字当交付证据。
