## 二、真机归档帧的独立核查 (不依赖任何合成假设)

- 在役 YOLO 抖动大: 同一权重在 0718 会话 3/3 检出 conf 0.912~0.942 (框 51×106px);
  在 1434 近景会话最高只有 0.213 且框贴在画面右边 (9.8×131px, 工件被裁) → ROI 质量门 (conf≥0.5 + 剔贴边框) 判 0 条可用。
- **工件在真机帧上比周围暗**: 框内均值 − 环带均值 的中位数 **−25 灰度** (18 张里只有 1 张是框内更亮)
  ⇒ "按亮度把工件抠出来"这条路**不成立**, 必须靠 ROI / 独立定位。
- **帧与 TCP 真值时间未对齐**: 0718 会话里 ΔTCP=0mm 而画面移动 ~100px
  ⇒ 采集端必须同刻配对 (共同时钟 + 容差), 否则 S1 的点对本身就是废的。
- 真机帧的运动掩膜高度碎裂 (相邻帧差分出 20~60 个连通域) ⇒ 提取要抗噪 (阈值 + 开运算 + 面积过滤), 并如实报残差。

## 三、命令 (现场 30 分钟)

```bash
# 0) 量一次 (不猜): 工件物理尺寸 (卡尺) · 工件中心相对 TCP 的偏移 (沿工具轴, mm)
#    ROI: 每帧一个工件框, 放 <会话>/roi.jsonl
gui-venv311/bin/python tools/make_roi_from_yolo.py --session data/yolo_annot/sessions/<会话>
#    (在役权重自动出框, conf≥0.5 + 剔贴边框; 缺帧留空不补; 近景检不出时人工框一次)

# 1) 探针计划 + 自检 (纯几何, 不连机器人) —— 不合格会直接拒 (越界/步距超限/退化)
gui-venv311/bin/python tools/real_probe_plan.py --tcp <当前TCP> --out /tmp/probe_plan.json
#    自检项: 非共面(平面性 σ3/σ1 ≥0.15) · 带 ±16° 姿态 · 步距 ≤80mm · 全在安全盒内

# 2) 现场按计划走 13 个位姿, 边走边采"帧 + 同刻 TCP/四元数" (Orin 零程序: 4060 侧 Docker 只读订阅)

# 3) 自标定 (秒级) —— 预检退化 / rms >2px 会拒绝落盘
gui-venv311/bin/python tools/real_autolabel.py --probe <会话>/frames --truth <会话>/truth.jsonl \
    --module-offset <偏移mm> --roi <会话>/roi.jsonl --out models/real_cam_proj.json
#    输出 ① 朴素解 rms ② 联合解 (P, 工具系偏移) —— ②只作诊断, **出框一定要用实测偏移**, 不要用解出来的合成偏移

# 4) 试标 (只统计不落盘)
gui-venv311/bin/python tools/real_autolabel.py --label-session <会话> --size <尺寸mm> \
    --module-offset <偏移mm> --dry-run

# 5) 接进训练模式: 画布「🔀 训练/推理」双击切到『🎯 真机数据 L2 训练』→ ▶ 运行
#    ss_l2_autolearn.py 的几何标注按两条标定来源取: models/real_cam_proj.json (机器人动作自标定, 优先)
#    → models/real_cam_calib.json (棋盘格/手眼 K·T) → 都没有则拒算并回落伪标注; --status 的 calib_route 回显走哪条
```

## 四、诚实边界 (本次明确没打通)

1. **自标定只解决 2D**: P 用于"真值 3D → 像素框"没问题; 像素→米的 3D 反投影**必须单独标 K** (浅景深不可辨识)。
2. 帧/真值时间对齐 (采集端共同时钟) —— 否则点对是废的。
3. 夹爪开度发布者缺失 → 抓取门只能用"图像随动 + ROI"; 有夹爪真值时优先用真值。
4. 现场几何未示教 → 只标 `peg`; 示教 goal 点后才有 `hole` 类。
5. val 只有 2 张人工标注 → mAP 不能当泛化证据; auto 标签**永不进 val**, 需再人工标 100+ 张。
6. 真机探针尚未跑 (本机不在产线网时 Orin 不可达, 位姿流收不到) —— 上线后按上面 5 步走一遍即可闭环。
