# eye-in-hand 手眼标定 — **已验证口径** + 当日七个真根因 (2026-09-19)

> 本文是 `references/eye-in-hand-board-calibration-2026-09-19.md`(当日早期版)的**更正版**。
> 早期版有两处已被现场证伪 (**板型**、**解法 API**), 以本文为准; 早期版的 ⑤采集器纪律/①假标定 仍有效。
> 触发现场: 相机固定在协作臂上 (eye-in-hand), 镜头朝下看**固定标定板** (~0.26~0.5m);
> 操作员**只能手动拖机械臂, 不能控夹爪开合**。

## ① 板规格与检测 — 先拿"用户肉眼所见"当第一手证据, 别照命名猜
- **❌ 被证伪**: "CGB-020 5*4 20mm = 棋盘格 → 内角点 4×3 = 12 个"。
  `findChessboardCorners` 对**圆点阵**会**误检 12 个"角点"**(把圆点间隙当角点), 4 张图上都"检出",
  很像真的。**该检测器不能作为"板在不在画面"的判据。**
- **✅ 真实板**: **白点黑底 · 20 个白色圆点 · 非对称 4×5 · 20mm 间距** ("5×4"=20 点)。
- **✅ 检测**: **必须反色** `src = 255 - cv2.cvtColor(img, GRAY)` → `cv2.findCirclesGrid(src, (4,5),
  CALIB_CB_ASYMMETRIC_GRID)` → 11/11 样本稳定 **20 点**。不反色 = **0 检出**(白点在黑底上)。
  低成本保险: 极性 × {对称,非对称} × {(4,5),(5,4)} 全枚举, 任一命中即用。
- 非对称物点约定 (与 findCirclesGrid 匹配): `x = (2*j + i%2) * spacing`, `y = i * spacing`, z=0。
- **口诀**: 检不到板时不要只报"没看到板" — 依次换 **极性/pattern/grid** 三轴枚举; 用户说
  "画面里能看到 20 个白色圆点"就是最硬的证据, 用它反推检测参数。
  工具: `tools/board_recheck_white.py`(数白斑+反色) · `board_recheck_circles.py` · `board_probe_cgb.py`。

## ② 姿态约定 — 四元数**分量顺序**是静默杀手
现场 `tcp_quat` 首分量最大 (如 `['0.949','0.017','0.312','0.046']`) ⇒ 顺序 **(w,x,y,z)**。
按 (x,y,z,w) 解析 → 旋转矩阵全错 → 手眼解出**荒谬平移 (实测 47 米)**、重投影 55px。
做法: 从数据统计自动判序 (|q0| 是否≥其余分量) + **打印判定**, 别写死。
自查: 解出的平移量级远超工件尺度 → 先怀疑姿态解析, 而不是去调参。

## ③ 采集器纪律 (每条都是返工换来的)
| 症状 | 根因 | 修法 |
|---|---|---|
| 拖 3 次一个样本都没存 | 停稳判据 **1mm** — 人手停稳后仍微抖 → 永远"未停稳" | 阈值放到**人手量级 (≤25mm)** |
| "距上次位移"恒 0 | 与**运动中更新的当前点**比 | 只与**上一次已保存**的位姿比 |
| 卡住看不出 (静默) | 只在保存时打印 | **每 5s 心跳**: TCP/停稳or抖动/距上次/累计/上次板 |
| **同一张图配多个位姿** | 相机**只有 ~0.53fps**(≈2s 一张新图), 一动就取图 → 取到旧图 | **必须校验新帧**: 图像 **md5 变化** + **帧龄 ≤3s**(8s 太松); 现场操作卡写明"停稳后多等 2~3s" |
| 机器人"没动" | 先证伪: 连续读编码器 TCP + 比 state 文件尾行时间戳与本机时钟(差 ~0.1s=活) | **别先怀疑操作员** |

合格判据(逐位姿即时回报操作员): 板在画面 **且点数=20** 且帧龄≤3s 且距上一样本位移≥8mm。
目标 **≥15 位姿** + **姿态多样性 ≥20~30°** (手眼标定吃旋转激励, 只看平移不够)。

## ④ 解算前的**数据自检**(决定性, 与解法无关, 先做它)
硬约束: 相机在工具上 ⇒ 工具与相机相对运动共轭 ⇒ **转角相等**; 板静止 ⇒
**|工具相对转角| ≡ |板在相机系里的相对转角|**。
废数据实测: 差 **中位 12.4°/最大 30.4°**, "工具动 34mm 而板在相机里只动 2.5mm" → 直接判废, 别解。
工具: `tools/handeye_diag.py`(两两 |Δangle| 对比) · `tools/handeye_mount_test.py`
(**板像素质心**分组对比 + **整幅 phaseCorrelate 位移**: 位移≈`fx·Δ/距离` ⇒ 相机确实随臂动;
质心完全相同的样本 = 同一张图 ⇒ 帧没更新, 见③)。
⚠️ "同图重复"与"相机没动"表象相似 → 用**质心分组**区分。

## ⑤ 解算实现 — 本机 OpenCV **5.0.0 无 `cv2.calibrateHandEye`**
调用即 `AttributeError` (早期版写的就是这条, 已证伪)。✅ 自实现 (`tools/handeye_solve_ls.py`, 可跑):
1. 每视图 `solvePnP`(20 物点↔像素) → T_board2cam;
2. 相对运动 A = T_tool2base_i⁻¹·T_tool2base_j, B = T_board2cam_j·T_board2cam_i⁻¹;
3. **Park-Martin 闭式解**旋转 (Σ β·αᵀ 的 SVD) + 平移最小二乘 → T_cam2tool 初值;
4. **scipy least_squares(LM) 最小化重投影**: 参数 = X(6) + 板在基座下(6); 11 视图×20 点 = 440 残差;
5. **留一法**重解 → 平移 σ/极差 (诚实不确定度);
6. 行/列顺序歧义 → 两种都解取重投影更优者, 并把采用哪种写进结果。
**落盘闸门**: 视图 ≥8(建议 ≥15) **且** 重投影中位 ≤1.5px, 否则**拒算并说明下一步**;
结果含 `views_used / per_view 误差 / LOO / pattern / K 来源`。

## ⑥ 不需要夹爪 + 诚实红线
夹爪不可控 ⇒ 不能用"工件随工具动"的自监督; 但**固定板 + 动相机 = 经典 AX=XB**, 不需要夹爪。
解出 T_cam2tool 后**静止工件**也能单帧反投影出基座系位置(插拔要的正是它), 并可回算板在基座系当参考面。
红线 (本类任务的通用纪律):
- 前提不成立(如相机在臂上却走"相机固定"自监督) → **物理前提闸门直接拒算**;
- **"成功"文案必须回读落盘文件**(存在性+关键字段)再打印 — 曾无条件打印"✅自监督标定成功"而文件不存在;
- 数据不合格(自检不过/帧重复/视图不足) → **拒算 + 报清楚哪一步不合格**, 宁可无结果不给假结果。
