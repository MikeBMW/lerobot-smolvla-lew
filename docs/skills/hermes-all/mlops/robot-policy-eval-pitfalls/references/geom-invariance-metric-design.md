# 几何不变性指标设计 + 域增强配方（2026-09-23 实测）

主题：怎么量"模型的性能在几何变换下是否变形"，以及**指标本身怎么选才可信**。
本文的起因是一次真实的**指标设计错误**：用错的指标得出了相反的结论。

---

## 1. 错误示范：用"相对变化%"量敏感度

```
❌ 敏感度 = mean|u_transform − u_base| / mean|u_base|
```

实测后果（引擎真帧，统一主干 SigLIP+四头，n=32，平移幅度扫描 4/8/16px）：

| 版本 | 逐幅度相对变化 | 均值 |
|---|---|---|
| 无增强 | 38.5% · 32.4% · **131.0%** | 131.0%（被 16px 那一档主导） |
| +几何增强 | 4.6% · 48.3% · 7.9% | 7.9% |

这个指标**不可用**，两个独立原因：

1. **基准幅度太小**（本例 `mean|u| ≈ 0.036~0.049`）→ 任何绝对波动都被放大成夸张百分比；
   当某个样本的 base 输出接近 0 时，比值会炸到 >100%。
2. **单幅度噪声大** → 少数样本能主导均值（逐幅度从 4.6% 到 48.3%）。

**由这个错指标得出的两个错误结论（都已撤回）**：
- "几何增强让模型变差"（当时只测到 600 步的中间 ckpt：16.7% vs 终值 47.7%）；
- "平移 33.8% 已贴近阈值 35%，是唯一弱点"（不同幅度下根本不单调）。

---

## 2. 正确做法：尺度无关指标 + 多幅度扫描

```python
# ① 方向一致性 (尺度无关, 物理含义 = 方向是否随几何变换保持)
A = u_tr.reshape(len(u_tr), -1); B = u_base.reshape(len(u_base), -1)
cos = ((A*B).sum(1) / (norm(A,axis=1)*norm(B,axis=1) + 1e-9)).mean()

# ② 多幅度扫描取平均 (单幅度噪声太大)
平移 dx ∈ (4, 8, 16) px · 缩放 s ∈ (1.05, 1.10) · 旋转 θ ∈ (5, 10)°
每档算一次 cos, 再取平均; 同时也打印逐档值 (看单调性/异常档)

# ③ 一致性类指标 (逐态 std) 必须用**真实变换输出**算
dim_std = np.stack([u_base, u_dx, u_scale, u_rot]).std(0).mean()
# ❌ 不能写成 base 与 base+常量 的 std → 得到 ≈0 的假通过
```

判据（本项目采用）：`cos ≥ 0.90`（三个变换各一项）+ `逐态 std / mean|u| ≤ 30%`。

---

## 3. 实测结果：域增强确实治几何敏感性，且不牺牲精度

| 版本 | 平移 cos | 缩放 cos | 旋转 cos | 逐态 std | 留出 L4 / 动作 |
|---|---|---|---|---|---|
| 无增强 | 0.817 | 0.841 | 0.886 | 65.4% | 0.008 / 0.048 |
| +几何增强 | 0.947 | 0.910 | 0.899 | 17.8% | 0.011 / 0.053 |
| **+几何增强 + 数据扩容** | **0.995** | 0.882 ⚠️ | **0.945** | 18.3% | 0.009 / 0.050 |

解读：
- 平移从 0.817 → 0.947 → **0.995**（近乎完全不变）；旋转也过线；
- 逐态 std 从 65.4% 降到 ~18%；
- **唯一未过线的是缩放（0.882）** → 下一轮把**尺度**增强的幅度从 0.95–1.05 放宽到 0.90–1.10
  （只放宽这一维，别全加，否则归一化尺度也被动）；
- 精度没有牺牲：训足步数后 0.009–0.011，与无增强版（0.008）同级。

## 4. 域增强实现要点（踩过的坑）

```python
# ① 增强开关必须是**实例属性**, 不能是类属性
class RealH5(Dataset):
    def __init__(self, files, chunk=7, aug=0):
        self.aug = int(aug)          # ✅ 实例级
    def __getitem__(self, i):
        ...
        if self.aug:                 # 留出集用 aug=0 → 判据才有效
            px = _aug_px(px, i)      # 确定性: 由索引派生 rng, 可复现

# ② 增强函数: 平移/尺度/旋转 一起, 用 warpAffine + BORDER_REPLICATE
def _aug_px(px, seed):
    rng = np.random.default_rng(int(seed) * 7919 + 13)
    M = cv2.getRotationMatrix2D((W/2, H/2), rng.uniform(-5,5), rng.uniform(0.95,1.05))
    M[0,2] += rng.uniform(-8,8); M[1,2] += rng.uniform(-8,8)
    return cv2.warpAffine(px, M, (W,H), borderMode=cv2.BORDER_REPLICATE)
```

- **留出集绝不能增强**，否则"几何鲁棒性判据"被自己污染；
- 若用类属性（`RealH5._AUG`）实现，构造顺序/worker fork 时机会让留出 loader 也吃到增强 → 用实例属性最稳。

## 5. 两条训练判读纪律（同批实测）

```
① best 出现在**最后一步** ⇒ 还没训够 → 加长步数再跑
   实测: best@2500(=末尾) → 续跑 6000 步
   反之: best 在中段、之后回升 ⇒ 过拟合 → 早停 + 存留出最优

② 别用**中途 ckpt** 下结论
   实测: 600 步时测得的敏感度(16.7%) 与终值(47.7%) 完全相反;
   而当时还叠加了"指标本身错了"的因素 → 双重不可信。
   结论必须同时满足: 训练收敛 + 指标可信。
```
