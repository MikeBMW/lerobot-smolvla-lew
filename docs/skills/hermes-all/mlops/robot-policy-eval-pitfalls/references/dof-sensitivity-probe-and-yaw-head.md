# DOF 敏感性探针 + yaw 条件头 (2026-09-11 实测: 28/28 全成功的"无最优角"结论)

## 为什么写这份
老倪要求: "把 yaw 纳入预测器输入重训 (act_dim 4→5, 用候选角+真实试抓成败做监督),
让 φ* 从边界值变成真正的最优对准角"。
**先做前置检查 = 探针, 结果推翻了这个前提**: 该场景 yaw 在物理上没有最优角 → 标签恒定,
任何监督学习都学不到角度信息。这一步如果跳过, 会训出一个"看起来有 output 但无意义"的头。

## 结论 (可复现, 两条探针, 共 28 次真实试验)
```
② 抓横放光模块 (无刚性锁, 真实摩擦夹持 + 抬升试探 Δz>0.08m 判成功):
   候选角 -90,-75,…,+90 (13 个) → 13/13 全成功 · Δz = 133.3 ~ 137.6 mm
⑤ 插入段 yaw 偏移 δ (在相位翻转上叠加 δ, 真实推入 + stall 保护):
   δ = -90…+90 (15 个) → 15/15 全成功 · 推入深度 48.7 ~ 49.8 mm
```
**物理原因**: metaworld `peg-insert-side-v3` 的 peg 是 `size="0.015 0.015 0.12"`
= **15×15mm 方形截面**长条 → 绕长轴转任意角度, 两指都能夹住 (斜对角才 21mm, 仍在开口内);
孔是旋转容差大的圆柱/方槽 → 插入也对 yaw 免疫。**方形截面 = 旋转不变 → 不存在最优角。**

## 铁律 (通用, 不止 yaw)
1. **先探针后训练**: 要"用真实成败监督某个自由度 (DOF)"之前, 必须先扫该 DOF 的候选值,
   确认成功率**有明显区分度**。全绿/全红 = 标签恒定 = 学不到东西 → 如实上报, 不要硬训。
2. **零件几何决定 DOF 是否 load-bearing**: 各向同性截面 (方/圆) 的旋转自由度无最优值;
   要让"对准角"有意义, 零件必须**各向异性** (真机 1.6T OSFP 光模块 = 长条矩形件, 有金手指方向)。
   遇到"模型学不出最优值", 先问几何是否让该 DOF 可辨识。
3. **刚性锁/治具会掩蔽成败**: 演示链里 `_grip_lock`(peg 每帧钉到手爪) + 治具钉(peg 坐盘)
   会让**任意指令都"成功"**。用这种链路采"成败"标签 = 采到常数。
   做探针必须**撤掉刚性锁与治具**, 用真实摩擦夹持 + 抬升试探判成败。
4. **模型输入维度决定打分能力**: 预测器 act_dim 里**没有**被优化的那个 DOF
   (此处 act_dim=4, yaw 不在其中) → 让它给候选角打分, 只能靠"把候选假设编码进状态"
   → 代价曲线**单调退化**: argmin 恒落在候选区间边界, 选择零信息。
   **签名**: 打印候选代价表, 若严格单调 (实测 +45.3° 0.168 → -44.7° 0.0955 单调降) = 命中。
   要真打分: 把该 DOF 加进输入维 (act_dim 4→5) 或用专门的条件头。
5. **两臂结果相同 ⇒ 不声明增益**: A/B (脚本固定角 vs 预测器决策) 均 6/6 成功、
   插入 49.1 vs 49.4mm、η 均 1.0 → 差异只在"指令来源", 不在任务结果 → 默认档保持脚本开环。
   要声明增益, 必须先把决策放到 load-bearing 位置 (探针证明有区分度的地方)。

## 要让"最优对准角"真实存在, 下一步 (需老倪点头, 会改已验收场景)
1. 把 L4 场景零件截面改成**矩形** (`gen_l4_demo_scene.py` 注入的 peg geom, 如 0.030×0.010)
   = 贴近真实光模块 → 夹爪必须沿短边轴闭合, yaw 错 → 指间开口不足 → **物理上真的夹不住**;
2. 先跑**全链回归** (①转台90°→②抓→③回正→④标准抓取→⑤插入→⑥拔出→⑦AOI→⑧耦合, 多 seed 同口径),
   确认相对旧场景**不回退**;
3. 再跑两个探针 → 有区分度 → 训 `YawGraspHead` → 接入执行器 (φ* 由该头决策, 预测 vs 实测曲线为证据);
4. 3D 面板来源行改为「yaw 头(真实试抓监督) + φ* + 预测成败」, 出 A/B + 视频。
