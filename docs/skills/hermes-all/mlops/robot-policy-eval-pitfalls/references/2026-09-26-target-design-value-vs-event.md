# 靶子设计铁律: 先看数据实况, 再定靶子; 值预测常输平凡基线 → 改事件级 (2026-09-26 实证)

> 场景: "认知预测头"换靶子(一步 → 多步 K → 事件级)。结论: **值预测这类靶子在本引擎数据上必然被平凡基线压制,
> 事件级才是真有信号的靶子, 而且跨域可用**。全过程以负结果+正结果各一份落盘。

## 2. 平凡基线是必选项（不是可选项）

| 靶子类型 | 必带基线 | 本次实测 |
|---|---|---|
| 值预测(1 步 / K 步) | **持久**(ŷ=obs[t]) + **匀速**(ŷ=obs[t]+K·Δobs) | 持久 R² 0.999/0.983/0.940, **匀速 R² 1.000/0.996/0.967**, 模型 0.95/0.93/0.89 ⇒ **模型输** |
| 事件级(未来 H 帧内是否发生) | **平凡基线 = 恒报"无事件"**(准确率=max(正例率,1−正例率)) | 模型 AUC 0.77~0.91, 准确率高于平凡基线 6/6 ⇒ **模型赢** |

**结构性结论**：引擎物理是**平滑线性**运动 + 多数段位常量 ⇒ 匀速外推几乎精确 ⇒
"预测下一帧/未来 K 帧观测"这类靶子**天然被平凡基线压制**, 换 K 没用（1/5/10 全输, 有效子空间 23 维同结论）。
别把这种输法解读成"模型不行"——是**靶子选错**。（与更早的一次一步预测结论一致: 一步 MAE 0.0154 vs 持久 0.0030。）

## 3. 改事件级: 定义、判据、跨域

- **定义（只用有变化的维, 且物理可解释）**:
  `gripper_close` 夹爪下穿 0.5（真动作, 每段一次）· `reach_z` 手 z 进入该段末值 ±2mm（插入到位）·
  `move_hand` 段内手位移 >1mm（在动）; 标签 = "未来 H(Q=5/10) 帧内是否发生"。
- **判据**: ① AUC > 0.5 且有裕度（>0.52）② 准确率 > 平凡基线 ③ 逐 seed 平均（≥3 seeds）。
- **跨域复评（必做, 别只看域内）**: 在域 A(v6) 训 → 域 B(v5) 测, 并与 B 域内训练同表比:
  本次 **6/6 事件跨域不退化**(夹爪 0.900/0.870 · 到位 0.802/0.769 · 手在动 0.920/0.905), 与域内几乎持平。
  ⇒ 事件头的表征是可迁移的; 值预测头则连域内都站不住, 跨域无意义。

## 4. 划分与报告纪律

- **按段划分**（`variant_id` / `ep_idx` 分组, 80/20）, **绝不用随机帧索引**——随机索引会让 t 与 t+K 跨段,
  早期一次"一步预测"评估就是随机索引, 口径不干净; 换靶子的对照必须段内配对。
- 落盘三件: 实验脚本 + 逐项 JSON（含 r2/mae/auc/正例率/判据标记）+ 运行日志（控制台全文）。
- **负结果要留档并写进路线图**（本次: 值预测两次判负 → 推动 ①-1/①-3 改事件级）。
- 数据实况(零维/常量 ctx)与"只能监督哪几维"一并写进结论, 供后续决定补数据。
