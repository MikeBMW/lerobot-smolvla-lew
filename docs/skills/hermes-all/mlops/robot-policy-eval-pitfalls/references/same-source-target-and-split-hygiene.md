# 同源口径 + 划分方差 + 靶子选择 (2026-09-26 实测, 三条硬结论)

来源: 状态空间工程的"认知头"专项 — 离线指标很好、进闭环却失效, 最后定位到**口径**而不是模型。

## 1. 训练数据必须与**运行流**同源 —— 否则离线再漂亮也是假的

实测: **同一颗头 (同一个网络/同一套超参), 只换训练数据来源**:

| 训练数据来源 | 与运行流的域一致性 | 引擎闭环 AUC |
|---|---|---|
| 造数据管线产物 (l5_gen_v6, 生成的轨迹) | 不同源 | **0.238** (低于随机!) |
| 引擎自己的 trace (state_space_sim_real 的 tr) | 同源 | **0.997 ~ 1.000** |

⇒ 差 **4 倍**, 不是模型能力问题。**判据: 训练集必须从"要运行它的那条流"里采**。
落地: 采集器直接从引擎 trace 抽 obs/动作/阶段 (本例 30 段×220 步 = 6600 帧, 21 秒采完),
在**同一条流水线**里做 5 折 CV → 落 ckpt → 再回闭环复验。

## 2. 单次留出划分会骗人 → 一律报 **K 折 CV 均值±分布**

实测: 某个事件在**单次 80/20 留出**上 0.770~0.783 (差门槛 0.008), 试了 容量×2 / 派生特征 /
5 种子集成 **三档都过不去**; 但**同一颗头的跨域 AUC 反而 0.83~0.84** → 说明问题在"这一次划分
挑到了哪些 episode", 不在模型。改成**按 episode/变体 5 折 CV** 后: 均值 0.7999 (过线),
最低折 0.7589, std 0.030。

纪律:
- 结论只报 **均值 + 最低折 + std**, 单次点值不能当结论 (既会低估也会高估)。
- 阈值附近的"勉强达标"要点名说清 (如"均值 0.80 只比门槛高 0.01, 最低折 0.76 ⇒ 不可当强结论")。
- 划分方差大 = 该任务在数据多样性上不足 → 补 episode 多样性比调模型更有效。

## 3. 靶子选择: 值预测易被平凡基线压制, **事件级**才有信号

实测同一份引擎数据:

| 靶子 | 模型 | 平凡基线 | 结论 |
|---|---|---|---|
| 预测下一帧 39D 观测 (一步) | MAE 0.0154 | 持久 (复制当前帧) **0.00297** | 模型输 **5.19×** |
| 多步 K=1/5/10 预测 obs[t+K] | R² 0.95/0.93/0.89 | 持久 0.999/0.983/0.940 · **匀速 1.000/0.996/0.967** | 模型全输 |
| 未来 H 帧内**事件是否发生** (夹爪闭合/到位/手在动) | AUC 0.79~1.00 | 恒报"无事件" (acc 0.85~0.99) | **6/6 全赢** |

机制: 物理轨迹平滑 → 匀速外推近精确; 生成数据里目标维常为常量 → 持久基线近满分。
**判别问句: 这个靶子, 平凡基线能拿多少?** 若基线已近满分, 换靶子 (事件级/多步/事件时刻),
不要加模型容量。

## 4. "进闭环"才算落地 —— 三件套证据

1. **逐帧真调用计数**: 引擎里放 `calls` 计数器, 取证断言 `calls == frames` (证明每帧真调, 非抽样/占位)。
2. **值域/来源可核**: 输出概率 ∈ [0,1] 且非 -1 (拿不到权重就写 -1, 不冒充 0), 并打印 ckpt 名与单帧耗时。
3. **闭环内指标**: 用 trace 自身按**与训练同定义**算标签, 再算 AUC (本例闭环 AUC 0.997~1.000)。
   ⚠️ 若该 episode 里事件根本没发生 (正例率 0) → AUC 无定义, **如实写"无定义"**, 不要拿 0.5 顶替。

## 5. 一个反模式 (在同一工程里出现两次)

"未识别的枚举 → 静默降级成索引 0":
- 阶段门控: 引擎 8 阶段 vs 专家 7 个 → 第 8 个阶段 stage_p 行和为 0 → 均匀兜底 → hard argmax **恒取 E0** (表现为"E0 吞掉了若干阶段")。
- 数据生成器: 阶段名带前缀 `"阶段 接近"` 而匹配表是 `"接近"` → 永远 False → 静默 `index=0` → **一整列特征变成常量** (skill_ctx 24 维只有 dim13=1)。

修法统一为: **未识别 → 独立槽位/显式默认 + 计数 + 打印**, 绝不静默落到 0 号; 并写一条单元取证
(喂入未识别输入 → 断言落到指定槽位且计数 +1)。
