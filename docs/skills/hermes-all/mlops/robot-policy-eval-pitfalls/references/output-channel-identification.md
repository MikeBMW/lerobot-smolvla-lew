# 外部模型输出接本工程通道: 先做"输出语义鉴定" (2026-09-12, INTACT→u_ff 实测定稿)

## 触发
- 要把一个**外部论文/外部训练**的模型接进本工程当控制信号 (前馈加速器 u_ff / 流形 / 目标点), 且要"默认生效"。
- 标定/拟合闸不过, 你正打算"再多标定一次"或"再调超参" —— 先做本文件的鉴定, 否则是在错误的目标上耗算力。
- 报告里要给 R² / 相关系数 —— 口径写错就是夸大。

## ① 先问"它输出的是什么", 不是"怎么拟合它"
把外部输出各维与**它自己的训练目标**求相关 (INTACT 实测):
```
chunk 各维 vs |Δ| = |z_goal − z_t| (它的 goal_displacement 目标) : |ρ| = 0.44 ~ 0.62
⇒ 它输出的是"离目标多远/往哪走"的**意向位移**, 不是速度指令。
⇒ 拿它当 u_ff (速度指令) 去标定 = 让"报距离"的信号当"踩油门"的指令 —— 注定标不上,
   而且这部分**与数据量无关**: 再练也还是意向。
```
反过来先测它真正有信号的通道:
```
意向 |Δ| vs 引擎流形真值(mani6):
  全局:     eta −0.765 · rem +0.617 · dperp +0.600   ← 看着很强
  去同轨迹线性趋势后: eta −0.109 · rem +0.313      ← 大幅缩水 (共享趋势成分)
  分阶段:   [插入·接触] eta −0.695 / rem +0.699 · [转移] eta −0.745 / rem +0.627 / dperp +0.729
  对照(引擎自己的 u_ff 分阶段最强): [转移] |ρ|=0.740  → 同量级
⇒ 真信号但**分段局部**; 相关必须同时报「分阶段」+「去趋势」, 只报全局就是把趋势当信号。
```
**结论形态**: 该通道用于**门控/条件化** (流形侧), 不要拿去当动作指令; 动作指令留给已验证的解析链/蒸馏路径。

## ② 标定口径: 选维+尺度, 不是回归
适配层契约: `out[:, axis] = chunk[:, slice[axis]] · scale[axis]`。
- ✗ 岭/线性回归拟合解析指令 = 让外部模型蒸馏一个**分阶段状态机** → 不可达 (实测中位 R² = −0.1471 → 无信号)。
- ✓ 物理量纲对齐: 每轴选 |ρ| 最大的外部维, 尺度 `K = cov(c_j, u_a)/var(c_j)` (单变量最小二乘, 令二者同尺)。
  这不是"学动作", 是"换算单位", 自由度只有 4~8 个 (可被独立数据验证)。
- 离散维 (如 gripper, 本工程由状态机接管) → 尺度 0 并在产物里显式标注"不参与标定", **不计入闸**也不假装标了。

## ③ 闸值与 R² 口径 (最容易自欺的地方)
```
嵌套 5 折 (每折在训练折上重选维/尺度 → 测试折打分):
   全局口径    : 样本内 0.055 → 样本外 0.043
   分阶段条件  : 样本内 0.177 (看着像有信号) → 样本外 **−0.63** (纯过拟合)
```
⇒ 铁律: **一律报嵌套交叉的样本外值**; 样本内数字只能作为"过拟合有多严重"的对照出现。
⇒ 闸: 每轴 |ρ| ≥ 0.30 且 嵌套CV R² ≥ 0.20 → 不过闸**不写标定文件**, 适配层继续拒绝映射 (诚实 > 好看)。
⇒ 一个诚实的失败也要留档 (`reports/*_FAIL.json`, 含 per-axis ρ 全表 + fails 列表 + 数据来源)。

## ④ 微调量级是硬约束 (别在几 epoch 上反复调参)
```
36 episodes / 18.6k 帧 / batch16 / 8 epoch 微调 84MB 预训练策略:
   动作映射最强 |ρ| 微调前 x 0.185 y 0.255 z 0.220  →  微调后 x 0.131 y 0.388 z 0.144
⇒ 无一致提升 (一维涨两维跌) ⇒ 量级根本不够"换动作空间"。
```
两条正路 (不要走第三条"继续小步调参"):
1. 按量级放大域内数据 (用解析控制器当 teacher 批量采几百回合) → 重训 → 再过同一道闸;
2. 改接它本来擅长的通道 (意向→流形门控), 动作仍由已验证链路出 —— 这才是"保留原生能力"的通常解。

## ⑤ 取证与来源字段 (老倪零容忍项)
- 配对数据每个文件必须记 provenance: `policy` (具体到 `weights_epoch_N.pt`) / `runtime` (paper|root) /
  `obs_source` (如 `engine_render 480²→224²(CHW)`)。缺任一项, 后面的相关性都无法归因。
- 加载自训权重: 目录里有多个 `.pt` 会撞 `Ambiguous checkpoint` → 传**显式文件名**
  `<policy_dir>/weights_epoch_N.pt` (相对 `$CACHE/checkpoints/` 解析), `INTACT_RUNTIME=root`。
- **校验加载的是哪个模型看 `dims.action_dim`** (论文 10 vs 域内微调 8/four_slot); 只看 `trained=true` 会被骗过。
- 输入真实性: 用引擎真渲染帧, 逐帧带 `obs_source`; 黑帧/合成 obs 上算出的任何相关性都是废数据
  (报结论前验图像 std > 5)。

## 一句话判据
**"它输出的是哪条通道的量?" → 用它与自身训练目标的相关性回答; 答不上来就还没资格谈标定。**
