# 分层职责更正 + 真机 L2 执行链 (老倪 2026-09-19 现场定稿)

## ⚠️ 分层职责以本表为准 (老倪现场更正, 推翻此前混用)
| 层 | 名称 | 职责 (一句话) |
|---|---|---|
| **LLM 大模型层** | DeepSeek VL | **理解场景** — 看清+说清: 目标是什么/位置/朝向/是否在夹爪上/画面质量/光照/背景线索/标定建议 |
| **L4** | INTACT | **工作安全 + 物理世界导航** — 否决/限幅/恢复预算; 在哪可以动、怎么走到目标(可达性/奇异点) |
| **L3** | — | **长程序列规划** — 选哪个目标、拆阶段、生成技能序列 |
| **L2** | — | **肌肉记忆操作** — 固化的原子动作序列(对准/下降/夹紧/抬起), 越练越顺 |

常见误标: 把 DeepSeek VL 标成 L3(它是 **LLM 层**); 把规划标成 LLM; 把 L4 只当"策略"而丢了"安全+导航"。
功能清单里的层标要同步: `feature_test_matrix.py` 的 F23(DeepSeek VL 场景理解) 层标 = **LLM**。

## 真机链路 (一次抓取的真实数据流, 已跑通)
```
Orin 真机帧(tap) ──► LLM: DeepSeek VL 场景理解 ─┐
YOLO(在役权重) 2D ──► 板坐标系/视觉常数 3D ─────┴─► data/scene_state.json (单一真源)
        │
        ▼
L4 闸门: power_state=on · operation_state=idle · has_error=false (有错先 /rokae_recover_estop 复位)
        │      + 可达性(目标点超范围/奇异点会 -50002, 改单轴小步)
        ▼
L3: 长程序列规划 (选目标模块 → 技能序列)
        ▼
L2: data/skills/l2_muscle/*.json → tools/l2_ros2_bridge.py (ROS2 转发) → Orin ROS2 服务
```
运行器: `gui-venv311/bin/python tools/l2_ros2_bridge.py --skill <json> --cycles N [--dry-run]`
每步: 三闸门 → 单步下发 → 取证(位姿/夹爪开度) → 落盘 `~/zmax_data/l2_muscle_run_*.jsonl`。
`--dry-run` 先打印将下发的完整字节(发前审字节, 不猜)。

## 现场作业协议 (踩过才知道, 必须遵守)
1. **人正在操作时绝不下发**: `operation_state=moving|drag` 或人在示教器上动 → 会互相干扰。
   实测两次 L2 步骤在人工操作期间跑, 读数全无效(success=False / z 与目标不符) ⇒ 先要"交给我"再发。
2. 每条动作前逐条请示 + 一次只发一个单步 + 全程前后取证(位姿/开度/图像)。
3. **先退后放**: 从插入位回槽位必须先沿反方向退出/抬起, 再平移下降; **禁止在插入位直接下降** (现场纠正)。
4. `success=False` + `error_code=ROBOT_IDLE_TIMEOUT` ⇒ 动作**通常已完成**, 判据看真值, **绝不重发**(会叠加)。
5. `collision_detection_enabled=False` ⇒ 撞了不会停: 下降分两级(先到中点观察, 再到底)。

## 视觉常数标定法 (俯视 eye-in-hand, 无手眼也能对准)
- 发一条纯平移指令(±X / ±Y 各 ~50mm) → 比同一目标 YOLO 框中心的前后像素 → 得 px/mm 与方向映射。
  实测: **基座 -X → 画面↓ 1.05 px/mm** · **基座 +Y → 画面← 1.12 px/mm** (两向对称 ✓)。
- 交叉验证: `fx ÷ (px/mm) ≈ 相机到目标距离` → 402px ÷ 1.07 ≈ 375mm, 与实测距离自洽 ⇒ 映射可信。
- 相机与夹爪刚性固连 ⇒ "把目标送到**夹爪像素**"即可对准; 夹爪像素可由"成功夹持瞬间目标框中心"反推
  (被画面边缘切半时要补全中心)。

## 显示约定陷阱 (现场必踩)
- 老倪的**面板显示 180° 翻转帧**, 本机 tap 原始帧未翻转; YOLO 按未翻转帧训练(翻转后 conf 掉一半)。
- ⇒ 报方向一律说「**朝画面中心 / 远离画面中心**」(两视图共同不动点), **不说左/右/上/下**,
  否则人看到的是反的("方向错了")。同一目标: 我帧左上 = 他帧右下。

## 抓取成功判据 (不依赖图像也能成立)
- 夹爪空载全合 ≈ 21; 夹牢模块 ≈ 185~250。抬升 100mm 前后**开度不变** ⇒ 未滑移 ✓ (掉件会掉到 ~21)。
- 合爪必须显式给力(见 real-arm-motion-control 技能): `target_pos=0 + target_force=40`。
