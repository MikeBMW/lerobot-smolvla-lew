# L4 演示档 (L4Demo) 全链 debug 实录 — 2026-09-10 六个实锤 bug

老倪连续 4 轮反馈同一画面("没拿起/夹爪乱转/机械臂自己抬升/光模块一跳一跳/螺旋/没插拔"),
曾断言"模型不对, 要重新训练" — 实际**动作回路里没有任何学习模型**, 全是 L4Demo 确定性伺服
代码的 bug。教训: 用户报乱象先查控制源与渲染层, 别顺着"重训"。

## 架构事实 (回答"谁在控制/渲染的是哪个模型")
- GUI 档位 L4 → simulink_module: `RealStateSpaceSim(seed=104, vision=False, demo_l4=True).run(cap="L4")`
  → `_run_demo()` importlib 动态加载 `tools/gen_l4_demo_video.py` 的 `L4Demo(seed=0)` → 全真
  metaworld 物理 8 段 (①来料转台90° → ②绕z抓横 → ③治具回正 → ④标准抓取 → ⑤插入 → ⑥拔出
  → ⑦AOI → ⑧光耦合)。引擎默认路径零改动 (仅 demo_l4=True 构造时走此分支)。
- GUI「🧭 3D 视图」(VEH.5.045) 数据源 = "程序执行轨迹 sim.run() N 步" — 播放的就是 L4Demo 的 tr。
- **tr len ≠ steps**: ① 转台 100 帧手动 `mujoco.mj_step` 只 `self.steps += 1` 不记录 tr
  (两次共差 ~200 帧) → 转台旋转动画过程在 tr/3D 缺失, 直接跳变。
- L4Demo tr 每帧: env.step → **先记录** peg 物理位置 → grip_lock/_grab **后钉** qpos (钉不更新记录)。

## 六个实锤 bug (现象 → 根因 → 修复)
1. **AOI 悬停掉 peg** (⑦): 悬停 60 帧 `step(zeros)` act[3]=0 不维持闭合力 → 仿真摩擦夹持滑脱
   (tr 帧级: peg z 0.081→0.008 掉台); ⑦ 空爪照样报 ok (只查悬停位置不查在位), ⑧ `_grab` 治具
   把掉地 peg 瞬移吸附到压电台 → 整链 success=True 掩盖掉件。修: 悬停保持 act[3]=1.0 +
   AOI 在位校验 (peg z>0.05, 否则中止不掩盖, commit e6484274)。
2. **动作高度过剩观感"机械臂自己抬升"**: ①避让 0.34m / ③抬爪 0.36m / 转移段"先抬 +0.18~0.20 再
   平移"层层叠加 → 手最高 0.457m。修: 避让/抬爪 0.20m, 转移抬升目标 z 封顶 0.32m (625f04e3)。
3. **②在 0.36m 天上空转 90°+悬停** (开场 7s 观感失控): 修为先降到模块正上方 15cm 再转 —
   动作目的肉眼可见, 爪扫掠 r≈0.073 < 间隙 0.11 安全。
4. **grip_lock 钉 peg 坐标系错** (用户"光模块一跳一跳/悬爪外/螺旋"真根因): step() 钉回用
   `hx @ rel_pos`, 而手基座含 −90°Y 旋转 (yaw≠0 时局部轴≠世界轴) → 世界系 z 向 −3.7cm 偏移被
   转成爪侧 −3.4cm → 抬升首帧 peg rel 从 (0,0,−37mm) 突跳 (−2,−34,+5)mm, 模块瞬移悬在爪侧面外
   跟着飞。④ 段同坑早修 (`_pin_world=True` 世界系钉回), **② 漏设**。修: ② grip_lock 建立前
   `self._pin_world = True` (b6cb54bc)。验证: 抬升全程 rel 恒定 (−5,−1,−33)mm, 单帧>2cm 跳多处→1。
5. **⑤插入偶发卡阻随机失败**: metaworld 同 seed=0 进程级微扰 (无渲染 4 连跑步数 4810-5247,
   渲染版偶发卡 11.7mm 中止)。修: 卡阻 (stall≥2 或深度<18mm) 自恢复 — 退 3mm + y/z 交替微调
   1mm 重对孔再推 ≤3 轮 (真机插拔同款, 427734a8)。4 新进程全 ok, 其一真实触发重试。
6. **3D 渲染层两坑** (tr 数据干净但画面乱 → 必查渲染):
   a. 播放跳帧: ss_dreamview 并行会话加 `step = n/800` → L4 4704 帧 = 5× 快进 (90° 旋转 0.7s 一闪
      = 观感"自己转一圈"; 插拔段 2s 快闪 = "没插拔"; L2/L3 短轨迹 <800 帧不跳帧所以平滑 — 用户
      对比 L2/L3 说差别就在这)。修: `step = max(1, round(n/1500))` ≈ 1× 物理速度 (48707eb1)。
   b. **夹爪双重旋转** (用户"夹爪无缘无故转一圈/螺旋"真根因): 旧代码 jaw 位置
      `jaw_lc = wrist + jaw_dir·gap` (jaw_dir 已按 yaw 转) 且 `_box_mesh_yaw(rot_center=_wrist)`
      又绕 wrist 转一次 yaw → 位置实际绕 wrist 转 **2×yaw**: yaw=90° 时画 180° 半圆弧回对侧 +
      静止位错对不上横放模块 (观感没夹住)。修: 位置用未旋转 ±y 基准 `wrist ± (0,gap,0)`, box 统一
      绕 wrist 单次转 yaw → 位置 Rz·(0,±1)·gap ✓ 朝向 Rz·x̂ ✓ 同时正确 (60646388)。

## 取证方法 (复用到任何"画面乱"类问题)
- **控制源先于重训**: L4/L4Demo 无模型在回路 → 先确认谁发指令, 再谈模型。
- **数据层 vs 渲染层分离**: CLI 重放 GUI 同链路拿 tr (无渲染全链仅 ~2s), 分析: hand_yaw 旋转事件
  (含 360° 包装检测: Δ>180 减 360)、阶段分布 Counter、peg−hand rel 恒定检查。数据干净 → 查渲染。
- **真夹判据 = mujoco 接触**: 遍历 `d.contact` 找 pad↔peg geom 穿透 (7 处 ≈ 真夹); pad-peg 几何
  中心距 ~32mm 是正常夹持几何 (模块半宽+爪半厚), **不是夹空证据** — 别用几何距离判夹空。
- **单帧大跳时刻表** (>2cm 逐帧列出 t/段/坐标) 定位钉 peg/治具切换帧。
- 验证顺序: 无渲染全链 → 渲染版 (main(), 会 ensure_scene 重生成 XML, md5 确定性) → **多新进程连跑**
  防 seed 随机 (每次全链仅 ~2-8s, 迭代极快)。
- GUI 运行日志 = /tmp/simulink_log.txt (真实化运行/演示全链/3D 数据源行), 用户操作还原首选。
