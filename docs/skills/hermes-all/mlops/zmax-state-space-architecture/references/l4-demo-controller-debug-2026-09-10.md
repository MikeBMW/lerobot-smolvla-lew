# L4 演示档 (L4Demo) 调试实录 2026-09-10

触发: 用户报"L4 档没拿起光模块/夹爪乱动/机械臂自己抬升/夹爪转一圈/轨迹螺旋/没插拔", 断言"模型不对要重训"。
第一判断: **L4 档动作回路没有学习模型** — 跑的是 L4Demo 确定性伺服控制器 (tools/gen_l4_demo_video.py), 重训无解。先查代码+数据, 别顺着"重训"走。

## 链路与取证方法 (可复用)
- GUI L4 档: simulink_module cap=L4 → `RealStateSpaceSim(seed=104, demo_l4=True).run(cap)` → importlib 动态加载 gen_l4_demo_video.py L4Demo → tr → 3D ss_dreamview 播放。**改 gen_l4_demo_video.py 不用重启 GUI (每次运行读磁盘); 改 ss_dreamview.py/simulink_module.py 必须重启 GUI**。
- 3D 视图 (VEH.5.045) 数据源查法: `/tmp/simulink_log.txt` grep "能力档位 →|真实化运行完成|3D 视图数据源" → 确认播的是哪次 run 的 tr。
- 无渲染重放取证: `L4Demo(seed=0, record=False).run_all()` ~2s 跑完 4700+ 步, 然后逐帧分析 tr (旋转事件/peg-hand rel/阶段分布)。
- 接触判定用 `d.contact` 遍历 geom 名 (pad↔peg 穿透深度), **不要用 pad 中点−peg 中心几何距离** (~30mm 是两半宽之和, 会误判"夹空"——②④ 真夹时几何距离仍 32mm)。
- 夹持真伪判据: peg−hand 相对差 (rel) 序列夹持中应**恒定**; 突变 = 钉 peg 位错。

## Bug 1: AOI 悬停掉 peg + 假成功链 (老倪红线: 假数据)
- ⑤ 段真物理插拔解除刚性锁后靠仿真摩擦夹持; ⑦ AOI 悬停 60 帧发 `step(zeros(4))` (gripper=0 不维持闭合力) → peg 滑脱掉台 (tr 帧级: peg z 0.081→0.008)。
- 后续假成功: AOI report 只查悬停位置不查在位 → 空爪 ok; ⑧ 光耦合用治具 `_grab` 把**掉在地上的 peg 瞬移"吸附"到压电台** → couple ok → 整链 success=True 掩盖中途掉件。
- 修: 悬停全程保持闭合力 act[3]=1.0 + 在位校验 (peg z>0.05; 掉台 z≈0.015) → 掉件即中止不掩盖。

## Bug 2: 动作编排观感 (老倪: 机械臂自己抬升/末端自己转)
- 原: ① 避让 servo 到 z=0.34; ② 在 0.36m 高空 ramp_yaw 空转 90° 再悬停 1.7s; 每段转移先抬 +0.18~0.20 → 手最高 0.457m (模块 0.423)。
- 修: 避让/抬爪降到 0.20; 转 90° 改为**模块正上方 15cm** (z≈0.171, 爪扫掠 r≈0.073 < 间隙 0.11 安全) — 目的可见; 转移抬升封顶 0.32 (手 0.457→0.356, 模块 0.423→0.322)。动作要"像人干的": 高度够用即可、旋转贴任务不空转。

## Bug 3: grip_lock 钉 peg 坐标系 (老倪: 光模块一跳一跳/悬爪外/轨迹螺旋/像没夹住)
- 症状: 抬升 servo 第一帧 peg rel 从 (0,0,−37mm) 突跳 (−2,−34,+5)mm → 光模块被钉到夹爪**侧面 3.4cm 悬空跟着飞**。
- 根因: `step()` 钉回 `q[peg] = hand + hx @ rel_pos`; rel_pos 采的是**世界系偏移**, 而手基座含 −90°Y 旋转 (mocap quat = 绕z(yaw)∘Ry(90°), yaw90° 时局部轴≠世界) → 世界 z 向 3.7cm 被转成爪侧偏移。
- 修: 夹持建立处统一 `self._pin_world = True` (世界系钉回 `hand + rel_pos`)。④ 段早已有此修复 (注释实锤"钉穿盘面 Δz=−0.011"), ② 段漏设 — 新段一律 _pin_world=True, 别用 hx@rel_pos 路径。

## Bug 4: 插入卡阻随机失败 (metaworld 进程级微扰)
- 同 seed 无渲染连跑 3 次 (同进程) 全成功但步数不同 (4810-5247); **新进程**渲染版偶发插入卡阻 11.7mm 中止 (成功阈值 ≥18mm) → 单次成功/同进程连跑不可信。
- 修: 卡阻自恢复 — stall≥2 或 <18mm → 退 3mm + y/z 交替微调 1mm 重对孔 ×3 轮 (真机插拔同款)。验证: 4 个新进程全 ok (48.6-49.7mm), 其一真实触发重试成功。

## Bug 5: 3D 播放 5x 跳帧 (老倪: 夹爪自己转一圈/轨迹跳/没插拔)
- 并行会话为"长轨迹逐帧播 4.5 分钟太慢"加 `step = n/800` → L4 4704 步每 tick 跳 5 帧 = 5 倍速: 90° 旋转 0.7s 一闪 (= "自己转一圈"), 伺服大步变跳点 (不平顺/直上直下), 插拔段 2s 快闪 (= "没插拔")。L2/L3 短轨迹 (352 帧 <800) 不跳帧 → 平滑 → 用户误以为 L4 模型差。
- 修: 播放速度恒定 ~1× 物理: `step = max(1, round(n/1500))` (4704 步 ≈ 94s, timer 60ms)。短轨迹仍逐帧。
- 方法: **tr 数据层干净 (旋转仅 ±90°×2、①-⑧ 全段、done=True) 时, 观感问题查播放/渲染层**, 别怀疑模型。

## 交付验证
每修一个 bug: 无渲染全链重跑 + 关键量断言 (rel 恒定/无掉台/插入深度) + 生成 mp4 证据 (main() 会 ensure_scene 重生成 XML, 确定性 md5 相同; 渲染版才是用户同条件)。
