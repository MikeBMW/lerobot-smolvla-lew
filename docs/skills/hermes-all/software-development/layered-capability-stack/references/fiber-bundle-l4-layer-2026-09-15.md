# L4 纤维丛联络层落地实录 (2026-09-15)

场景: INTACT 世界模型**预测的 z 潜空间** → 流形专家预测器 → 接触丛/性能丛 → DiT 生成轨迹。
需求原话: 「动作丛 → 接触丛; 应用纤维丛的映射联络关系; 光模块插拔对性能流形没啥作用, 主力是接触流形;
最后进 DiT; **要让每条 L4 的线条都有实际的数据**; 不能降低 L2/L3 的性能, 要叠加增强 L4。」

## 一、丛结构与联络 (设计模板, 可复用到别的工程)

| 丛 | 底空间 | 纤维 | 角色 |
|---|---|---|---|
| 动作丛 A | 相位/进度 | 执行/意图矢量 (下层参考场 = canonical 水平场) | 参考 |
| 潜空间丛 Z | 同上 | z ∈ R^192: z_t / z_goal / **z_pred=predictor(z_t,a)** | 上层预测 |
| 接触丛 C | 同上 | F_C(6) = [e∥, e⊥, V, V̇, v∥, v⊥] | **主力** |
| 性能丛 P | 同上 | F_P(6) = [η, δ⊥, δ_axial, δ⊥xyz] | 次要 (只作条件, 不参与幅值) |

联络件:
* 丛映射 Φ: Z→F_C = `W·z + W_q·φ(PCA₈(z))` (线性=联络系数; **二次项让曲率可非零**)
* 水平提升 `h_z = Φ(z_pred) − Φ(z_t)` (沿预测潜空间方向的协变导数)
* 挠率 `κ = ‖h_z − h_geo‖` (潜空间联络 ⊖ 几何联络), `cos∠` 作可信度
* 曲率 `Ω = Φ(z_t+δa+δg) − Φ(z_t+δa) − Φ(z_t+δg) + Φ(z_t)` (交换子)

**自检判据 (必做)**: 线性 Φ 的 ‖Ω‖ 必须 ≈0; 二次 Φ 的 ‖Ω‖ 必须 >0。否则"曲率项是摆设"。

标定数据 = 引擎真跑逐帧采的成对样本 (z_t/z_pred/z_goal, 接触/性能真值, 几何 z7);
标定 = ridge + **LOO 交叉验证**, 闸值 `R²_loso ≥ 0.30 且 null < 0.10` (与同仓既有闸一致)。
实测 (n=582, 8 seed×900 步): Φ_contact 0.471 / A:z_pred→z7 0.607 / Φ_geo 0.586 / Φ_p 0.410。

## 二、下游接线 (只产条件, 绝不写执行量)

1. 预测器输入换源: 既有训练权重**一字未改**, 只把 z 从"当场几何 z7"换成 `ẑ7 = A·z_pred + b`
   (丛映射 Z→几何基)。这样"用预测潜空间喂预测器"不需要重训。
2. DiT 条件 token 叠加 (不替换): `[δ̂(192) ⊕ ĥ_z(6) ⊕ Φ(z_pred)(6) ⊕ Φ_p(z_pred)(6) ⊕ 标量]` = 214 维
   经同一个 `apply_l4_cond` 机制进 DiT (该实现会按输入维自动重建投影)。
3. 唯一执行出口不动 (`sched.decide` + `safety.saturate`); 融合走能力栈收缩投影 (clip/veto 记账)。
4. 环境守卫 `SS_L4_FIBER=1`; 不设 = 逐位零变化。

## 三、四个真坑 (这次踩到的)

1. **桥的白名单会吃键**: worker 导出了新键 (z_pred), 但 `model_adapter` 只 `{k: ... for k in ("z_t","z_goal","delta")}`
   → 下游永远拿不到, 表现成"导出了却没人收到"。改导出*必须先看消费侧的白名单/拷贝*。
2. **采数不能依赖"已就绪"**: 若采数写在"标定过闸之后", 会出现 `没标定→没采数→永远标不了` 死锁。
   正确姿势: 未过闸也**照跑照采**, 只把注入权重设 0 (诚实拒绝)。
3. **零回退仪器前提**: 大模型 CPU bf16 路径有 FP 级非确定 + 推理含随机噪声采样 ⇒ 同配置两臂跑两次
   逐位 hash 也可能不同。必须 **先证仪器**: 同配置跑两臂, hash 相同才敢用 hash 当判据; 否则改用
   结构性判据 ("新代码在两臂计数都为 0" + 唯一出口未动)。
4. **行号写死会误导**: 证据脚本里按行号定位断点行 (如 loss 行 307) 会随文件增长漂移 → 误报"命中 0 次"。
   一律按源码内容动态定位 (可加锚点: 在 `class X` 之后再找 `def forward(`)。

## 五、汇报口径 (三段分开)

接线段: 逐条给计数/hash/夹紧量 + 可复现命令。
质量段: 标定 LOO R²、挠率/曲率真实数值; 未过闸就写"不注入"。
闭环段: 未跑就写"未跑" + 缺口清单 (哪几条边死线、为什么、下一步怎么补)。
