# 自适应增益 + 李群意图层 落地实录 (2026-09-16)

场景: Z-MAX 状态空间引擎。需求原话 (老倪) 两段:
① "前馈 MLP 主执行这个通道, 需要参考卡尔曼滤波增益的方式 —— 增益大了更相信 L4, 增益小了默认
   使用 L2 前馈加速器 (肌肉记忆, 直接连物理世界); 泛化场景或被干扰后 L4 增益被抬升。即
   **L4 是导航增益, L3 是流程增益, L2 是实际动作执行**; DiT 把 L4 意图转成流程动作, 流程动作
   又被 L2 肌肉记忆修正, 最终物理执行。"
② "INTACT 的动作意图, 纯旋转用 SU(2), 完整刚体动作 SE(3), 关节空间 T^n; 把意图输出、动作流形、
   接触流形、性能流形按 SE(3)/SU(2) 结构设计, 经 DiT 解码成前馈加速器能接受的 action,
   中间的增益由 L2/L3/L4 记忆层协调调整。"

## 一、仲裁层 (卡尔曼式自适应增益) 的可抄结构

- 模块: `src/lerobot/manifold/adaptive_gain.py` — `GainScheduler` / `GainOut` / `vec_hash`,
  纯 numpy, 含 5 条自检判据 (零回退 hash / 熟场景衰减到 0 / 受扰抬升 / 扰动消失回落 /
  5000 组越界 0 违规 + 增益上界)。
- 递推: `P⁻ = κ·P + Q0 + ΣQ_event`; `K_i = P⁻/(P⁻+R_i)`; `u = u⁻ + K_nav(y_nav−u⁻) + K_flow(y_flow−u⁻)`;
  `P = (1−K_eff)·P⁻`, `K_eff = 1−(1−K_nav)(1−K_flow)`; 每步 κ=0.90 衰减。
- **熟场景零增益闸**: `P⁻ ≤ 1.6·Q0/(1−κ)` → K **硬置 0** (逐位纯下层)。不加这个, K 会稳在
  ~0.01 的残留上, "默认用 L2" 这句就不成立, A/B 也没有干净判据。
- 事件→Q (全部可测, 无手感系数): `ood`(39 维观测用左脑 MLP 自带 sm/ss 归一后 max|xn|/DOMAIN_SIGMA − 1) /
  `mm_miss`(muscle.get_champ(seed,stage) 无标杆) / `innov`(|ν| > 3√R → 超门幅度) /
  `stall`(本阶段任务势 25 帧窗口几乎不降) / `stage_switch`。权重: 0.05 / 0.03 / 0.04 / 0.06 / 0.02。
- 肌肉记忆修正项 (老倪"流程动作被 L2 肌肉记忆修正"): `u ← u + K_mm(u_champ − u)`,
  `K_mm = 0.35·(1−K_nav)` ⇒ 熟场景(K 小)标杆强、受扰(K 大)标杆让位。
- 接线点两处 (都 opt-in, `SS_ADAPT_GAIN=1`, 不设=一行不改):
  1. 引擎直连线融合口 (sched.decide **之前**): K_nav 替代固定 w=0.3; K=0 时**不 commit** (逐位纯 L2)。
  2. 直驱档闸内 (`tools/intact_direct_rollout.py`): `w_eff=cos` 换成 K_nav (cos≥0.9/幅度≤1.5×/阶段白名单三闸保留)。
  为防 DiT 计两次: 增益档下把 DiT 固定 β 让位, 两路分别留档 (`_l4_last_u0` 导航 / `_l4_last_ud` 流程)。

### 实测 (600 步 × 11 臂, 每臂独立进程, `SS_MUSCLE_PATH` 冷隔离, 热 seed 有标杆 / 冷 seed 无标杆)

| 臂 | seed | 场景 | dmin mm | dfin mm | K_nav 均 | refused | 事件 |
|---|---|---|---|---|---|---|---|
| base | 0 | 有标杆 | 285.8 | **336.9** | — | — | — |
| gain | 0 | 有标杆 | 336.9 | 441.3 | 0.268 | — | stall 294 |
| gain+对齐 | 0 | 有标杆 | 336.9 | 338.4 | 0.390 | — | stall 453, ood 133 |
| gain+对齐+闸 | 0 | 有标杆 | 336.9 | 338.4 | 0.390 | 0 | 同上 |
| base | 777 | 无标杆 | 18.5 | **23.4** | — | — | — |
| gain | 777 | 无标杆 | 16.6 | 51.0 | 0.346 | — | mm_miss 427 |
| gain+对齐+闸 | 777 | 无标杆 | 16.7 | 48.0 | 0.341 | **40 (6.8%)** | mm_miss 419, stall 116 |
| gain+对齐 (闸=0) | 777 | 无标杆 | 16.7 | 47.2 | 0.342 | 0 | — |

结论 (诚实): 机制生效且方向正确 (熟场景 K 尾 **0.0** + 肌肉快通道命中 564/600 帧; 泛化 K≈0.34~0.4;
开关关闭时 `gain.steps=0`), 但**抬增益没有收益** —— 所有 gain 变体终点差于 base, 只有最小距离略好。
根因: 上层动作本身质量差于 L2 (与离线判闸一致: 动作幅度塌/std 小 16 倍) ⇒ 增益是放大器。
⇒ 保持 opt-in, **不进默认档**; 下一步前置条件 = 质量闸 (上层在本场景优于 L2 才允许 K>0)。

## 二、李群意图层 (SU(2)/SE(3)) 的可抄结构

- 模块: `src/lerobot/manifold/lie_intent.py` — SU(2) 四元数运算 (双覆盖消歧 w≥0) / SE(3) 闭式
  exp∘log / `contact_twist(T_peg,T_hole)=log(T_hole⁻¹·T_peg)`(孔系表达的接触误差, 位置+姿态同一 twist,
  刚体变换不变性 8e-17) / `LieGainBlend`(切空间融合 + 方向幅度闸) / `LieIntentMap`(PCA+ridge+LOO)。
  自检 11/11: SE(3) exp∘log 4.5e-16, 群合成 1.4e-17, 测地线中点 90°→45.0000°, K=0 逐位回退 hash 相同。
- 教师标签的真值路径 (可抄): 每帧从物理引擎读 **末端/工件/孔口位姿** → 逐帧差分
  `ξ_true = log(T_ee(t+1)·T_ee(t)⁻¹) ∈ se(3)`, `ω_true = log(ΔU) ∈ su(2)`。
  ⚠️ MuJoCo 3.x `MjData` **没有 `site_xquat`** (只有 `site_xpos`/`site_xmat`) → 用 `site_xmat` 转四元数
  (Shepperd 分支); 写错键会**静默采到空** (npz 少一整个 key → 标定脚本报"无样本")。
- 标定 (352 对逐帧样本, 8 seed × 400 步真跑): Φ_su2 R²_loso **0.806** (null 0.080),
  Φ_se3 R²_loso **0.712** (null 0.076); 逐维 [0.14, 0.23, **0.82**, 0.44, 0.06, 0.51]
  ⇒ 绕插拔轴的旋转最强、横向平移最弱 —— 与"插拔主力是绕轴对准"及既有"横向不可辨识"结论一致。
- 接线 (opt-in `SS_L4_LIE=1`): ① Δz --Φ--> [ξ(6) ⊕ ω(3)] **追加**进 DiT 条件 (192→201 维, 不替换);
  ② `ξ` 的平移部分取单位方向 × **L2 幅度包络** 作导航参考 (上层只给方向, 不放大);
  ③ 逐帧列 `lie_xi`/`lie_omega` 入 trace (每条线可审计)。
- 实测 (L4line 120 步): frames 15 · ran 15 · applied 15 · cond_dim 201 · 导航方向与 L2 的 cos 均 0.813,
  增益闸真否决 21 帧 (能力栈里留下 `⛔否决(cos=0.198 超幅)`)。
- 未完成的诚实边界: DiT **真消费** 201 维条件未跑 (CPU 上 DiT 几十秒/次, 120 步 >900s);
  动作空间只有平移 ⇒ 切空间融合退化为欧氏 (别宣称"用上李群"); 网络权重未重训 ("换源不重训"纪律)。
