# 功能清单 ↔ 测试用例 追溯矩阵 + 验证脚本腐化 (2026-09-18 实测)

老倪原话: 「**功能清单和测试用例都要对应**」。这是交付门槛的一部分 (与他既有的
"交付=有提升非仅不回退"、"要证据才认完成" 同源)。

## 一、跑一遍 `verify_*.py` 得到的 PASS/FAIL ≠ 功能好坏

实测: 25 个验证脚本 → **15 PASS / 10 FAIL**; 逐个查根因后 **5/10 是脚本自身腐化**, 不是功能坏。
先把 FAIL 分三类再动手, 否则会把好功能"修坏"或者白改一天。

| 腐化形态 | 实例 | 修法 |
|---|---|---|
| **期望过时** | 代码默认类别早已 `optical_module → peg`, 脚本仍断言旧名 → FAIL | **先读代码/注释判哪边对**。本例代码注释写明"旧名在 CLASS_MAP 无条目 → 真机权重接不进感知链, 光模块那路恒空" ⇒ 代码对 → 改**脚本**并在断言文案里写清依据 |
| **路径写死** | `ROOT = "/home/tashan/zmax_yolo"` (别人家目录) → `PermissionError` | 路径自适应 (`if os.path.isdir(alt) else <本仓根>`); 该脚本本来就是给 Orin 写的 |
| **脆弱快照断言** | "连线数应比上版少 1" 依赖 `/tmp/state_space_obs.bak2.json` | 改成**稳健子集判据** ("旧连线全在") 或容差 (`>= len(base)-1`); 别把某个历史 diff 钉成永久不变式 |
| **用例缺失** | 矩阵里 2 个功能指向不存在的脚本 | 补写用例 (不是删功能); 补时把 path 与 import 一次配齐 (`sys.path` 要含 `src` **和** `tools/gui`) |
| 环境依赖 | `ModuleNotFoundError: lerobot` (脚本没在 `PYTHONPATH=src` 下跑) | 脚本自加 `sys.path.insert(0, ROOT/'src')`, 别依赖调用方 |

**纪律 (红线)**: 改测试让它过之前, **必须先证明代码是对的** (注释/调用点/数据佐证), 并把依据留在
断言文案或注释里。否则就是把"为过测而篡改"包装成交付。

## 二、矩阵怎么建 (可复用)

1. 每条功能按**能力**命名, **禁算法词**: 写「按意图零搜索产出动作块」, 不写「INTACT actor 前向」;
   写「坐标系间无损变换」, 不写「flight.py to_port()」。每条给全: `ID | 能力 | 层 | 开关 | 对应用例 | 判据 | 状态`。
2. **一功能一用例**, 且判据**机器可判** (非零/非常量/往返误差<1e-9/候选搜索数=0/留一R²≥0.30 …)。
3. 输出两件事: ①正向通过率 ②**反向检查"无对应用例的功能"** —— 必须为 0。
   只报通过率会漏掉"写了功能没测"这一类。
4. 落地成可跑的脚本 (`tools/feature_test_matrix.py`): 直接跑全表, 功能增删自动暴露缺口;
   三种用例类型都支持 —— `python`(直接 import 调函数) / `script`(跑 `tools/verify_*.py`) / `self`(静态自检, 如唯一出口计数)。
5. 静态自检也是功能: 例「各层开关独立(无档位互斥)」= 正则扫 `unsetenv|del os.environ` 命中数 == 0;
   例「唯一执行出口」= `u, stage = self.sched.decide(` 计数 == 1。

## 三、案例: 13 项功能矩阵 (L0–L4 + 仿真/真机切换)

```
F01 输出单步控制量           L3   SS_L3            → 控制量非零且在界内
F02 按意图零搜索产出动作块    L4   SS_L4_INTACT     → 候选搜索数=0 且动作块非零
F03 坐标系间无损变换         L4   —                → 往返误差 <1e-9
F04 潜空间→几何基映射        L4   SS_L4_INTENT_LINE→ 留一 R² ≥ 0.30
F05 接触条件注入(可关)       L4   SS_L4_FIBER      → 关闭时逐位相同
F06 上层参考被收口夹紧        L2   —                → 越界 100% 被夹紧
F07 任务进展势函数不增        L2   —                → 逐帧单调不增
F08 仿真/真机数据源隔离       L0   ZMAX_ANNOT_ROOT* → 两源互不污染
F09 数据源可随时切换         L0   ZMAX_ANNOT_ROOT  → 切换后状态正确
F10 画面来源如实标注         L0   —                → 标注=真实来源
F11 各层开关独立(可叠加)      ALL  SS_L4_*         → 无档位互斥
F12 唯一执行出口             ALL  —                → 出口计数=1
F13 仿真↔真机随时切换        ALL  MODE_ORDER       → 三模式入口在
```
F08/F09/F10/F13 就是"仿真与真机随时切换"这项能力的用例集 —— 老倪提这种要求时,
先在矩阵里找出**属于该能力的既有用例**, 用它们的红/绿回答, 而不是另写一段演示。
