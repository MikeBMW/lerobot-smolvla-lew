# 同口径 A/B 与零回退判据（判「该通道能否进默认档」时）

场景: 新通道（新模型/新联络层/新节点出口）已接线+标定+零回退，问题是**它到底有没有提升**，
以及**能不能进默认档**。老倪的门槛是「交付 = 有提升非仅不回退；未证明提升不得进默认档」。
本文件是 2026-09-15 一次真实 A/B 的教训（纤维丛联络层 SS_L4_FIBER 0/1 两臂）。

## 1. 标准做法（照抄）

```bash
export INTACT_RUNTIME=root INTACT_POLICY=intact_l4_current SS_L4_INTACT=1
for arm in 0 1; do
  if [ "$arm" = "1" ]; then export SS_L4_FIBER=1; else unset SS_L4_FIBER; fi
  timeout 3000 <venv>/bin/python tools/intact_direct_rollout.py --mode full \
    --seeds 104,105,106 --max-steps 4000 --infer-every 1 --baseline 1 \
    --video-dir reports/evidence_ab_<通道>_f$arm
done
```
- **同轮同口径**: 两臂跑**同一批 seed**、同一 `--max-steps`、同一 `--infer-every`。
- 每臂出报告 json (`reports/intact_direct_<时间>.json`, 含 `meta` + `rows`) 和独立视频目录。
- 开关**默认关**（env flag 才开）；默认关 = 零回退由构造保证。

## 2. 样本量坑 —— 最容易骗自己的地方

名义 n ≠ 有效 n。若 seed 集里含**物理上不可能**的 seed（解析链自己也失败，即该几何下任务无解），
它两臂都失败，**不携带任何区分信息**。

实测（纤维丛 A/B, n=3）:
| seed | 解析链(对照) | 臂0 (fiber=0) | 臂1 (fiber=1) |
|---|---|---|---|
| 104 | pass/878 | pass/948 | pass/949 |
| 105 | fail/3000 | fail/3000 | fail/3000 |
| 106 | fail/3000 | fail/3000 | fail/3000 |

→ 成功率 `1/3 vs 1/3`，**有效样本 n=1**（只有 seed 104 携带信息）。
在 1 个样本上相等**既不能判死也不能判活**该通道。

**规矩**: 结论必须显式写出「有效样本数」；有效 n 太小（≤2）时报告应给"扩样本"选项
（如 10 seed × 2 rep）而不是下结论。这与"单次评估不可靠·必多重复"是同一条纪律的延续。

## 3. 零回退判据（三种，按档位选对）

| 判据 | 适用 | 说明 |
|---|---|---|
| **逐位 trace_hash** | 可确定的档位（L2 解析链路径） | 同种子同配置应逐位相同。实测 L2 档 f0/f1 hash 完全一致 = 零回退成立 |
| **链路计数 = 0** | 不该进新代码的档位 | 新通道的 frames/calls 计数为 0 ⇒ 代码根本没进那条路 |
| **结构不变 + 行为一致** | **有 FP 非确定性的档位** | 不能用 hash！ |

⚠️ **FP 非确定性档位禁用 hash 当判据**: 实例是 625M 模型 CPU bf16 路径 —— 同配置两趟 hash 也不同，
播种 + 单线程也一样（已复现 3 次）。这种档位改用「新代码未进 + 结构不变 + 可确定档位逐位相同」三件事代替。
**不要为了凑一个漂亮的 hash 判据而假装它成立。**

L4 档**按设计可变**（叠加生效），f0/f1 hash 不同是预期，不是回退。

## 4. 判定与汇报模板

```
A/B 同口径: 名义 n=3 · 有效 n=1
  臂0(fiber=0): 1/3 · 臂1(fiber=1): 1/3 · 步数 948 → 949
判定: 不满足提升门槛 → 通道保持**默认关**（env flag 开启）
零回退: ✅ 成立（L2 逐位 hash 相同 + 不对应档位链路计数=0）
局限: 有效样本 1，不足以定论；建议扩样本 10 seed × 2 rep 后复判
```

**禁止**: 把"没回退"说成"有效"；用名义 n 冒充有效 n；在小样本上宣布"该层无用"而撤销接线
（接线+标定+开关是有价值的沉淀，撤销的应该是"进默认档"这个动作，不是产物本身）。
