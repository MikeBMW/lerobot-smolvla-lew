# 长轨迹数据平均化 (2026-08-08 核心发现)

## 现象
300 步完整插拔轨迹（官方专家 Phase1-5: 接近→抓取→抬起→转移→插入）训练后，
ACT/SmolVLA/LEW/VLA-Touch/AWE **全部学成"后退/不动"**：
- 评估 0/10 抓起，距孔=初始值
- 手动 rollout: hand 距离 peg **增大**（0.157→0.322m）
- 动作输出**恒定**（如 [-0.343, -0.347, -0.031] 5 步不变）≈ 数据平均动作

## 根因
多阶段轨迹里"接近"（朝 peg）和"插入"（朝 hole）方向**相反**，
行为克隆回归拟合的是**平均动作** → 学到原地踏步/微小漂移。
类比: 让学徒同时"向前走"和"向后走"，只能原地踏步。

## 证据
- 全动作均值 [-0.527, -0.02, -0.127] 非零但接近抵消
- 前半均值 vs 后半均值方向不同
- MLP 蒸馏（90000 样本/300 轨迹）6/10 抓起 3/10 插入——**免疫**
  （39D 坐标→动作直接映射，每步独立决策，无时序平均化）
- 官方专家（39D 坐标规则）85%——同样用坐标不用图像

## 解法
1. **分段数据**: 截断到"抓起"即停（stop_after_grab），方向一致
   - 实测轨迹 93/104/84 帧（vs 300 满帧）
   - 夹爪闭合占比 36%（vs 7%）
2. **坐标叠加架构**: latent += state 投影（坐标逻辑主线），图像降为背景 token
3. **RL 无解**: PPO 60 轮 0%（奖励稀疏 -9.9 卡住），RL+夹爪规则也 0%（位置也没学好）

## 关键结论
**插拔能力取决于"感知到目标精确坐标"而非模型架构**：
- 给纯坐标（39D）→ 学会（MLP/专家）
- 给图像+坐标混合 → 学不会（视觉大模型）
- 真实产线解法: YOLO 检测→3D 坐标→喂模型（仿真=真机同构）
