# 案例: peg-insert "抓不起工件" 5 项根因链 (2026-09-07, Z-MAX commit c142b55a)

现象: 状态空间 ▶运行 3D 视图, 机械臂总是无法抓起销钉(光模块), 500 步反复尝试 0 成功。
复现: 视觉闭环同参单轮 500 步 0/1 (下降 230-280 步 + 抓取滑脱循环)。
修复后: 352 步完整 抓起→抬起→转移→插入→完成, 3/3 确定性复现。

## 五项根因与证据 (全部数值探针钉死)
1. **深度 scale 常数过时** (0.978→0.9616): 10 布局初始帧隐含真 scale 0.9577-0.9674 平均
   0.9616 → peg 3D 系统偏 2-5cm。误差 1:1 深度传导 (真值深度代入公式仅 2mm 误差)。
2. **obs 索引取错**: geom peg_z0 = o[4] 取到 peg **x** (obs 段 [4:7]=xyz, o[6] 才是 z) →
   抬升锚错位。修复 o[6] 后 R0 回归不伤 (353→343 步, 不伤反快) — 旧值靠抬升目标补偿巧合能跑。
3. **真值泄漏 (红线)**: 视觉未检出时回退 obs 真值 o[4:7] 冒充检测 → 改保持上次估值;
   未定位时目标=原地悬停等检出。
4. **遮挡幻影**: 夹爪进入销上方 ~10cm (斜视角), 检测框锁夹爪 (z=0.083=夹爪高, 误差 82-92mm;
   混合框 z≈0.064 半幻影漏过 3.5cm 窗)。修复 = 定位状态机 + z 窗免疫 ±2cm + 大跳变 2 帧确认。
5. **夹持后偏移未锚定**: peg_head 用视觉锁存偏移 (残差 2.5mm + 销在钳内轴向滑 5-7mm) →
   转移路径擦孔沿 → 撞击滑脱掉件 (首抓成功→转移掉→重抓死循环, 掉落后视觉重定位又失败)。
   修复 = 随动验证稳定 (≥15 帧 & 偏差<8mm) 后锚定 off0=实测值。⚠️ 阈值 5mm 太紧会漏锚。

## 关键探针 (误差分解三步法落地, 全部入库 tools/probe_r1_yolo_*.py)
- err.py: 初始帧 2D 中心 vs 真值投影 (自推 forward_project v 公式反号 → 误报"垂直翻转",
  改用训练数据生成器投影函数为准)
- err3.py: 真值深度代入公式 → 2mm → 公式/2D 无责, 锁定深度
- calib.py: 10 布局隐含 scale 标定 → 0.9616
- err2.py: 深度分位扫描 → 中位数最优 (低分位是夹爪前景; 背景污染假设证伪)
- plane.py: 2D+平面 z 方案 → 运行期 2D 中心也漂 244mm (遮挡让 2D 全崩) → 深度反投影相对稳

## 数据佐证 (数字)
- 单帧静态 (手远离) 定位 1mm vs 运行期 (手移动) 30-51mm — 评估必须沿轨迹采样
- YOLO 检出率 79%→100% (修复后); peg 定位误差 51mm→2.5mm (悬停锁存值)
- R0 (真值感知) 同 seed 343 步成功 vs R1 (视觉) 修复前 500 步失败 → 视觉为瓶颈, 修复后追平
- R1 多布局 2/6: 物理难布局与 R0 同分布 — 视觉非瓶颈后暴露真实物理上限
