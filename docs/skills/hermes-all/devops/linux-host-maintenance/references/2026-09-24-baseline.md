## 5. 复现命令骨架
```bash
# 清理 (写脚本文件再跑, 不要内联长命令)
U(){ df -BM / | awk 'NR==2{print $3}' | tr -d M; }; B=$(U)
sudo journalctl --vacuum-size=200M
sudo rm -f /var/log/{syslog.1,kern.log.1} /var/log/*.gz; sudo rm -rf /var/log/installer /var/crash/*
sudo apt-get clean && sudo apt-get autoclean
rm -rf ~/.cache/{pip,uv}/* ~/.cache/{thumbnails,tracker3,mesa_shader_cache,mesa_shader_cache_db}/* \
       ~/.cache/{gnome-desktop-thumbnailer,gstreamer-1.0,LarkShell}

rm -rf ~/.local/share/Trash/{files,info}/*
```

1. **别拿"发一条测试消息"当探活**: 兜底通知脚本 `feishu_notify.py` 没有 `--probe` 参数, 传进去的
   `--probe` 被当**正文**发进了群里 → 先 `read` 脚本用法, 探活走只读接口/health 端点。
