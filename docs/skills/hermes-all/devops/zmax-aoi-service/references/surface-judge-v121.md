## 场景实测(2448x2048 原图)

- 背景是**暗机台**(灰度 21~63); 光模块 = 横向长条, **顶面过曝到 250~255**(无内部纹理)。
- 模块直段厚 ~176px; 右侧 x≳1500 起那块料**比模块高 35px、低 65px**、高 277px(模块 175px)、底部磨砂麻点(190~240,
  模块同高度纯 255)、并连到带螺钉/贴纸的底座 ⇒ **不是模块本体**; 再往右 x≳1820 并入**同为 255 的亮白台面** ⇒
  亮度完全分不开, 只能靠几何(台阶)切。
- 左端 x 380~545 是连接器头(青蓝金属, 灰度 ~187) ⇒ 阈值 200 切不出来, 放宽到 170 才并得进来。
- 倾角: 上边缘**中段**(x 1050~1450) 是干净直线(残差 <1px); 全段拟合残差 ±100px 是脏的 ⇒ **只信干净的直线段**。

## 算法(定案 v12.2)

1. 固定站位外框 ROI `x[330,1815] y[960,1440]`(右界只当兜底 —— 正常走台阶收紧)。
2. **估倾角双法互校**: A = 上边缘"最直 400px 段"直线斜率(残差 ≤3px); B = ROI 内 `g>200` 掩膜最大轮廓的
   `minAreaRect` 角度; `|A-B| ≤ 1.5°` 才用, 取均值; 否则判失败(实测 A=-3.893 / B=-3.995 ⇒ -3.944)。
3. 反旋(`getRotationMatrix2D(ROI 中心, ang)`, 边界填背景灰)。
4. **在旋后帧里量几何**: 上边缘点中位 = 基线 `y_base`; 最直段逐列亮像素数中位 = 厚度 `thick`(实测 177px)。
5. **右界 = 上边缘"向上的竖直台阶"**: 自 x0+300 起, 首个满足 `y_base - y_top ≥ 18px` 且后 8 列持续 ≥60% 的位置
   (实测 x=1503); 取 `x_end = x_step + 15`(保端面)。找不到 ⇒ 用 ROI 右界并在 meta 里写
   `right_edge_src="ROI 右界(未找到台阶 ⇒ 可能切在亮料中间)"`。
6. 掩膜 = 旋后帧 ∩ ROI ∩ `x ≤ x_end` ∩ 纵向带 `[y_base-12, y_base+thick*1.3]` ∩ `g>170`(≥1500px 连通域并集) → 外接框。
7. 裁 box + 12px 留边 → letterbox 到**定尺 1400x300**, 缩放 `min(...,1.0)` 只缩不放; 模块水平居中, 四周填背景灰。
8. 交付 meta: `judge_ok`/`why`/`rot_deg`/`angA_deg`/`angB_deg`/`y_base`/`thick_med`/`band_y`/`right_edge_x`/
   `right_edge_src`/`module_bbox_rot`/`module_aspect`/`cover_frac`/`border_med`/`bg_median`/`ms`。

**失败闸门(绝不硬裁)**: 亮条点太少 / 最直段残差>3px / 两法差>1.5° / 量不到厚度 / 模块 <400x60 /
画布边缘发亮(>max(120, bg+60)) ⇒ `judge_ok=False` + `why`, 调用方**回退全幅规范图**并在日志告警。

## 审计方法(可复用): "反解"判据图 定位它到底切了哪儿

判据图 = 原图旋转 ang 后取窗口; 找判据图里 2~3 个**特征**(左端舌尖/青色片中心/已知台阶)对应到原图,
即可解出 `(ang, 窗口)` 并交叉验证到 1~4px, 之后判据图上任何边界都能换算回原图坐标判定对错。
本法曾发现: (a) 右端是硬切(切在 x=1815 亮料中间, 上下都是 255); (b) 长条本体止于 x≈1495(上跳)/1513(下掉);
(c) 左端没被截、青色连接器头完整(面积只差 2%)。

## 坑

- `minAreaRect` / `connectedComponentsWithStats` 返回 numpy 标量 ⇒ meta 必须 `int()`/`round(float())`, 否则
  `/crop_info` 的 `jsonify` 报 `Object of type int32 is not JSON serializable`。
- **改 `print` 的格式串后必数占位符个数 == 参数个数** —— 曾用 sed 把格式串从 7 个占位符改成 9 个而参数没加,
  `TypeError` 会让判据图路径直接 500(而 `py_compile` 查不出来)。改完立刻跑离线验收。
- 内存帧是 JPEG(92)、落盘是 PNG ⇒ 别断言"逐字节一致"; 正确口径是"尺寸一致 + 逐像素平均差 ≤4"。
- 判据图渲染只加 ~50~180ms, 可以放在 `GrabAndSaveImage` 里同步做。
- 离线测试里遍历判据图列位置要 `min(N, W-1)`, 否则定尺改了(1600→1400)就 IndexError。
