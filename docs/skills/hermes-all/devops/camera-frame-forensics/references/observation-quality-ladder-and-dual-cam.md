# 相机观测可用性判定阶梯 + 双眼场景叠加 (2026-09-26 实测)

两只相机: 本机内置 `/dev/video0`(640×480) + 臂上 `/realsense/color/image_raw`(640×480, 由 tap 落盘到
`/home/ubuntu/zmax_ss_remote/cam_rs.png`, 带 `age` 帧龄)。

## 一、先判"图像能不能当观测量用" —— 阶梯式, 每级都有量化判据
不要一上来就做标定/追踪，按顺序过：
```
① 取图新鲜度: 每次取图**校验落盘文件编号/时间戳变化**（本次 No_329→No_330）
   —— 不校验就会拿旧图当新图，"画面变了/没变"全是误判
② 曝光稳定性: 同一位姿连拍 3 帧 **对比跨位姿**
   · 同姿态内 std 完全一致(81.8/81.8/81.8) 但**跨姿态剧变**(81.8 → 30.1 → 53.5)
     ⇒ **自动曝光在跟随场景测光**（不是噪声，也不是遮挡）
   · 这是"强度类特征不可重复"的根因，会一路毁掉差分/模板匹配
③ 强度差分: 跨位姿差分若全幅 >70% 变化 ⇒ 立刻放弃强度法（本次 85~94% 像素变化）
   CLAHE 归一后能压到 0.5%, 但**差异簇的身份会跳**（位移翻倍却换到完全不同的簇）⇒ 仍不可用
④ 位移一致性: 走 ±40mm / ±80mm 看同一特征位移是否**单调成比例**（期望 ≈2×）
   本次 Δu: 562 → 103 px = 乱跳 ⇒ 不成比例 ⇒ 不可追踪
⑤ NCC 模板匹配(对线性亮度变化免疫, 最后的救命稻草):
   · 峰值 **NCC ≈ 0.84 且与臂位移的相关性 ≈ 0.03** ⇒ 这是**泛匹配地板值**, 匹配到的是噪声不是目标
   · 判据: 光有高 NCC 不够, 必须看 **峰位与真值位移的相关性**（corr < 0.3 一律判无效）
```
**结论纪律**: 阶梯全部不过 ⇒ **停下并如实报"该相机在当前条件下不可作为观测量"**，
**不要**用不可靠的观测去解标定/写 calib 文件（宁停不假；假标定会污染后续所有环节）。
可行出口(不依赖现场改动): ① 固定曝光/增益 ② 贴 ArUco/AprilTag 等对曝光免疫的标记
（`cv2.aruco` 生成 720² + 打印版 1600²；打印宽度 100~150mm）③ 换传感器。

## 二、双眼场景叠加（可用, 已验证出图）
`tools/dual_cam_scene.py` —— 四档模式, 一图看全，**只读不动机器人**：
```
panel (默认)  并排 + 半透明融合 + 真值带 (TCP/关节/夹爪/帧龄)   ← 实际交付用这档
sbs           左右并排(各带标签/时间/帧龄)
blend         半透明融合(α 可调)
edge          视角A 的边缘(黄)叠在视角B 上  ← 专门用于 sim2real 几何对齐检查
```
两条硬规矩（用户要求，别省）：**每格都标相机来源 + 拍照时间 + 帧龄**（实时数据必须标拍照时间与帧龄）。
产物: `data/scene/dual_scene_*.png` + `scene_map_*.json`（sim↔real 参数逐项映射表, 每项写 已映射/待映射 + 怎么映射）。

## 三、把图发到飞书（图片消息的正确通道）
```
文本工具只支持 text/media；**图片必须走 image**:
  ① POST /open-apis/im/v1/images 上传 → 拿 image_key
  ② 发消息 msg_type=image, content={"image_key": ...}（可再补一条文本说明）
现成实现: tools/aoi_feishu_push.py 的 send_image(path, chat_id, tok, caption) 与 `--file PATH`
  实测: upload_code=0 · code=0 · msg=success · 返回 image_key + message_id ✓
```
注意: 飞书长文 ≥1.5k 字须拆条; token 缓存过期报 99991663 → 重启 gateway。

## 四、sim2real 参数映射表（"仿真参数都要与真实场景映射"的落地形态）
```
✅ 已同源: 关节角(编码器↔qpos) · TCP(SDK endInRef↔engine tcp, 实测偏差 0.91µrad) · 夹爪开度(量程归一)
⏳ 待映射: 图像分辨率(真实 640×480 ↔ 策略 128×128, 需 resize+自裁口径归一)
          碰撞几何(真机 7 个 STL 已只读取回; 仿真侧用简化几何)
          光照/曝光(真实自动曝光存在 64.5% 跨位姿变异 ↔ 仿真固定光照 → 走**域随机化**)
判据口径: 每条都要写"怎么映射", 不能只写"已映射" —— 否则下一轮无法复核。
```
