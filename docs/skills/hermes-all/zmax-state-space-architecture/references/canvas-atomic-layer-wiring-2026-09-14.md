## 二、诊断口径 (先取证再改)

## 三、契约 (照用户要求落地)
`sslimit.out1` 扇出到 11 个节点, 全部落 **in2** 槽位 (in1 留给原链式入线, 端口语义不回退):
`ssa`(🅰️通用算子A) · `ssb`(🅱️B) · `ssc`(🅾️C) · `sssk1..sssk8`(①接近 ②对位 ③下降 ④抓取 ⑤抬起
⑥转移 ⑦插入 ⑧完成)。label 统一 `🛡 限幅后控制 → <节点名>`。
**每条 link 的 (t, t_port) 仍不能双占** —— 目标已有 in1 时新线必须落 in2。
**目标节点的 `inputs` 数组要同步补 `"in2"`** (本项目 `inputs` 是声明式数组: 只加入线不改声明 →
渲染器只画一个入口, 第二条线看不见; 这与"端口槽位由 link 数组先后决定"是两件不同的事, 都要做)。

## 四、几何铁律 (为什么必须移动源节点)
单行布局端口固定"左入右出", 而本项目的几何体检把 `ax=源右缘 > bx=目标左缘` 判为**逆向线**。
⇒ 一个源要扇出到整行, **源必须在行首** (x 小于所有目标左缘), 否则出线全部逆向。
- 原位置 (3856,625) 在原子行中右部 → 11 条扇出里 10 条会被判逆向 ✗
- 移到行首 (754,625) → 11 条**全部前向, 逆向 0 条** ✅ (右缘 1034 < ssa 左缘 1090)
- 行首位置空带检查: 该行上方 y≈625 在 x<1090 区间是空的 (row_bg 从 y=795 起), 可直接放。

## 六、整齐版替代方案 (一句话可切换, 让用户拍)
