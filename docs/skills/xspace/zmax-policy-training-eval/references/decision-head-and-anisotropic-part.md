# 让一个决策量真正 load-bearing + 条件决策头 (2026-09-11 L4 夹爪 yaw 试抓头, act_dim 4→5)

场景: 老倪要求"某个决策量 (这里是 ② 段夹爪偏航角 yaw) 必须由真实模型给出, 且 φ* 要是
真正的最优值, 用候选角 + 真实试抓成败做监督"。这类需求 (任何 "让模型学会选一个离散/连续
选项" 的任务) 按下面 8 步走, 每步都有实测数字与坑。

## 0. 先证伪: 该决策量在当前任务里是否 load-bearing (不跳过!)
- 方法: 用**真实试验**扫描该变量全范围, 直接测最终指标 (不是看模型打分)。
- 实测 (metaworld peg 30×30mm 方截面, 半尺寸 0.015):
  · ② 抓横放件 13 个候选角 → **13/13 全成功** (Δz 133~138mm)
  · ⑤ 插入 yaw 偏移 15 个值 → **15/15 全成功** (深度 48.7~49.8mm)
  → 该几何下"最优对准角"根本不存在, 拿成败当监督标签 = 标签恒 1 = 训不出任何角度信息。
- 物理原因 (想清楚再改): 方形截面绕长轴转任意角都能被两指夹住 (对角才 21mm, 仍在开口内);
  孔又是旋转容差大的槽 → 抓/插都对 yaw 免疫。
- **教训: 任何"监督信号是不是平的"必须先量, 平了就换几何/换任务, 不要硬训。**

## 1. 造/找有区分度的几何: 候选扫描
- 脚本模式 (`tools/rect_sweep.py`): 直接 patch 场景 XML 的件 geom size → 对每个候选跑
  **抓 0°/90° + 插 0°/90°** 四项, 判据 = ① 插入 0° 必须成功 (不回退红线) ② 至少一个角度失败。
- 实测表 (半尺寸, mujoco box size = 半宽):
  | 截面 | 抓 0° | 抓 90° | 插 0°/90° | 结论 |
  |---|---|---|---|---|
  | 0.015 0.015 (30×30) | ✅105mm | ✅138 | ✅/✅ | 无区分度 |
  | **0.020 0.008 (40×16)** | **✅105mm** | **❌0mm** | ✅/✅ | ✅ 选中 |
  | 0.014 0.008 (56×16) | ❌60 | ❌23 | ❌5.7/✅ | 破坏链 |
  | 0.020 0.010 (68×20) | ✅ | ❌27 | ❌/❌ | 插不进 |
  | 0.020 0.010 (80×20) | ✅ | ❌32 | ❌/❌ | 插不进 |
- 落地: `tools/gen_l4_demo_scene.py` 默认注入矩形 **0.020 0.008 0.12**, `--peg-stock-section`
  回旧方形 (出问题可一键回退对照)。

## 2. 真实物理判据 (最容易出假成功的地方)
- 原演示链: 闭夹后**无条件**建立"刚性锁" (`_grip_lock=True`, 每帧把件钉到手), 然后才做抬升
  判定 → 件必然跟手 → `dz>0.08` 恒真 = **假成功**, 训练/决策完全不影响结果。
- 修: **把抬升试探放到建锁之前** —— 抬 12mm, 件随动 >6mm 才算真夹住, 否则真失败中止
  (`SS_L4_GRASP_VERIFY=1`, 默认开)。日志同时打印"真实夹持验证 Δz"。
- 通用原则: 演示/评估里任何"锁定/吸附/写死跟随"的机制都会把决策变量的作用抹掉 —
  做决策学习前先把这些机制找出来并让真实物理接管。

## 3. 探针数据集 (真实试验, 带决策时刻特征)
- `tools/yaw_grasp_probe.py`: 每试一次记录
  `{seed, 候选值, ok, Δz(或深度), **z7 决策时刻状态**, a4, module_yaw}` → JSON。
- **每行必须含决策时刻的输入特征**, 否则事后无法训 (本次 z7 = hand−pegGrasp + hand−pegCenter
  + 夹持标志, 与执行器同构)。
- 规模: 3 布局 × 13 候选 = 39 次 ≈ 1 分钟 (真实物理), 成功率 12/39 且**有明确最优区**
  (φ≈0: 3/3; φ=±90: 0/3) → 有信号。

## 4. 条件决策头 (act_dim 4→5 的语义)
- `src/lerobot/manifold/yaw_head.py`: in = z7(7) + a4(4) + **候选值归一(1)** → 双头:
  `head_dz` 回归 (主导分, 连续信号数据效率高) + `head_ok` logit (辅助/可解释 P(成功))。
- 打分: `argmax 预测 Δz` (并列看 P(成功))。**关键: 决策变量必须作为输入维度出现** —
  旧世界模型 act_dim=4 无 yaw 维, 让它在候选角上打分必然退化 (argmin 恒落区间边界, 实测)。
- 训练: `tools/train_yaw_head.py` (小 MLP 256×2, Adam 2e-3, 4000 ep, CPU 秒级)。

## 5. 诚实验收 (不是只看 MSE)
- 留一布局交叉验证 + **"预测 argmax 是否命中实测 argmax"** 命中率 (这才是决策质量)。
  实测: 训练 acc 0.949 / 留一 0.92·0.92·0.85 / **预测最优角 3/3 命中实测最优角**。
- 若各候选结果近确定 (同角重复几乎一致) → **必须在报告里写明"泛化验证偏乐观"**, 别称"强泛化"。

## 6. 接线 + 默认档 (老倪红线)
- 执行器 `yaw_actuator.py` 加 `grasp_head` 打分分支 (候选搜索放开全周 ±90°), 保留流形打分作回退。
- **默认档必须是学习决策** — 老倪红线: 不接受"默认脚本 + 可选真链路"; 面板/日志出现
  "脚本开环/写死" 即不合格 (标注免责不算)。
- 日志/面板必须可核对: `scorer 名 + 权重文件名 + 前向次数 + trained`。
  实测日志: `② 姿态适配(yaw 试抓头决策): yaw 指令 -0.3° (决策 1 次 / yaw 试抓头前向 13 次 /
  trained=True / 权重 l4_yaw_head_grasp_dz_v1.pt)`。
- 3D 面板加"指令来源"两行 (来源 + 下发值 + φ* + 前向次数 + trained), 让用户**看得见谁在下令**。

## 7. A/B 证据 (决策真的 load-bearing 才算完成)
- 同 seed 同链路对比: 学习决策 vs 固定脚本角。
  实测: 学习 φ*=-0.3° → 真实夹持 Δz≈12mm → 抬起 0.122m → ③④⑤⑥⑦⑧ 全绿 (4 个 seed 全 success);
  **固定 +90° → ② 抬升试探件随动 0.1mm → 物理失败中止**。
- 视频 + 面板截图一起交 (老倪要证据不认口头)。

## 8. 权重分发 (打包版要能跑真头)
- 权重不进代码库 → 上传 ECS 静态目录 → CI `curl` 下载 + **md5 断言** → `--add-data` → 构建后
  校验条目在包内 (缺即 fail)。包内缺权重时日志必须诚实标 `trained=False` (随机对照)。

## 坑清单 (本类任务通用)
1. **JSON 序列化**: numpy float32/bool_ 直接 `json.dump` 报 `TypeError: Object of type float32
   is not JSON serializable` → 指标/报告里所有值 `float()`/`bool()` 包一层 (round() 也返回 np 类型)。
2. **扫描脚本"替换成功"断言写错**: `assert out != src` 在"候选 = 原值"(基线那一行) 时误判失败 →
   断言应检查**替换后的目标子串是否存在** (`assert f'size="{a} {b} 0.12"' in out`)。
3. **场景生成器替换方向**: 搜索侧必须用 **stock 源文本** (`size="0.015 0.015 0.12"`), 替换侧用
   目标截面 — 两边都写目标值会 `assert 未匹配` 失败。
4. **GUI 线程铁律**: worker 线程禁碰 QObject → 勾选框 (`chk_*.isChecked()`) 必须在**主线程**读入
   (`self._x = chk.isChecked()`) 再传进 worker; 在线程里直接读是崩溃隐患。
5. **候选集必须覆盖正确解**: 旧默认 span ±45° 以 φ_ref 为中心, 正确角在区间外时学习头也够不到 →
   有明确监督后把搜索放开到全周 (±90°)。
6. **旧"打分退化"结论要跟着更新**: 一旦监督信号补齐, 之前记录的"单调退化/无信息"结论作废,
   在技能/文档里同步改掉, 别让旧结论继续指导后续会话。
