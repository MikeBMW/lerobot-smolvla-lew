## 1. 🐛🐛 lerobot PEP695 泛型语法 vs Python 3.10 容器 (镜像运行必炸)
- lerobot 要求 Python >=3.12, 代码用 **PEP695 泛型**:
  - `def deserialize_json_into_object[T: JsonLike](fpath, obj) -> T` (io_utils.py:93)
  - `class Backtrackable[T]:` (streaming_dataset.py:58)
  - `class DataProcessorPipeline[TInput, TOutput](HubMixin):` (processor/pipeline.py:254)
  - 调用处: `RobotProcessorPipeline[tuple[RobotAction, RobotObservation], RobotAction]` (rollout/context.py, factory.py, gym_manipulator.py, lerobot_teleoperate.py, lerobot_record.py)
- **pytorch/pytorch:2.2.0-cuda12.1-cudnn8-runtime 和 2.5.1-cuda12.1-cudnn9-runtime 都是 Python 3.10** — `--ignore-requires-python -e .` 能装上, 但**运行时 import 到该模块 SyntaxError** (`invalid syntax` at `[T: JsonLike]`). 逐模块炸, 一次修一个永远修不完.
- **两条路**:
  - (a) 换 Python 3.12 基础镜像 — 国内加速器 tag 404/拉取超时常见 (2.7.1-cuda12.4 403; 2.6.0 拉取 300s 超时), 4GB 重下不值
  - (b) **剥 PEP695 泛型 (实测最快, 全仓 3 处 def/class + 调用处去下标)**:
    ```python
    import re, glob
    for f in glob.glob('src/lerobot/**/*.py', recursive=True):
        src = open(f, encoding='utf-8').read()
        for cls in ['RobotProcessorPipeline', 'DataProcessorPipeline', 'Backtrackable']:
            src = re.sub(cls + r'\[[\s\S]*?\]', cls, src)   # 跨行非贪婪
        open(f, 'w', encoding='utf-8').write(src)
    ```
- ⚠️ **正则陷阱**: `\[[^\]]*\]` 不跨行且遇嵌套 `]` (tuple[...] 在内) 会截半 → 残留
  `RobotProcessorPipeline, RobotAction]` 直接语法错. 用 `[\s\S]*?` 跨行, 但**嵌套 `]` 仍截半** →
  替换后必须:
  1. `python3 -c "import ast; ast.parse(...)"` 全 src/lerobot/**/*.py
  2. `grep -rn "RobotProcessorPipeline,\|DataProcessorPipeline,\|Backtrackable," src/lerobot/ --include="*.py"`
     找残留 (import 行/参数逗号是合法误报, 看上下文)
  3. 坏文件 `git checkout <file>` 恢复后重改 (checkout 对未提交改动有效)
- 去泛型后 Pyright 报 "Type variable has no meaning" 是**静态噪音**, 运行无影响 (Python 动态).

## 2. 🐛 venv 里 `pip install -e .` 会重下 torch 2.11 换掉 cu118
- venv 已有 `torch==2.2.2+cu118`, 跑 `pip install -e .` → pip 解析依赖要求 → 拉 **torch 2.11.0 (cp312, 默认 cu13)**, 下载 839MB 且替换后
  `libtorch_global_deps.so: cannot open shared object file` (cu13 需要额外 nvidia 包).
- **修**: `pip install -q --no-deps -e .` + 显式补核心依赖
  `termcolor tensorboard transformers sentencepiece protobuf huggingface_hub accelerate`;
  若 torch 已被换, 重装 `pip install torch==2.3.0 torchvision==0.18.0 --index-url https://download.pytorch.org/whl/cu118`
  (torch 2.2.2 的 cp312 cu118 wheel 不确定, 2.3.0 确定支持 py3.12 + V100 sm_70).

## 4. 🐛🐛 simulink 模板加载 edges 索引错位 → SmolVLM2/SigLIP 没接 (终极修法)
- 现象: 加载 Model Zoo 模板后 SmolVLM2-500M / SmolVLM2·LEW / SigLIP 入0出0 (模型无法运行).
- 根因: `load_reference_app` 里 `ids` 列表 = **创建顺序** (跳过共享定义后 ≠ 定义索引), 而 edges 数值 = **定义索引** → `ids[fi]` 全体错位.
- **修 (load_reference_app, layout 与兜底两分支都要)**:
  ```python
  index_to_id = {}
  # ... 每个 add_node 后:  index_to_id[i] = n["id"]
  for fi, ti, *label in link_specs:
      fid, tid = index_to_id.get(fi), index_to_id.get(ti)
      if fid and tid:
          self.add_link(self._items[fid], self._items[tid], label=label[0] if label else None)
  ```
- ⚠️ **结构条件行级定义索引 off-by-one**: 共享定义(索引2)占位后, 5 个行级 🧩 定义在 **59-63** (不是 58-62) — edges 写 58-62 → AWE 🧩(63) 入0出0 且各 🧩 连线错位. 用脚本数
  `for i,item in enumerate(specs): if '结构条件' in str(item[1])` 得真实索引再改 edges.
- **验证模板连线完整性**: offscreen 加载 → 断言每个模型主干 (SmolVLM2/ResNet18/DINOv2/SigLIP) 入≥1出≥1, 每个结构条件入≥2出≥1.

## 6. 验证脚本断言坑 (追加, 接 2026-08-08 前段 8b)
- offscreen 下 `isHidden()` 返回 False、`isVisibleTo(parent)` 不可靠 (parent 未 show) — **用 `isVisible()`** 判断隐藏.
- 切模型测试第一项不触发信号 (当前值==目标值) — 先切到别的值再切回.
- 方法体断言按字符切片 (3000-4000) 常太浅到不了深处代码 — 切到下一个 `def ` 边界.
- 断言字符串引号不配对 → 条件变成无意义长字符串 → 静默 False (写断言后先自查).
- `QSpinBox.setValue(float)` 直接 TypeError (无 decimals) — try float 先、except 后 int 回退 (见前段 §14).
