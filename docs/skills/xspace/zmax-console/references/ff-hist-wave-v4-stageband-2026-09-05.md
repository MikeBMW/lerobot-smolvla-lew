## 坑 8: "波形还是直线/不是波" — 确定性前馈网络没有持续振荡 (物理事实, 不能造假)
- 用户以脑机接口类比期待"可探测的持续波形"。实测引擎 331 步轨迹 (播放真实数据源, 不是 parquet):
  - 层能量 E=Σx² 帧间变化**中位仅 0.2** (E∈[16,69] 但大部分帧几乎不动) → 能量是慢包络;
  - 激活 0↔活跃 翻转事件均值 6/帧 (大多 0-5, >20 的帧仅 5-6%) → 也稀疏;
  - **‖Δx‖₂ 帧间激活变化范数**: 中位 0.12 持续非零, 事件尖峰启动 1.4 / 插入段 4.7-8.8 (最强)。
- 结论: 平滑运动段激活近乎静止是**真实特性** (确定性 MLP + 平滑输入 → 内部表征稳定), 生物式持续振荡
  不存在 → **不能硬造波形欺骗**。给用户的波形 = **事件波形**: 平时细微起伏 + 启动/抓取/接触/插入尖峰,
  与神经事件记录仪同构。若用户坚持要持续振荡的波 → 那是架构层 (循环/噪声) 的事, 明说边界, 不做假。
- 画法: 事件波形必须**去基线放大** (y 取窗口 [min*0.9, max*1.15] 而非从 0) — 否则 20±7 的能量/0.1±0.05
  的 ‖Δx‖ 在 0 起刻度下全压成贴地平线 ("看着像直线"的显示根因, 信号本身在动)。

## 坑 9: Scope "绘图异常" 第二根因 = 轨迹缺流形信号 → 空数组 np.min 崩
- 引擎快演轨迹含 mani_rem/manidperp (验收两格有数据); **真实化 (RealStateSpaceSim) 轨迹无任何 mani_* 键**
  → Scope 第 7/8 格 `np.min([])` ValueError → 整窗画"绘图异常" (默认 ▶运行=真实化, 必现)。
- 修: plots 里 mani_* 用 `.get(..., [])` (别用 [0] 默认 — [0] 会让缺信号的格画假平线);
  循环开头 `if y.size == 0: 格内提示"该轨迹未采集此信号"; continue`; 底部验收摘要无流形数据时明示。
- 通用: 画布/Scope 多格布局, 每格数据数组独立判空, 缺信号格提示不崩 — 别让一个缺键毁整窗。

## v4 最终形态: 分阶段全程波形 (老倪: "不同阶段显示在每层横轴, 不同类型波形对应不同阶段, 体现整个插拔流程, 尤其插拔成功")
- 布局: 每层一行 (共 3 行), 行内顶部 18px **阶段色带**, 下方事件波形 ‖Δx‖₂;
  横轴 = 全程时间 (0s→T, 播放左→右生长, 不滚动; N_FRAMES 300→600 保证全程不丢);
  行底时间轴 0s/T; 全窗底部绿字 "✅ 插拔成功 (已走完 接近→对位→下降→抓取→抬起→转移→插入) · 已播 N 帧/Ts"。
- **阶段色带**: STAGE_ORDER 8 阶段 8 色 (接近蓝/对位紫/下降绿/抓取黄/抬起橙/转移紫红/插入红/完成青),
  逐帧 stage → 段边界, 每段淡色块; 段名宽度检测 (`xb-xa >= tw+10`) 才写, 白字 9pt, 防重叠。
- **数据链铁律**: 引擎每步 probe 快照**必须放在 `u, stage = sched.decide(...)` 之后 append 才能带 stage**
  (accel.forward 在前、stage 在 decide 才产生; 快照 append 太早则无 stage)。
  state_space_sim 与 state_space_sim_real 两处同改: `_snap = dict(probe); _snap["stage"] = stage; tr["probe_seq"].append(_snap)`。
  GUI 播放 tick 推 probe_seq[idx] → 窗口 push 读 probe["stage"] 存 self.stages (FIFO 同长)。
- **阶段名复合**: 引擎 stage 带接触子态 ("下降 · 接触"/"插入 · 接触") → `_map_stage(name)`:
  按 STAGE_ORDER 前缀匹配归一 ("插入 · 接触"→"插入") — 色带取色、成功判定都用归一后的 base。
- **成功判定**: 引擎 done = 插到底, break 前最后 append 的 stage 停在 "插入·接触" (字面"完成"基本不出现) →
  ok = 到达过"插入" 且 末段 base ∈ (插入, 完成)。别等字面 "完成" 字样, 否则 ✅ 永不显示。
- 完成/插入段金色底纹 (fillRect QColor(255,213,0,26)); 超顶尖峰 (‖Δx‖ > y 上限) 截顶并在峰顶标真实值 "▲8.8"。
- 窗口右上视图切换 QPushButton (〰波动 / 📊直方图) = child 按钮绝对定位 (resizeEvent 里 setGeometry + show/hide),
  别再叠 QVBoxLayout (QLabel 拉伸坑)。
- 状态条行1 实时显示 "第 N 帧 · 阶段: 抓取 · u_ff=[…]" — 阶段名从 probe 取, strip "阶段 "/"阶段:" 前缀。

## 波形类可视化的通用回答框架 (老倪连问四次)
1. 先区分"显示聚合抹平" vs "信号本身平滑": 前者换本帧/分桶画法; 后者是物理事实要拿实测数字讲清楚。
2. 确定性前馈网络 + 平滑物理输入 → 激活包络平滑, 差异在事件点 (启动/抓取/接触/插入) 与少数单元 — 
   用事件波形/阶段色带/单帧统计呈现, 别试图伪造持续振荡。
3. 三连问节奏 (这是啥→怎么没变→怎么是直线) 说明窗口缺"自解释 + 动态可见": 图例文字直接写窗口里 +
   每行标题带本行实时统计数字 + 播放中数值/波形逐帧更新。
