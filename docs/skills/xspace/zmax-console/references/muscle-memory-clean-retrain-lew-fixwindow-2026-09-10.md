## 一、清库重练执行结果 (12 轮实测, seed104 insert)

**清库流程(必须按序)**:
1. 备份 `data/muscle_memory.json`(本次脏库 138 桶 / 1.4MB) → 写入 `{}`;
2. **单例重置** — `import muscle_memory as MM; MM._INSTANCE = MM.MuscleMemory(path=P)`;
   不重置的话引擎拿到内存里的旧 `_INSTANCE`, 清库等于白做;
3. 每轮新建 `RealStateSpaceSim(seed=104, vision=False, mode="insert")` → `run(max_steps=900)`;
   R0 一轮仅 ~1s(比 R1 视觉快两个数量级, 适合做轮次统计)。

**结果**:
- ep1-3 冷启动: 每轮 done=True / 343 步; ep3 末按 `MIN_OK_RUNS=3` 固化 **7 桶标杆**。
- ep4-12 快通道: 命中 **180~185 帧/轮**, **12 轮全部 done=True**(100%)。
- 影子 du: 前 5 段(快通道接管) **du=0.0** = 标杆就是实际下发动作(精确重放);
  转移 du≈0.93 / 插入 du≈0.35 = 实时决策与标杆不同 → **再次印证插入/转移段不能改成重放**。
- **"越练越顺"实测(12 轮 dx_mean 全段下降, 单位 mm)**:
  接近 1.14→1.04 · 对位 1.65→1.57 · 下降 2.27→2.10 · 抓取 2.59→2.46 ·
  抬起 4.55→4.50 · 转移 3.11→2.70 · 插入 1.80→1.09。
  = `E_MERGE=0.3` 指数融合生效的直接证据。**汇报"越练越顺"必须带逐轮数字, 别只讲机制。**

**⚠️ gate 判据教训(重要)**:
- `gate_ok = dx_max < 2mm` **偏严**: 清库重练后 dx_max 仍 4.5~4.8mm(抬起段最大), 但 12 轮全链成功。
- dx 的物理含义 = "标杆记录位置 vs 重放时实际位置"的**累积物理微差**(前段抓取位置的微小差异被
  后段继承), 不是动作错误 — 那些段 du=0, 动作完全一致。
- **建议判据 = `dx_mean < 2.5mm` + 该段成功率**; 只看 dx_max 峰值会把可用标杆误判为不可用。

**启用顺序建议**: 先在 dx_mean 小的段(接近/对位/插入)启用 L2 直读; 下降/抓取多练几轮达标后跟进;
插入/完成段永远保持实时决策(曲率大段禁重放 — 与设计文档一致)。

## 二、SS_LEW 前视修正的无限循环坑 (红线级: 接新功能导致回退)

- **现象**: `SS_LEW=transformer` 让 seed1 成功率 **3/3 → 1/3**(681 步 → 900 步耗尽)。
- **根因**: 插入遇阻 → LEW 预测对心微调(8 帧窗口) → **窗口内不计 stall 且 `_stall_events` 不增长**
  → 再遇阻又落进"修正"分支(`_stall_events < 3` 永远成立) → **永不触发第 3 次回退** → 卡死。
  设计意图是"前 1-2 次先试修正, 第 3 次才回退", 但修正把计数冻结了。
- **修复**: 修正窗口结束时(`_lew_corr == 0`)校验插入深度是否推进(窗口起点需先存 `_lew_d0`);
  无改善 → `_stall_events += 1`(最多 2 次修正) → 与 SS_LEW 关闭路径行为对齐。
- **通用铁律**: 任何"重试 / 修正 / 探路"窗口都必须**计入失败计数**, 否则会形成永不退出的重试环。
  这类"修正窗口"模式在遇阻保护/重抓策略里到处都是, 加新修正分支时先问"失败计数还涨吗"。

## 三、验证这类改动必须用同进程交替 A/B

- 跨进程单次对比**不可靠**: 同 seed 不同进程有物理微扰 — 实测同一配置不同进程 681 / 774 / 854 步。
- 正确做法 = **同一进程内交替跑 N 轮**(每轮新建 sim 实例, 跑前改 `os.environ["SS_LEW"]`;
  `SS_LEW` 在主循环里实时读 env, 所以同进程可切换):
  ```
  off 3/3 (774/854/710)  ·  transformer 3/3 (761/653/706)   ← 零回退, 平均步数还少 ~9%
  ```
- 老倪红线: "新模型/新功能接入不得让插拔成功率与性能回退" — 报"接好了"之前必须先跑这个对比。
