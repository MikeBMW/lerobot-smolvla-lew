## 发布执行序列 (实测 v5.3.0)
```bash
# 提交(显式 add, 勿 add -A — untracked 有 bak/pdf/flow_*.json 杂项)
git add VERSION.md tools/gui/studio.py tools/gui/update_checker.py tools/gui/version_sync.py tools/gui/docs_sync.py
git commit -m "vX.Y.Z: <内容> — 版本号五处同步 + VERSION.md"
# push main + tag (直连 + HTTP/1.1 flags 实测通; VERSION.md 说走 ghproxy 是旧建议, 卡死才用)
git -c http.version=HTTP/1.1 -c http.postBuffer=524288000 -c http.sslVerify=false push origin main
git tag vX.Y.Z && git -c http.version=HTTP/1.1 -c http.postBuffer=524288000 -c http.sslVerify=false push origin vX.Y.Z
timeout 20 git ls-remote --tags origin | grep -c "refs/tags/vX.Y.Z"   # =1
# CI 轮询/资产验证见 github-actions-ci references/pre-tag-version-sync-ghless-poll.md
```
- 语法预检: `python3 -m py_compile` 四个文件 (py_compile 不 import 依赖, 无 PyQt5 也能跑)。
- 残留检查: `grep -rn 'v5\.1\.0' tools/gui/*.py` 应为 0 (软链双报忽略)。
- CI run name "Build Desktop (Windows .exe + macOS .app)" — tag 会并行触发 docker/simulink-ci/pypi。
