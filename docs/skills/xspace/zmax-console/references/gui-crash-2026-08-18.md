# GUI 崩溃与显示层深坑 (2026-08-18 晚实锤, 全部 gdb/faulthandler 验证)

## 1. PyQt5 5.15 sip 枚举错位 (坑人半天)
`QGraphicsView.ViewportUpdateMode` 的 PyQt5 枚举值与 C++ **不一致** (sip 映射错位):
```
PyQt5 名                  值  → C++ 收到
NoViewportUpdate           3  → BoundingRectViewportUpdate
MinimalViewportUpdate      1  → MinimalViewportUpdate (唯一一致)
FullViewportUpdate         0  → NoViewportUpdate   ← 陷阱!
BoundingRectViewportUpdate 4  → SmartViewportUpdate
SmartViewportUpdate        2  → FullViewportUpdate  ← 值=2 才是 C++ FullViewportUpdate
```
- `setViewportUpdateMode(QGraphicsView.FullViewportUpdate)` 实际 = C++ NoViewportUpdate (滚动不重绘!)
- **要 C++ 全量重绘就传整数值**: `setViewportUpdateMode(2)`; 要 Minimal 传 1
- 判断运行时模式用 `viewportUpdateMode()` 返回值对照上表, 别按 PyQt5 名猜

## 2. QDialog 事件虚函数抛异常 = qFatal 杀进程 (Segfault 假象)
- **现象**: "Fatal Python error: Segmentation fault", 崩溃前有 `QObject::killTimer:
  Timers cannot be stopped from another thread` + `QObject::~QObject` — 这些是
  pyqt5_err_print 打 traceback 时的噪音, **不是根因**!
- **真根因** (gdb 全线程栈实锤): `sipQDialog::resizeEvent → sip_api_call_error_handler
  → pyqt5_err_print → QMessageLogger::fatal → abort`
- **铁律**: resizeEvent / paintEvent / closeEvent / showEvent / mousePressEvent 等
  **C++ 回调虚函数重写里 Python 异常 → PyQt5 直接 qFatal abort** (显示为 Segfault)!
- **修复**: 所有事件重写必须 try/except 包裹 (paintEvent 拆 _paint + try; resizeEvent
  try 包 super+渲染)。普通信号槽 (clicked 等) 异常只打 stderr 不崩, 只有 C++ 回调要 try

## 3. Pillow 渲染持 GIL 卡主线程 → 渲染移子进程
- **现象**: 点「运行」仿真完成后拖滚动条 → 卡死/崩溃 (activateTimers NULL receiver)
- **根因链**: 后台线程 Pillow 渲染视频 (240 帧 PNG) 持 GIL → 主线程事件循环饿死 →
  QTimer 堆积 → activateTimers 碰撞 SIGSEGV
- **修复**: `subprocess.run([sys.executable, "gen_state_space_video.py", out], cwd=gui_dir)`
  渲染移子进程 (脚本自跑仿真自渲染, 主线程零阻塞)。Pillow 绘图持 GIL, 线程内渲染
  必卡 GUI — 重 CPU 的 Python 工作一律子进程化, 别用 threading.Thread

## 4. faulthandler 抓"卡死"线程栈 (比 gdb attach 好用)
- studio.py main 里: `faulthandler.enable()` + `faulthandler.dump_traceback_later(20,
  repeat=True, file=sys.stderr)`
- **信号定时器不依赖事件循环** — 卡死/崩溃时照样 dump 全部线程 Python 栈, 直接看主线程卡在哪
- gdb attach 经常赶不上进程死亡 (Fatal 后几秒就退出); 卡死时 attach 也难

## 5. VcXsrv 渲染 bug → "滚动/重绘只有一部分动" (环境级, 见 vcxsrv-display-pitfalls.md 第 11 节)
- 大 XPutImage (~5MB 整窗) 只画顶部一小条; XCopyArea 位块移动只移动一半
- Qt 侧最优 = MinimalViewportUpdate (默认); 禁 FullViewportUpdate/全量 repaint
- 根治: 升级 VcXsrv 或 Xvfb+VNC
