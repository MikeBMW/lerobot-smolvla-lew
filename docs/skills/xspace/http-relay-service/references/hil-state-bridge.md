# HIL 状态桥落地配方 (画布节点 ↔ ECS web 座舱, 2026-09-26 实测 17/17)

需求形态 (老倪原话): 「在状态空间工程增加 HIL Human in the loop 节点, 向 ECS web 发送状态空间状态;
我在浏览器上给出要求; 就用 hermes 的标准浏览器的形式」。

一句话架构: **本机把"系统现在在想什么"投影到网页, 人在网页里回话, 回话经中转回到本机工程**; 全程不下发物理动作。

```
本机 hil_bridge.build_snapshot()  ──POST /api/relay/hil/state──▶  ECS 中转 (append-only + 最新覆盖)
      上行内容 (全真值, 取不到写 null/-1):
        阶段 (真机只读流里的 prod_stage) · 观测 obs[0:7] · 帧龄 · 事件/预测概率 (真调模型对真帧推理)
        · 分层健康 (由服务/权重文件/端口实测判定, 不猜) · 资源 (GPU/磁盘/内存) · 画布简况 · 最近取证文件
网页座舱 (同源轮询)  3s 拉 /hil/state 刷新左栏 + 3s 拉 /agent/reply 追加右栏对话
      ──POST /agent/prompt {from:"hil_web"}──▶ 中转 ──本机 GET ?after=N──▶ hil_bridge 指示映射
                                                                        │
指示映射 (只读/离线动作): 解释 · 状态 · 阶段=<x> (记软先验) · 暂停/恢复 (落 flag 文件) · 待办
红线: 动作类正则命中 → 回执写 "未执行, 记为待授权" + 审计 jsonl 落盘 (人看得到明确的拒绝)
```

## 落地五步 (每步都要证据)
1. **中转**: 加 `POST/GET /hil/state` (append-only jsonl + GET 最新 + `?history=N`) —— 纯追加, 既有路由一行不改; 备份 + `ast.parse` + 重启后回归既有端点。
2. **运行时桥** (真源模块, 不是脚本胶水): `build_snapshot()` 采集真值 + `poll_instructions()` 用**独立游标文件**持久化 (`reports/<bridge>_state.json`) → 幂等不重放。
3. **画布节点**: 构图工具带六断言 (id 唯一 / int 坐标 / 零重叠 / 行带 / 全前向 / 端口存在) + 备份; ⚠️ 行背景节点 `params.bg|row_bg` 必须排除在重叠判定外, 否则永远报"与行背景重叠"。
   位置选法: 先算目标行带里所有非背景节点的 x 区间, 找 ≥ 节点宽 + 2×35px 的空缺带, 居中放置 (保持图面简洁, 不挤压既有节点)。
4. **运行时接线**: `node_logic._reg(...)` + `_EXTERNAL_LOC` (点右键跳真源码) + **真执行函数** (节点双击 = 上报一轮 + 收一轮指示, 打印真值); 档位级审计确认 R2-真接。
   ⚠️ `_reg(...)` 常是**两行调用** (描述串换行) —— 按"锚点行之后插入"会把新语句插进调用中间 → SyntaxError "expression cannot contain assignment"。先扫到包含结尾 `fn)` 的行再插。
5. **网页 + 常驻**: 页面部署到站根 (宝塔 `/www/wwwroot/<domain>/`), 首行 `<script src="/auth.js"></script>`; systemd `User=<普通用户>` 每 5s 上报 + 收指示; `Restart=always`。

## 防"看起来接上了"的三处硬校验
- **真值而非占位**: 快照每个字段都要能追到来源 (真机流/真模型推理/`systemctl is-active`); 没有来源就写 null/-1, 并在页面上显示"未读到"。
- **真调用计数**: 引擎/桥里放 `calls` 计数器, 取证断言 `calls == 帧数` (证明每帧真调, 不是抽样或占位)。
- **网页可见性**: 回执必须能被前端按来源过滤出来 (否则"功能好了但人看不到"= 没交付)。

## 新坑 (2026-09-26 实测)
1. 中转 `POST /agent/reply` 原**写死 `from`** 且丢 `action` → 多消费者时前端认不出自己的回执。**来源字段是路由依据**。
2. 两个消费者轮询同一提示词队列 → 同一条指示被答两次 → 必须按来源前缀隔离 (只认/只跳过 `hil_web`)。
3. 远端 `pkill -f <脚本名>` 匹配到自身 ssh 命令行 → 自杀 + 真进程存活 → "补丁部署了却仍 unknown endpoint"; 改按端口占用 PID 杀, 判活三件套 (文件 grep + 端口 PID 换新 + 真打端点)。
4. 网页换了域名/站根后 404: 先 `nginx -T` 找 `root`, 再看面板结构 (宝塔站点不在 `/var/www/html`)。
