# 开机任务的设计口径 (写脚本之前先读这个)

> 来源: 2026-09-25 本机实测 (网络优化开机任务 `zmax-net-optimize` + AOI 飞书监听 `aoi-feishu-push` + 控制台存活)
> 适用: 任何"每次开机自动做一件事"的脚本 —— 优化/预热/体检/监听/推图/巡检。

## 1. 一次开机脚本该长什么样 (四段)
1. **应用**: 改旋钮/开开关 —— 每改一项**立刻 `sysctl -n` / `iw ... get` 打印真值**(不许"以为生效了")。
2. **断言**: 关键前提再确认一次 (例: WiFi 省电 off; 数据盘已挂; 必需服务 is-active)。
3. **体检**: 采一组可跨天对比的数字 (RTT / TTFB / 吞吐 / 解析耗时 / 条目数) —— 全带超时, 单项失败 `|| true`。
4. **落台账**: 追加一行 JSONL (每次开机一行) 到仓库 `reports/<名>_<YYYYMMDD>.jsonl`。
   **一行一行追加**而不是覆盖, 这样"这次是不是真比上次好"才有据可查; 单次采样有噪声, 看趋势别看单行。

## 2. 必须满足的硬约束
- **失败不阻塞开机**: 每个外部调用带 `-m/--timeout`; 非致命失败用 `|| true`; unit 用 `SuccessExitStatus=0 1`。
- **幂等**: 重复跑不产生副作用 (同一目标值再设一次无害; 台账追加而非重写整份)。
- **可核验**: 必须留下三样东西 —— 日志文件、台账文件、`is-enabled/is-active` 真值。
  任何"跑完就消失"的开机任务都等于没做。
- **绝对路径**: 开机时 cwd 与 PATH 与交互式 shell 不同; 脚本里所有路径写绝对 (从仓库根推)。
- **单项逻辑留在仓库**: unit 只做薄壳, 逻辑在 `<repo>/tools/<名>.sh` —— 可 diff、可 review、可复用。

## 3. "清理/体检" 与 "优化" 是两件事 (用户口径)
用户先让"清理/检查", 紧接着就会问"**优化了么?**"; 那句要的是**实测有收益的调优**, 不是清理本身。
- 清理: 报"条目 127→40 / 释放 X MB / 热解析 6/6=0.00s"。
- 优化: 必须先量后调 —— 交错 A/B(**Latin-square 轮转**) ≥6 轮 + 中位 + **噪声带** + **胜率**, 无收益就回滚并如实写"无可测收益"。
  (实测教训: 固定顺序 A→B 能造出 +19% 的**假**提升; 轮转后真实只有 +6.1%/5胜6。)
- **拒绝项也要落盘**(写进配置文件注释/参考文档): 下次别重走"看似该调但实测无收益"的路。

## 4. 反复出现的具体坑
| 场景 | 现象 | 处理 |
|---|---|---|
| 开机预热类 | 开机时缓存**本来就是空的**, flush 没价值 | 价值在**预热**(把常用目标打一遍, 例如 `getent hosts` 常用域) |
| DNS 证据 | 不 flush 直接测, 全是 0.00s(缓存命中) → 误判"本来就快" | 先 flush 再测**冷解析**; 冷/热两条口径一起报; `resolvectl statistics/show-cache` **必须 sudo** |
| ping 汇总行解析 | 日志里出现 `mdevms` 之类怪值 | `awk -F'= ' '{split($2,a,"/"); print a[2]}'` 取 avg, **别用** `-F'[/ ]'` |
| GUI/窗口类 | 开机 unit "起过又正常退出(status=0)" | 多半是**设计如此**(用户要求 GUI 只人工启动, `Restart=no`); 别当成故障反复拉起, 也别加自动重启 |
| 需要"活着"的 GUI | 启了但几秒后消失, 无人知晓 | 用一次性启动脚本 + **盯 60s 存活**(每 5s 检查 pid, 挂了就打印日志尾并返回非 0), 而不是 systemd `Restart=always` |
| 长内联命令 | 被 hardline 拦截 / 输出截断 | 一律落 `/tmp/*.sh` 再 `bash` 它, 并在仓库里留一份可复用脚本 |
| 手工复跑 | 改了脚本 `systemctl start` 却毫无动静 | oneshot + `RemainAfterExit=yes` 时 **start 不重跑**, 用 `restart` |

## 5. 交付话术 (用户拿它当结果看)
四件套一起给, 缺一件就是"看起来做了":
```
文件路径(脚本/unit/sysctl.d/台账) + is-enabled/is-active 真值 + 日志或台账的一行真实输出 + 回滚一条命令
```
再补一句"重启后会不会自动跑"(= `is-enabled`), 而不是"我手动跑过一遍"。
