# Z-MAX 三级能力升级路径 (参考自动驾驶 L2/L3/L4)

## 现状 (2026-09-08 实测全绿)
| 级别 | 能力 | 技术 | 自动测试 |
|---|---|---|---|
| **L2 基础辅助** | 人在环分段技能 (9 功能) | 分段式小模型: YOLO+前馈MLP+状态机+原子技能 | 161/161 ✅ |
| **L3 高级 NOA** | 特定场景端到端自主 (3 功能) | 端到端模仿学习: VLM+Flow-Matching ActionHead | 54/54 ✅ |
| **L4 专家城区** | 复杂场景全自主+恢复 (7 功能) | 世界模型: 潜空间预测+流形导航+自主恢复+肌肉记忆 | 82/82 ✅ |

## 自动驾驶类比
- **L2** = 车道保持+ACC: 人必须监控, 系统只辅助单段 (当前: 每段技能人触发/监控)
- **L3** = 高速 NOA: 特定场景(高速)系统全自主, 出场景交还人 (目标: 标准插拔任务自主)
- **L4** = 城区 NOA: 复杂场景(城区)全自主, 系统能自己恢复失败 (目标: 任意布局+失败重试)

## 升级路径 (当前 → 目标)

### L2 → L3 (基础辅助 → 高级 NOA): "从单段辅助到整任务自主"
**升级什么**:
1. **VLM 权重接入** (核心): 下载 SmolVLM 500M → smolvla_lew 真实推理
   (当前: 架构节点+源码映射, 无权重=教学展示 → 真实 encoder: 图像/触觉/检测框→潜空间)
2. **Flow-Matching ActionHead 训练**: 用现有 metaworld 数据训练 DiT action head
   (潜空间 z → 动作块, chunk 预测) — 数据已有 (9.2万帧左脑数据集可复用)
3. **任务指令→动作直通**: 画布 ▶运行 增加"L3 端到端模式"选项
   (任务指令 → VLM 编码 → ActionHead 解码 → 执行, 不经状态机分段)
4. **交还机制**: 置信度低/出域 → 交还 L2 分段控制 (画布自动切换)

**验收**: 端到端模式在标准布局 (seed104) 达到与分段控制同等的插入成功率;
交还测试: 人为扰动触发交还不卡死。

### L3 → L4 (高级 NOA → 专家城区): "从场景自主到全自主恢复"
**升级什么**:
1. **世界模型实时预测接入**: 右脑 WM 预测的 next_obs/接触概率 从"展示"接入决策
   (当前: 预测只在估计器/可视化用 → L4: 预测超前半步, 预判接触/风险)
2. **流形导航闭环**: 接触/性能流形从"诊断地图"接入 ActionHead/前馈
   (当前: 流形节点吃 z 但输出未参与控制 → L4: Decoder 沿流形解码, 偏离自动回流形)
3. **多布局自主恢复强化**: 失败布局 (seed100/105-109) 自主恢复策略
   (重定位/重抓/重插 分级重试 — 当前恢复已有基础, 提升难布局成功率)
4. **肌肉记忆跨场景**: 标杆模板按布局聚类共享 (相似布局复用标杆, 减少训练轮)

**验收**: 多布局成功率提升 (R0 5/10 → 目标 8/10+); 自主恢复测试:
人为制造夹持滑脱/插入遇阻 → 系统自主恢复完成, 无需人介入。

### L4 → L4+ (专家 → 工厂量产): "从自主到自适应进化"
**升级什么**:
1. 肌肉记忆标杆持续进化 (真机运行积累, 越用越顺)
2. 产线换型自适应 (新光模块型号 → 技能编排 + 快速学习)
3. 全流程无人值守 (多轮连续运行, 成功率自我监控+预警)
