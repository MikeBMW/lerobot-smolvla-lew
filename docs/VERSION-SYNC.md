## 同步规则

1. **中版本必须一致**：产品中版本升级 → 管线中版本同步升级（1.x ↔ 2.x 同功能集）
2. 小版本可独立（产品补文档 / 管线修 bug 各自 commit）
3. 大版本（产品 2.x / 管线 3.x）需三人评审后统一升级

1. 确定功能集（三人对齐）
2. 中版本升级：pipe version.json + GUI docs/VERSION.md 同步更新
3. 打 tag（pipe tag vX.Y.Z / GUI 文档记录）
4. 推送 + 通知三人 pull
