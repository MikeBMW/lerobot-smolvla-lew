## 一、场景 1 · 金线键合连板 搬运与上料

### 工艺环节背景
金线键合是光引擎封装的必经工序：整板连板需从料笼取出 → 送入键合设备 → 完成 193 根金线键合 → 取出 → 交人工显微镜全检。

### 操作需求描述
1. 从料笼中取出连板（料笼为多层插槽结构）
2. 将连板送入键合机治具（治具为导轨式插槽）
3. 键合完成后将连板从治具抽出
4. 放回料笼指定槽位，等待下一工序

### 节拍与效率要求
| 项 | 要求 |
|---|---|
| 单次上下料节拍 | ≤ 6 秒（含取放与往返） |
| 连续作业 | 24 小时不间断，换批时间 ≤ 5 分钟 |
| 人工替代 | 替代 1 名专职上下料操作员 |

### 良率与质量要求
| 项 | 要求 |
|---|---|
| 搬运良率 | ≥ 99.5%（不碰伤、不刮擦、不脏污连板表面） |
| 到位准确 | 连板每次入槽位置一致，不得倾斜、不得未插到位 |
| 追溯 | 每板 SN 自动记录，与键合数据绑定 |

### 物料规格（连板）
| 项 | 规格 |
|---|---|
| 外形尺寸 | ~230 × 280 mm（含工艺边） |
| 厚度 | 1.6 mm 标准 PCB 板厚 |
| 重量 | ≤ 500 g |
| 材质 | FR-4 玻纤基板 + 表面金手指，易刮伤 |
| 装夹方式 | 料笼插槽 / 治具导轨，需侧向进入 |

### 环境与安全
- 无尘车间 Class 1000，操作不得产生颗粒
- 与键合机信号联锁：治具到位确认后才允许键合启动

## 二、场景 2 · 芯片贴装 上下料与流转

### 工艺环节背景
DA 芯片贴装（PIC/TIA/PD/COC 等）分多道工序，每道工序前后都需要从料盒取料、上机、下料、退回料盒。物料以"连板 + 料盒"形式流转。

### 操作需求描述
1. 从料盒取出连板，送入贴片设备（设备自动识别连板标记）
2. 贴片完成后取出连板，退回料盒原槽位
3. 多道 DA 工序间连板流转（料盒 → 设备 → 料盒）

### 节拍与效率要求
| 项 | 要求 |
|---|---|
| 单次上下料节拍 | ≤ 4 秒 |
| 连续作业 | 24 小时不间断 |
| 人工替代 | 替代 1 名上下料操作员 |

### 良率与质量要求
| 项 | 要求 |
|---|---|
| 搬运良率 | ≥ 99.8% |
| 到位准确 | 连板入盒入槽位置一致，槽位不刮擦 |
| 追溯 | 连板 SN 与贴片数据绑定，随过站记录 |

### 物料规格
| 项 | 规格 |
|---|---|
| 连板尺寸 | ~150 × 200 mm |
| 料盒 | 标准 SMT 料盒（多层槽位），单盒 ≤ 1 kg 满载 |
| 重量 | 连板 ≤ 200 g；料盒满载 ≤ 1 kg |
| 材质 | 防静电材质，操作全程需防静电（ESD 安全） |

### 环境与安全
- 防静电车间，设备需 ESD 接地
- 与贴片设备信号联锁（进出料确认）

## 三、场景 3 · 透镜耦合 取放与对准

### 工艺环节背景
LD 透镜耦合（AA 耦合）是光引擎最精密的环节：透镜需从物料盘取出 → 送入耦合设备 → 耦合完成后取下放回。耦合过程由设备自动完成，机器人负责"取放料"与"对准配合"。

### 操作需求描述
1. 从物料盘取透镜（透镜为微小型光学件）
2. 送至耦合工位（需与设备工装精确对位，保证光路耦合窗口居中）
3. 耦合完成后取下，放回物料盘指定格位
4. 全程不得触碰透镜光学面

### 节拍与效率要求
| 项 | 要求 |
|---|---|
| 单次取放节拍 | ≤ 10 秒 |
| 连续作业 | 24 小时不间断 |
| 人工替代 | 替代 1 名精密取放操作员 |

### 良率与质量要求
| 项 | 要求 |
|---|---|
| 取放良率 | ≥ 99.5% |
| 对准要求 | 透镜入位偏差控制在头发丝直径量级（客户现场以光功率判定为准） |
| 防污 | 光学面零接触、零污染；不合格透镜隔离回收 |

### 物料规格（LD 透镜）
| 项 | 规格 |
|---|---|
| 外形尺寸 | ~3 × 3 mm（含镜体与支架） |
| 重量 | < 1 g |
| 特性 | 光学面极易污染/划伤，需真空吸持或软性夹持 |
| 料盘 | 标准 5×5 格位料盘 |

### 环境与安全
- 万级洁净环境，操作区正压
- 透镜全程单件流转，禁止叠放

## 四、场景 4 · 保护盖 安装与压合

### 工艺环节背景
光引擎模块完成贴装后需安装保护盖（PEI Cover）：先对连板点胶（3 处），再将保护盖对准安装位压合到位，目检后装回料笼。

### 操作需求描述
1. 从料笼取下连板
2. 将保护盖对准连板安装位（盖体带定位销/卡扣结构）
3. 垂直压合安装到位（安装后盖体与连板贴合无翘起）
4. 目检后装回料笼

### 节拍与效率要求
| 项 | 要求 |
|---|---|
| 单件安装节拍 | ≤ 15 秒（含取放与压合） |
| 连续作业 | 24 小时不间断 |
| 人工替代 | 替代 1 名装配操作员 |

### 良率与质量要求
| 项 | 要求 |
|---|---|
| 安装良率 | ≥ 99.9% |
| 压合质量 | 盖体安装到位、卡扣闭合、无翘边；压合压力可控不损伤连板 |
| 追溯 | 盖体 SN 与连板 SN 绑定 |

### 物料规格
| 项 | 规格 |
|---|---|
| 保护盖尺寸 | ~40 × 30 mm（PEI 材质） |
| 重量 | ~8 g |
| 连板 | ~150 × 200 mm（与场景 2 同规格） |
| 结构 | 盖体带定位销 + 卡扣，需垂直方向压入 |

### 环境与安全
- 压合过程不得产生颗粒（PEI 材质轻微磨屑需避免）
- 与点胶工序衔接：胶水固化窗口内完成安装

## 五、场景 5 · 隔离器 安装与定位

### 工艺环节背景
隔离器需安装在光路两侧：先在连板指定位置点胶，再将隔离器放置到胶面上，UV 固化后完成。左右两侧各一次。

### 操作需求描述
1. 取隔离器（微型光器件，带磁环结构）
2. 对准连板胶面位置放置（位置需精确，保证光路对中）
3. 放置后保持稳定直到 UV 固化完成（约 10 秒）
4. 左右两侧各执行一次

### 节拍与效率要求
| 项 | 要求 |
|---|---|
| 单侧安装节拍 | ≤ 20 秒（含固化等待） |
| 连续作业 | 24 小时不间断 |
| 人工替代 | 替代 1 名贴装操作员 |

### 良率与质量要求
| 项 | 要求 |
|---|---|
| 安装良率 | ≥ 99.7% |
| 放置精度 | 隔离器中心与光路中心对齐，偏差不超过一根头发丝的几分之一 |
| 固化质量 | 固化期间隔离器不得位移/倾斜 |
| 追溯 | 每件隔离器 SN 与连板绑定 |

### 物料规格（隔离器）
| 项 | 规格 |
|---|---|
| 外形尺寸 | ~5 × 5 × 3 mm |
| 重量 | ~1 g |
| 特性 | 带磁环，取放时避免吸附周围金属件；光学面需保护 |
| 料盘 | 防静电料盘 |

### 环境与安全
- 防静电操作，避免磁环吸附异物
- UV 固化区域有紫外线辐射，操作区需与固化区隔离

## 六、场景 6 · 光芯片 固晶与绑定

### 工艺环节背景
COC 光芯片固晶/绑定（AuSn 共晶 280°C）与打线是基板区最精密工序：基板级物料（Submount 垫块、COC 芯片）需高精度固晶，随后绑定。

### 操作需求描述
1. 从料盘取基板级物料（亚毫米级微小件）
2. 送至固晶工位，与固晶台精确对位
3. 固晶/绑定完成后取下，放入下一工序料盘
4. 全程零触碰非夹持面

### 节拍与效率要求
| 项 | 要求 |
|---|---|
| 单次固晶节拍 | ≤ 8 秒 |
| 连续作业 | 24 小时不间断 |
| 人工替代 | 替代 1 名精密固晶操作员 |

### 良率与质量要求
| 项 | 要求 |
|---|---|
| 固晶良率 | ≥ 99.9% |
| 对位精度 | 芯片与基板对位达到微米级（肉眼不可辨的精度） |
| 温控配合 | 配合 280°C 共晶工艺，取放时序与温度曲线联动 |
| 追溯 | 芯片 SN、基板 SN、固晶参数三方绑定 |

### 物料规格（基板级）
| 项 | 规格 |
|---|---|
| Submount 垫块 | ~1 × 1 mm 级，重 < 0.5 g |
| COC 芯片 | 亚毫米级，重 < 0.5 g |
| 基板 | 陶瓷/金属化基板，表面洁净度要求极高 |
| 料盘 | 精密微孔料盘，单格防滑 |

### 环境与安全
- 万级洁净环境
- 高温工位（280°C）周边需隔热与安全防护
- 微件取放全程防静电、防飞散（一旦飞落不可找回）

## 七、通用要求（所有场景适用）

### 节拍与产能
- 所有操作环节节拍达标后，产线综合节拍满足现有 UPH 目标
- 设备具备换批快速切换能力（换批时间 ≤ 5 分钟）

### 良率与质量
- 所有操作良率 ≥ 99.5%（个别场景更高，见各章）
- 操作全程不产生新增不良（不碰伤、不污染、不混料、不丢件）
- 每个动作可追溯、可回放（时间、工位、物料 SN、操作结果）

### 物料适配
- 外形尺寸覆盖上述各章规格，兼容料笼/料盒/料盘/治具四类载具
- 重量范围覆盖 <0.5g 至 1kg
- 兼容防静电、光学防污、高温、磁吸四类物料特性

### 环境
- 无尘/万级/防静电环境要求（按区域）
- 24 小时连续作业，全年 350 天以上可用

### 人机协同
- 设备运行期间人员可在安全距离内进行目检、抽检、异常处理
- 异常报警后 10 分钟内可恢复（人工介入通道畅通）
- 操作界面中文，一线员工 30 分钟培训可上手

## 九、与现有产线的衔接

- 各场景对应产线现有工位（见各章工艺背景），设备到位后原人工工位转为抽检/异常处理
- 物料载具（料笼/料盒/料盘）沿用现有规格，不改动现有流转
- 信号衔接：设备与上下游设备（键合机/贴片机/固化设备/耦合设备）的联锁与节拍匹配由产线集成商负责
- 本需求书与产线工艺文档（各区域完整工艺文档）配套使用
