## 3. 无标定方案 (从已有资源自构, 三条并行)
### 方案 A · 运动学自校 (只用编码器+控制器TCP, 零外部)
- 我自主把臂走到 N(≥30) 个关节构型 → 记录 (关节向量 q, 控制器 TCP)。
- 用我的 URDF/MoveIt 模型算 FK(q) → 与控制器 TCP 比对 → **自拟合** (基座偏移 / 工具偏移 / 关节零位残差)。
- 判据: 校正后 FK 与控制器残差 **< 0.5mm / 0.2°** (校正前先量出基线残差)。
- 价值: MoveIt 规划与真机同源 ⇒ 规划可直接执行; 且**不需要任何外部标定物**。
### 方案 B · 视觉-基座映射自监督 (用编码器 TCP 当标签, 不依赖曝光稳定)
- 关键认识: AOI 相机**曝光不稳**(实测跨位姿 64.5%) ⇒ 不用强度特征, 改用**曝光不变特征**:
  ① 边缘/相位结构 (CLAHE+Sobel 后取相位相关) ② 帧间**结构张量方向的分布** ③ 由臂自身运动引起的**结构变化区域**的多尺度直方图。
- 监督标签 = 同一时刻编码器 TCP (µrad 级真值) ⇒ **自监督** 学 `f(图像特征) → (x,y,z)_base`。
- 判据: 留出位姿的预测误差 (mm) 与平凡基线(常数/均值)对照, 必须显著更好才算成立。
- 若仍不成立 → 如实记录"该相机在现有条件下不可用", 并转向方案 C (不是回到求人)。
### 方案 C · 仿真-真机自监督迁移 (零外部真值)
- 仿真引擎提供全标注 (位姿, 观测, 事件) → 在仿真学映射/策略 → **真机只做一致性校验** (无标注)。
- 已在做: 事件头 (同源 300 段 CV 6/6 · 闭环 7/7) · state_space 策略 (引擎闭环 20% → 目标 ≥60%)。
- 这条**完全不依赖现场条件**, 是主进化路径。
