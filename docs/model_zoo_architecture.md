# 🧩 Model Zoo 配置表架构设计 (技术对比维度)

> 版本: v2.7.4 · 2026-08-25 · 作者: Z-MAX 控制台
> 实现: `tools/gui/studio.py` ZOO_SPEC (宝马整车配置表风格 · 9 模型横列 × 类别分组)

---

## 一、背景

Model Zoo 横向对比表把 9 个模型放在同一张表里，用"类别分组 × 模型横列"表达技术差异。
模型: ACT / SmolVLA / SmolVLA+LEW / VLA-Touch / AWE / MLP 蒸馏 / 官方专家 / 状态空间 / YOLO检测

核心难点: 这 9 个模型分属三条技术路线 (VLA / CNN / 状态观测)，直接比"层数"会张冠李戴。
解决方案: 用**三层架构划分**统一维度，每条路线在各自专有层上填值，其余 "—"。

---

## 二、三层架构划分 (核心)

| 层次 | 性质 | 是否"层" | 是否可学习 | 内容 |
|------|------|---------|-----------|------|
| ① 模型层 | 可学习参数, 梯度流过 | ✅ 是 | ✅ | 状态编码器 / 左脑MLP / 右脑WM / VLM层 / CNN层 / Expert层 |
| ② 决策编排层 | 符号规则, 非参数 | ❌ 模块非层 | ❌ | 动作调制器 (8阶段门控) |
| ③ 系统安全层 | 硬件/物理约束 | ❌ | ❌ | 安全限值 (Sys-0 安全护盾) |

只有 ① 是"专有层"；② 是规则编排；③ 独立于模型，所有路线共有。

---

## 三、架构类别栏位设计

```
🏗 架构
  ├ 架构        各模型骨干 (SmolVLM2→DiT-B / CSPDarknet→PAN-FPN / MLP 512×3→4D)
  ├ VLM 层     Transformer 层数 (SmolVLA 16 / VLA-Touch 8 / AWE 6)
  ├ CNN 层     卷积模块数 (YOLO检测 8×C2f+SPPF)
  ├ 状态编码   状态向量编码 (39D→512, 左脑 MLP)
  ├ 动作调制   阶段门控融合 (状态空间 8阶段门控)
  ├ Expert 层  MoE 专家数 (SmolVLA 4 / 状态空间 1)
  ├ 模型宽度   向量宽度=隐藏层维度 (ACT 512 / SmolVLA 1024 / YOLO "—")
  └ 世界模型   世界模型头 (SmolVLA+LEW LeWorldModel / 状态空间 状态空间估计器)
```

三条技术路线分野:
1. **VLA 路线**: 视觉-语言 Transformer (VLM 层数 16/8/6)
2. **CNN 路线**: 卷积特征提取 (C2f×8+SPPF)
3. **状态观测路线**: 状态向量编码 (39D→512) + 动作调制 (8阶段门控) + 世界模型 (状态空间估计器)

## 四、术语辨析 (血泪, 勿再混)

### 4.1 模型宽度 = 向量宽度, 不是模型规模
- "模型宽度" = 隐藏层维度 (vector width)，如 ACT 512 / SmolVLA 1024。
- YOLO 是 CNN 检测器，**无向量宽度概念** → 填 "—"。
- ❌ 曾误填 "yolov8s" (那是模型规模代号, 不是宽度)。

### 4.2 状态空间 ≠ 状态空间模型
- **状态空间 (State Space)**: 控制论概念, 系统状态集合。Z-MAX 用这个 (39D 状态观测)。
- **状态空间模型 (SSM = Mamba/S4)**: 深度学习序列架构。Z-MAX **未用**。
- 两者名字像, 完全不同的东西。

### 4.3 39D state 是"状态观测", 不是层
- 39D = 策略输入特征向量 (手位姿/夹爪/peg/hole/上一帧/目标)。
- 处理它的专有层叫 **状态编码器 (State Encoder)**: 39D → 512 latent (左脑 left_hidden=512)。
- 与 VLM 层 (Transformer) / CNN 层 (卷积) 并列同一维度。

### 4.4 动作调制 = 决策编排模块, 不是层
- 实现: `modeling_left_right.py` `_act_state_machine()` (8 阶段状态机门控)。
- 数学: u = g(stage)·(w_ff·u_ff + (1−w_ff)·u_fb)，权重按阶段切换。
- 接近 w_ff=0.3 (慢通道防碰撞) / 抓取·插入 w_contact=0.85 (力控推力主导)。
- 理论: Brooks 包容架构 (Subsumption) + 残差策略。
- **无参数, 梯度不流经** — 左脑学"修正量", 状态机做"编排"。
- 专业名: 动作调制器 (Action Modulator) / 行为仲裁 (Behavior Arbitration)。

### 4.5 安全限值 = 系统级安全壳, 不是模型层
- 实现: `state_space/safety.py` saturate() + `sys0_safety.py` Sys0SafetyController (L1-L4)。
- 专业名: 安全护盾 (Safety Shield) / 动作安全过滤 (Action Safety Filter) / 控制屏障函数 (CBF)。
- **独立于策略, 所有模型共有** — 不放模型架构表, 应单开"安全"类别。
