## 〇、项目背景与设计理念

光模块工厂的插拔工序 (QSFP/OSFP 等) 要求高节拍、高成功率、保护金手指。现场没有昂贵的激光跟踪仪，只有机器人自身关节编码器 + 六维力传感器。

**核心矛盾**: 没有外部测量设备，如何判断 Kp/Kd 设对了？

**答案**: 用"力"和"位置"两个物理量反向推断代数方程 —— 这就是前馈PD控制系统的设计哲学：

- **前馈通道** (感知链 K_obs × 双脑 K_ff): 回路外补偿固有运动模式，只移零点不改稳定性
- **反馈通道** (状态机 P × 动作 D): 回路内串联校正，Kp 定刚度、Kd 定阻尼
- **状态机增益调度**: 6 阶段各用一组特征根，接近快、转移准、插入稳
- **现场标定三步法**: 推拉测试(ζ手感) → 力尖峰(极限增益) → 听声音(衔接)，不看复数

**核心指标**: 节拍 <15s · 插拔成功率 >99% · 插拔类负载 >1.00kg · 搬运类 ≥5kg

## 五、数学分析 — Z700 模块级数据分析过程

**数据流链路** (Z700 实时控制管线):
    视觉/触觉 → 感知链(观测) → 双脑(预测) → 状态机(决策) → 动作(执行) → 末端

**① 感知链 — 观测模型 y = C·x** (给眼睛)
    输入: YOLO 2D 像素框 + 3D 反投影 + 触觉 4D → 39D 状态向量
    输出: 光模块位姿估计 (peg/hole 3D 坐标)
    数学角色: 观测增益 K_obs = 1.00 (y = Cx 的 C 系数, =1 表示状态直接作为观测)

**② 双脑 — 前馈预测 (给肌肉)**
    左脑 MLP: 由当前 obs 预测动作 u_ff (4D) — 前馈通道主输出
    右脑 WM: 预测 next_obs + contact 概率 (接触时机判断)
    数学角色: 前馈增益 K_ff = 0.20 — 回路外补偿, 预测并抵消固有运动模式

**③ 状态机 — 比例决策 (给节奏)**
    输入: 感知误差 e = r − x (如 ‖hand−peg‖)
    输出: 阶段切换 + 比例指令 (6 阶段增益调度)
    数学角色: 串联校正 P — Kp = 2.00 (增益调度表见下)

**④ 动作 — 微分执行 (给阻尼)**
    输入: 误差变化率 ė + 前馈 u_ff
    输出: 关节力/加速度指令 (限幅 ±0.6 = 饱和阻尼)
    数学角色: 串联校正 D — Kd = 0.30, 等效阻尼项 (b+Kd) 中的 Kd

**⑤ 被控对象 — 末端等效动力学** (质量-弹簧-阻尼):
    m·ẍ + b·ẋ + k·x = F(t),  m=1.0kg · b=2.0N·s/m · k=5.0N/m

**组合 — 双通道校正结构**:
    前馈通道 (回路外): F_ff = K_obs × K_ff = 1.00 × 0.20 = 0.20
    反馈通道 (回路内): C(s) = Kp + Kd·s = 2.00 + 0.30s
    前馈控制律: F(t) = 0.20·r + 2.00·e + 0.30·ė

**拉普拉斯域** (零初始条件):
    [m·s² + (b+Kd)·s + (k+Kp)]·X(s) = [Kd·s + (F_ff+Kp)]·R(s)

**闭环传递函数**:

    G_cl(s) = (0.300s + 2.200) / (1s² + 2.3s + 7)

**特征方程** (决定稳定性):

    1s² + 2.3s + 7 = 0
    特征解 s = -1.150 ± j2.383
    自然频率 ωₙ = 2.646 rad/s · 阻尼比 ζ = 0.435
    **关键结论**: K_ff 不出现在特征方程 — 前馈只移零点、不改稳定性边界，与经典控制理论完全吻合。

**增益调度** (状态机各阶段特征根移动):

| 阶段 | Kp | Kd | ωₙ (rad/s) | ζ | 特征解 | 特性 |
|:---|:---|:---|:---|:---|:---|:---|
| 接近 | 2.00 | 0.30 | 2.65 | 0.43 | -1.15±j2.38 | 欠阻尼 |
| 抓取 | 0.10 | 0.00 | 2.26 | 0.44 | -1.00±j2.02 | 欠阻尼 |
| 抬起 | 0.80 | 0.00 | 2.41 | 0.42 | -1.00±j2.19 | 欠阻尼 |

## 九、风险分析与应对策略

| 风险 | 概率 | 影响 | 早期信号 | 应对策略 |
|:---|:---|:---|:---|:---|
| **Reality Gap 过大** (仿真→真机差距) | 中 | 高: S2 零样本成功率骤降 | S2 成功率 <60% | 补数据回仿真重训; 视觉域随机化; 分轴逐步迁移 |

| **搬运类负载超限** (≥5kg 工况) | 低 | 高: 结构过载 | 电机电流超阈值 | 按搬运类独立标定 m/b/k; 速度限幅降低; 力保护 |
\n**风险应对流程图**: 发现异常信号 → 立即停机保护 → 归因分类 (视觉/力/时序/机械) → 查排查表处置 → 复测验收 → 记录归档。

**兜底机制**: 状态机超时保护 (每阶段超时自动回退待机) + 力限位保护 (超 20N 立即停机) + 模型版本回滚 (保留最近 3 个版本) + 数据闭环 (每次失败自动归档供增量训练)。


## 十、产品形态建议 — AMR 车 + 机械臂

光模块插拔场景的部署形态，推荐 **AMR 自主移动底盘 + 协作机械臂 + 快换末端** 的组合，兼顾插拔精密性与上下料移动性。

**形态一: 单机插拔工作站 (推荐)** — 1 台 AMR + 6 轴机械臂 + 插拔末端

| 部件 | 规格建议 | 依据 |
|:---|:---|:---|
| AMR 底盘 | 负载 ≥30kg (含臂重), 重复停位 ±5mm, 对接精度 ±1mm | 搬运类 ≥5kg + 机械臂自重 |
| 机械臂 | 6 轴, 负载 ≥5kg, 重复定位 ±0.05mm, 臂展 ≥800mm | 插拔力 <20N + 精度 <1mm |
| 插拔末端 | 平行夹爪 + 六维力传感器 + 柔性快换 | 力控 0.6N±0.1 + 力峰监测 |
| 感知 | 2D 相机 (YOLO 检测) + 3D 相机 (深度定位) + 手眼标定 | 39D 状态向量输入 |
| 算力 | Orin (边缘推理, 双脑模型 <0.2ms) | 实时控制管线 |
| 供电 | 48V 电池 + 热插拔换电, 连续 ≥8h | 产线连续节拍 |
\n**形态二: 插拔+搬运复合工作站** — 1 台 AMR + 7 轴机械臂 + 双快换末端

| 特点 | 说明 |
|:---|:---|
| 快换末端 | 插拔末端 (精密) ↔ 搬运末端 (夹爪+吸盘, 兼容 ≥5kg 料盘) |
| 7 轴冗余 | 狭小料盘格位避障, 姿态灵活性 |
| 一机两用 | 插拔工序 + 料盘上下料 + 扫码/AOI 辅助, 设备利用率高 |
| 代价 | 快换精度损失 ~0.02mm (可标定补偿), 成本 +30% |
\n**形态三: 多机协同产线** — 2 台 AMR 分工

| 角色 | 配置 | 职责 |
|:---|:---|:---|
| 插拔机 | AMR + 6 轴臂 + 插拔末端 | 专注插拔 (节拍 13.5s/次) |
| 上下料机 | AMR + 6 轴臂 + 搬运末端 | 料盘上下料/上料 (搬运类 ≥5kg), 与插拔机接力 |
| 协同 | 任务调度 + 安全避让 (激光雷达+视觉) | 产线节拍最大化 |
\n**产品形态决策建议**:

    ① 单产线试运行 → 形态一 (成本最低, 快速验证)
    ② 量产多工位 → 形态三 (插拔/搬运分离, 各司其职, 总节拍最优)
    ③ 场地紧凑 → 形态二 (一机两用, 省场地)

**AMR+机械臂 vs 固定工位对比**: 移动部署免基建改造 · 多工位共享一台设备 · 换线灵活 (改路径即可) · 初期成本高于固定工位, 但全生命周期 TCO 更低。
