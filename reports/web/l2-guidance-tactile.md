## 一、功能定义 (L2 基础辅助功能)

| 编号 | 名称 | 定义与实测指标 | 能力分组 |
|---|---|---|---|
| L2-A12 | 3D 视觉引导 | 视觉引导闭环 (视觉伺服): 2D→3D 解算位姿 → 引导向量 → 伺服收敛。实测 (真物理引擎 seed104 400 步): 横向偏差前1/3中位 140.8mm → 后1/3 38.5mm (**0.27×**), 末端法向偏离 148.3mm → **0.3mm** (mani_dperp 首末)。位姿来源: R0 几何真值 / R1 真帧 YOLO detect_3d (F-C01/C02 另测)。**如实标注**: "静态目标向量 vs 逐帧速度"方向一致率仅 12.3% → 该口径不合适, 判据用**偏差收敛 + 法向偏离归零** (用例 F-B12)。 | 2d3d / sobs / yolo |
| L2-A13 | 触觉反馈闭环 | 力/触觉 → 接触概率 → 力保护闭环。实测: corr(contact_p, |force|) = **0.974** (力→接触概率真实联动) · 插入段 contact_p 中位 **0.9918** · 力上界 **0.672N** (≤1.0 力保护未越界); 触觉通道 obs[39:43] = [原始开度, grasped, 0, 0] 与状态**互补一致率 1.000** (夹紧度=1−开度, 既有约定) · grasped 一致率 0.995。**缺口如实标**: 通道 2/3 (前向/侧向力) 在引擎恒 0 —— 真机触觉才有 (用例 F-B13)。 | tac / sssensor / sobs |

## 三、关键实测数字

| 指标 | 实测值 | 判据 |
|---|---|---|
| 引导向量范数 (中位) | 130.75 mm | — |
| 横向偏差 前1/3 → 后1/3 | 140.84 → 38.54 mm | 后1/3 ≤ 前1/3 × 0.50 |
| 末端法向偏离 首 → 末 | 148.28 → 0.3 mm | 末帧 < 1 mm |
| 触觉通道↔状态 互补一致率 | 0.0 (互补口径 1.000) | ≥ 0.99 |
| 力 → 接触概率 相关性 | 0.9741 | ≥ 0.80 |
| 插入段 contact_p 中位 | 0.9918 | ≥ 0.90 |
| 接触力上界 (力保护) | 0.6718 N | ≤ 1.0 N |
| 触觉通道 2/3 (前向/侧向力) | 引擎恒 0 | 真机触觉缺口 — 如实标注 |

> 注: 触觉通道 0 = 钳口**原始开度**, 轨迹 gripper = **夹紧度 = 1 − 开度** (既有约定), 故用**互补一致率**断言;
> 「静态目标向量 vs 逐帧速度」方向一致率仅 ~0.21 — 该口径不含阶段子目标, 故判据用**偏差收敛 + 法向偏离归零**。
