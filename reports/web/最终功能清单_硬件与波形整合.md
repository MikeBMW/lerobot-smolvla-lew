## 三、波形 = 统一的'脑机接口'验证面 (所有功能的实时证据)

| 可视化窗口 | 验证什么 (波形通道 → 功能) |
|---|---|
| 🧠 前馈激活波动 | 每层能量/激活变化事件波形, 阶段色带(8阶段), 插入尖峰 — ssff 决策/sssched 阶段/全流程 |
| 📊 仿真波形 | 距离/前馈/残差/接触概率/法向偏离/插深剩余/横向错位(0.5mm线) — 感知-估计-动作闭环各功能 |
| 🧭 3D 视图 | 机械臂/光模块/孔 YOLO 检出层/坐标 — 感知硬件的空间证据 |
| 🎯 归因视图 | 512 单元分工 (PCA/t-SNE) — 模型内部功能归属 |
| 🎥 操作视频 | 真机/仿真操作对比 — 最终动作证据 |

**验证闭环**: 测试用例(auto 断言)跑引擎真实数值 → 同一轨迹同时驱动波形窗口 →
波形显示的就是该功能在动作里的实时表现 → 测试=看波形可测到功能, 硬件可溯源(感知查摄像头链路, 动作查珞石臂链路)。

## 四、关键验收 (唯一指标, FNaccept01)

- 插入成功 12/12 扰动集 · 插入段 <0.5s · 末横向错位 <0.5mm · 插深到底 <0.5mm
- 波形证据: 📊仿真波形 底部验收摘要 + 插深剩余/横向错位 0.5mm 红线; 🧠波动视图 插入段金色高亮+✅
- 硬件证据: 感知=摄像头检出(3D YOLO 层), 动作=珞石臂轨迹(3D 机械臂层)
