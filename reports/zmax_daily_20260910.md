### 1. 抓取滑脱死循环 —— 机理完全厘清(这是今天最有价值的发现)
一直以为"难场景卡住"是速度问题,今天实证**不是**:

```
peg 夹持处于临界(metaworld 摩擦夹持, 裕度小)
  → peg 在夹爪内缓慢下滑(|off| 每帧 +0.5~0.7mm)
  → 滑移判据触发 → grasped=False → grasp_force=0
  → 调度器回退到"抓取之前"(stage_idx < GRASP_IDX)
  → gripper_cmd() 返回 0 = 张爪  →  peg 真掉件   ← 爆点在这!
  → 重抓 → 再滑 → 死循环(1500 步跑不完)
```

**修复**:回退重抓期间**保持夹爪闭合**(工件还在手上就不许扔)。实测 seed11 滑移 **20 → 3 次**,
成功组(seed7/9/104)**零回退**(346/355/343 步,与改前逐帧一致)。
