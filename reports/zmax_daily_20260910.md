## 一、决定性突破:黑帧 bug(今日最高价值)

**现象**:模型在 rollout 脚本里能干活,一进引擎接管就卡死(卡"转移"段 2318 帧,2500 步跑不完)。

**定位方法(通用)**:同一 env、同一帧,对比「引擎取帧函数」与「env.render()」的像素差
```
引擎 _render_frame : (480,480,3)
env.render()       : (480,480,3)
平均像素差 130.72 / 255  →  引擎帧其实是一张全黑图
```

**根因**:
```python
def _render_frame(self, ...):
    ...
    return self._render_frame()      # 调用自身 → 无限递归 → RecursionError
    except Exception:
        return np.zeros((h, w, 3), np.uint8)   # 被静默吞掉 → 永远返回黑帧, 零报错
```
mac 安全渲染包装时把原实现覆盖了 → 成了自我递归。**极隐蔽:影子模式(不接管)让这个 bug 完全隐形。**

**修复后实测**:
```
insert 模式 : 341 步 · 完成=True   (解析链基线 343 步)
full  模式 : 865 步 · 完成=True   (解析链基线 868 步)
             📷 AOI 检测 PASS · 插入残余深度 5.86mm(<8mm) · 接触力峰 0.976(<1.0) · 无回抓
```

**附带收获**:明确了"模型 + L2 六层控制器"协同的价值 —— 纯模型(rollout 裸跑)仍失败,
而模型接管引擎(有 L2 兜底与状态机管理夹爪)可以完成全链。

## 二、抓取滑脱死循环(机理彻底厘清)

```
peg 夹持临界 → 夹爪内缓慢下滑(|off| 每帧 +0.5~0.7mm)
  → 滑移判据触发 → grasped=False → 调度器回退到"抓取之前"
  → gripper_cmd() 返回 0 = 张爪 → 工件真掉 → 重抓 → 死循环
```
**修复**:回退重抓期间**保持夹爪闭合**(工件还在手上就不许扔)。seed11 滑移 20→3 次,成功组零回退。

**8 条路证伪**(不再重复踩):夹持力 ×4 档、运动限幅 ×3 档、重夹窗口、滑移判据、对孔阈值 ×5 档、
LEW 前视 —— 全部无效或不足。**结论:seed11/12 是仿真物理/布局边界**(seed12 与成功的 seed7 几何完全相同
却滑脱;seed11 的 peg 摆放偏右 6cm),**3/5 是这套仿真的能力上限**。

## 三、插入精度缺口量化 + 螺旋搜索
