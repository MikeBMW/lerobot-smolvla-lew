# 8793 /station 手动控制台 · 第 6 轴 (J6) 独立自转按钮

日期: 2026-09-30 · 需求(老倪): 「8793 手动控制台，增加让 6 轴独立旋转的按钮，分成逆时针旋转和顺时针旋转」

## 1. 设计（先判清「哪个轴」再动手）

| | 位置语义 | 走的通道 | 掉电? | 能不能转 J6 |
|---|---|---|---|---|
| 原有 A/B/C(绕**工具**轴) | TCP **不动**(靠多关节配合) | /move_pose | 不掉 | **不能** |
| **本次新增 J6 自转** | 只转**关节 J6**, TCP 沿 ~24.2mm 半径走小圆弧 | /move_pose | 不掉 | 是 |
| (未采用) /target_relative_joint | 关节增量(最直接) | rt 关节通道 | **动作后下电** | 是 |

**为什么 A/B/C 转不到 J6**: 由现场 URDF tool0→tool1 的固定位姿算, J6 轴在**工具系**的方向
`a_tool = R_off^T·[0,0,1] = (-0.6250, +0.0289, +0.7801)`, 与 工具 X / Y / Z 各差
**51.3° / 88.3° / 38.7°** ⇒ 三个工具轴没一个等于 J6。

**为什么不用关节通道**: 实测 rx rt 通道动作后驱动会把**伺服下电**(现场要反复上电, 老倪已投诉),
改用**等效笛卡尔**: 绕 J6 轴线(法兰原点 + link6 的 z)转 θ 后下发 /move_pose。

## 2. UI (页面新增卡片, 放在「绕轴旋转」下面)

```

   步进  [1°] 5°  10°
   ┌──────────────┐ ┌──────────────┐
   │  ↺ 逆时针     │ │  ↻ 顺时针     │
   │  +J6 · 1°    │ │  −J6 · 1°    │
```

- 两个大按钮并排, 左绿右黄(视觉可辨), 步进**默认 1°**(首次现场确认观感用), 上限 10°(执行层守卫)。
- 未授权时按钮变淡但仍可点 —— 点了出「🧪 演练(未下发)」+ 执行器原始行(不动作)。
- 与 A/B/C 同样的四道闸: 服务级 `--ctl-motion` → 页面授权真动 → 技能白名单 → 限幅/限流。
